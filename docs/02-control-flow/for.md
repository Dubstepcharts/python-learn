# Цикл for

!!! abstract "Уровень: ⭐ Начальный"
    Подойдёт для 5–7 класса. Нужно знать: [цикл while](while.md).

---

## 🍎 Объясняем просто

!!! example "for — когда знаешь, сколько раз"
    Если нужно «повторить 5 раз» или «пройти по всем конфетам в коробке» —
    это `for`. Он берёт **каждый элемент по очереди** и делает с ним что-то.
    
    В отличие от `while`, здесь не надо вручную увеличивать счётчик —
    Python делает это сам.

---

## 📖 Теория

**Цикл `for`** проходит по элементам «коллекции» и на каждом шаге подставляет очередной элемент в переменную.

```python
for i in range(1, 6):
    print(i)
```

**Результат:**
```
1
2
3
4
5
```

Разберём по частям:
- `for` — ключевое слово
- `i` — имя переменной (любое, но обычно `i`, `x`, `n`)
- `in` — «внутри»
- `range(1, 6)` — коллекция чисел от 1 до 5 (**не включая 6**)

!!! info "Подробнее: почему range(1, 6) даёт 1..5 🔬"
    `range(начало, конец)` включает начало, но **не включает** конец. Это
    удобно в программировании: `range(0, n)` даёт ровно `n` чисел.
    
    Три формы:
    - `range(5)` — от 0 до 4 (5 чисел)
    - `range(2, 6)` — от 2 до 5
    - `range(0, 10, 2)` — от 0 до 8 с шагом 2 (чётные)

---

## ✍️ Синтаксис

```python
for переменная in последовательность:
    # тело цикла
    # отступ 4 пробела
```

**Последовательность** — что угодно, по чему можно пройти:
- `range(...)` — диапазон чисел
- строка — по буквам
- список — по элементам
- кортеж, словарь, множество

## 💡 Примеры

### Пример 1. Обратный отсчёт ⏱️

```python
for n in range(5, 0, -1):
    print(n)
print("Поехали!")
```

**Результат:** `5, 4, 3, 2, 1, Поехали!`

Третий аргумент `range(5, 0, -1)` — шаг `-1`, идём вниз.

### Пример 2. Сумма от 1 до 100 🧮

```python
total = 0

for i in range(1, 101):
    total += i

print(total)   # 5050
```

Обратите внимание: `range(1, 101)` — потому что 101 **не включается**.
Это ловушка, в которую попадают все начинающие.

### Пример 3. Пройти по буквам слова 🔤

```python
for letter in "Python":
    print(letter)
```

**Результат:**
```
P
y
t
h
o
n
```

### Пример 4. Пройти по списку 🎒

```python
fruits = ["яблоко", "банан", "груша"]

for fruit in fruits:
    print(f"Я люблю {fruit}")
```

**Результат:**
```
Я люблю яблоко
Я люблю банан
Я люблю грушу
```

### Пример 5. Таблица умножения 📊

```python
n = 7

for i in range(1, 10):
    print(f"{n} × {i} = {n * i}")
```

**Результат:**
```
7 × 1 = 7
7 × 2 = 14
...
7 × 9 = 63
```

### Пример 6. Сюжетный — космос 🚀

```python
planets = ["Меркурий", "Венера", "Земля", "Марс", "Юпитер"]

for planet in planets:
    print(f"Изучаем планету: {planet}")
```

## 🔍 `for` vs `while`

| Задача | Что выбрать |
|---|---|
| Повторить N раз | `for` |
| Пройти по элементам списка, строки | `for` |
| Повторять, пока не выполнено условие | `while` |
| Неизвестно, сколько итераций | `while` |

**Правило:** если ты можешь сказать «повтори N раз» или «пройди по всем элементам» — это `for`.

## 📌 Полезные приёмы

### Пропустить ненужную переменную

Если переменная цикла не нужна — используйте `_`:

```python
for _ in range(3):
    print("Привет!")
```

Три раза напечатает «Привет!» — имя переменной не важно.

### `enumerate` — с номерами

```python
fruits = ["яблоко", "банан", "груша"]

for i, fruit in enumerate(fruits, start=1):
    print(f"{i}. {fruit}")
```

**Результат:**
```
1. яблоко
2. банан
3. груша
```

`enumerate` даёт и номер, и элемент. Классика для нумерованных списков.

### `sum`, `max`, `min` — готовые функции

Вместо ручного цикла:

```python
numbers = [3, 7, 2, 9, 5]
print(sum(numbers))   # 26
print(max(numbers))   # 9
print(min(numbers))   # 2
```

Эти функции принимают любую коллекцию и работают быстрее ручного `for`.

## ⚠️ Частые ошибки

!!! warning "Ошибка 1. Забыли, что range не включает конец"
    ```python
    for i in range(1, 10):     # даст 1..9, а не 1..10
    ```
    Для 1..10 нужно `range(1, 11)`.

!!! warning "Ошибка 2. Изменение списка внутри цикла"
    ```python
    items = [1, 2, 3]
    for x in items:
        items.append(x * 2)   # ❌ цикл становится бесконечным
    ```
    Никогда не меняйте коллекцию, по которой идёте.

!!! warning "Ошибка 3. Отступы"
    ```python
    for i in range(3):
    print(i)   # ❌ IndentationError
    ```

!!! warning "Ошибка 4. `range(1, 5.5)`"
    `range` работает **только с целыми числами**. Для дробных нужен
    `while` или другой подход.
