# Цикл while

!!! abstract "Уровень: ⭐ Начальный"

---

## 🍎 Объясняем просто

!!! example "Повторяем, пока…"
    Ты когда-нибудь слышал: «Ешь суп, **пока** не доешь»? Это цикл `while`.
    Программа повторяет действие до тех пор, пока условие остаётся истинным.
    
    Как только условие стало ложным — цикл останавливается.

---

## 📖 Теория

**Цикл `while`** повторяет блок кода, пока условие истинно.

```python
count = 1
while count <= 5:
    print(count)
    count = count + 1
```

**Результат:**
```
1
2
3
4
5
```

**Как это работает:**
1. Проверяем `count <= 5` → True (1 ≤ 5)
2. Выводим `1`, увеличиваем `count` до 2
3. Снова проверяем → True (2 ≤ 5)
4. И так далее…
5. Когда `count` станет 6, условие станет False — цикл завершится.

!!! warning "Самая опасная ошибка — бесконечный цикл"
    Если забыть изменить `count` внутри цикла, условие **никогда** не станет
    ложным, и программа будет крутиться вечно:
    ```python
    count = 1
    while count <= 5:
        print(count)
        # забыли count = count + 1
    ```
    Это называется **бесконечный цикл**. Остановить — `Ctrl + C` в терминале.

!!! info "Подробнее: три обязательных элемента цикла 🔬"
    В любом корректном `while` есть три части:
    1. **Инициализация** — задаём начальное значение (`count = 1`)
    2. **Условие** — когда продолжать (`while count <= 5`)
    3. **Изменение** — что меняется на каждом шаге (`count += 1`)
    
    Если пропустить любую из трёх — цикл либо не запустится, либо не остановится.

---

## ✍️ Синтаксис

```python
инициализация
while условие:
    # тело цикла
    изменение_переменной
```

Сокращённые операторы — те же, что мы уже знаем:
- `count += 1` — то же, что `count = count + 1`
- `count -= 1` — уменьшение
- `count *= 2` — умножение

## 💡 Примеры

### Пример 1. Обратный отсчёт 🚀

```python
n = 5
while n > 0:
    print(n)
    n -= 1
print("Поехали!")
```

**Результат:**
```
5
4
3
2
1
Поехали!
```

### Пример 2. Сумма чисел от 1 до 100 🧮

```python
total = 0
i = 1

while i <= 100:
    total += i
    i += 1

print(f"Сумма: {total}")   # 5050
```

### Пример 3. «Угадай число» 🎲

```python
secret = 7
guess = 0

while guess != secret:
    guess = int(input("Угадай число от 1 до 10: "))

print("Молодец, угадал!")
```

Программа будет спрашивать снова и снова, пока пользователь не введёт `7`.

!!! tip "Можно добавить подсказки"
    ```python
    while guess != secret:
        guess = int(input("Угадай: "))
        if guess < secret:
            print("Больше!")
        elif guess > secret:
            print("Меньше!")
    ```

### Пример 4. Сюжетный — копилка 🐷

```python
goal = 5000    # копим на велосипед
saved = 0
day = 0

while saved < goal:
    saved += 250      # каждый день откладываем 250 руб.
    day += 1

print(f"Цель достигнута за {day} дней!")
```

**Результат:** `Цель достигнута за 20 дней!`

### Пример 5. Проверка ввода 🔁

```python
password = ""

while password != "python123":
    password = input("Введите пароль: ")
    if password != "python123":
        print("Неверно, попробуйте снова")

print("Добро пожаловать!")
```

Цикл повторяется, **пока пользователь не введёт правильный пароль**. Это классический шаблон «повторять, пока не получится».

## 🔍 Когда использовать `while`

| Ситуация | `while` подходит? |
|---|---|
| Повторять, пока пользователь не введёт корректные данные | ✅ Да |
| Повторять, пока не найдём нужное | ✅ Да |
| Пройти по всем элементам списка | ⚠️ Лучше `for` |
| Повторить N раз | ⚠️ Лучше `for` |

Общее правило: если **знаешь количество повторов** — используй `for`. Если **не знаешь, сколько раз** — `while`.

## ⚠️ Частые ошибки

!!! warning "Ошибка 1. Бесконечный цикл"
    ```python
    i = 1
    while i < 10:
        print(i)
        # забыли i += 1 — цикл никогда не остановится
    ```
    Если случайно запустили — `Ctrl + C`.

!!! warning "Ошибка 2. Условие, которое сразу False"
    ```python
    i = 100
    while i < 10:
        print("Это никогда не выполнится")
    ```
    Проверьте начальное значение!

!!! warning "Ошибка 3. Изменение не той переменной"
    ```python
    i = 1
    j = 1
    while i < 5:
        print(i)
        j += 1     # ❌ меняем j, а условие зависит от i
    ```
    Меняйте **ту же** переменную, что в условии.

!!! warning "Ошибка 4. Потерянная единица"
    ```python
    i = 0
    while i < 5:
        i += 1
        print(i)     # выведет 1, 2, 3, 4, 5 — а не 0..4
    ```
    Проверьте, где именно вы увеличиваете счётчик — до или после вывода.
