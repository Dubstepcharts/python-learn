# break и continue

!!! abstract "Уровень: ⭐⭐ Средний"
    Подойдёт для 7–9 класса. Нужно знать: [цикл for](for.md), [цикл while](while.md).

---

## 🍎 Объясняем просто

!!! example "Два «рычага» для цикла"
    - **`break`** — «стоп, выходим из цикла совсем». Как кнопка «аварийный
      выход».
    - **`continue`** — «пропустим этот шаг, идём к следующему». Как «дальше,
      тут не интересно».

    Обе команды используются внутри циклов `for` и `while`.

---

## 📖 Теория

### `break` — полностью прервать цикл

Как только Python встречает `break`, он **немедленно** выходит из цикла,
даже если условие ещё истинно.

```python
for i in range(1, 10):
    if i == 5:
        break
    print(i)
```

**Результат:**
```
1
2
3
4
```

На `i == 5` произошёл `break`, и цикл остановился. `5` не напечаталось.

### `continue` — пропустить оставшуюся часть шага

`continue` не выходит из цикла. Он просто переходит к следующей итерации,
пропуская код, который идёт **после него в теле цикла**.

```python
for i in range(1, 6):
    if i == 3:
        continue
    print(i)
```

**Результат:**
```
1
2
4
5
```

Число 3 «выпало», всё остальное напечаталось.

!!! info "Подробнее: разница на картинке 🔬"
    Представь цикл как конвейер:
    
    ```
    ┌─→ начало итерации
    │      │
    │      ▼
    │   какой-то код
    │      │
    │      ▼
    │   continue ──────┐
    │      │           │
    │      ▼           │
    │   ещё код        │
    │      │           │
    │      ▼           │
    │   break ──→ (выход из цикла навсегда)
    │      │
    └──────┘
    ```
    
    `continue` прыгает в начало следующей итерации. `break` выпрыгивает
    из цикла.

## 💡 Примеры

### Пример 1. Поиск числа 🔍

Ищем, есть ли в списке число 7. Как только нашли — выходим:

```python
numbers = [3, 8, 1, 7, 5, 9]

for n in numbers:
    if n == 7:
        print("Нашли семёрку!")
        break
```

Без `break` цикл проверил бы все элементы до конца — а смысла нет.

### Пример 2. Пропустить отрицательные 🚫

Считаем сумму только положительных чисел:

```python
numbers = [4, -2, 7, -5, 3, -1, 8]
total = 0

for n in numbers:
    if n < 0:
        continue
    total += n

print(total)   # 4 + 7 + 3 + 8 = 22
```

### Пример 3. `while` с `break` 🔐

Бесконечный цикл `while True` — но выходим по условию:

```python
while True:
    password = input("Пароль: ")
    if password == "python":
        print("Открываю секрет...")
        break
    print("Неверно, ещё раз")
```

Классический шаблон «повторяй, пока пользователь не введёт правильно».

### Пример 4. Сюжетный — школьный журнал 📓

```python
grades = [5, 4, 3, 2, 5, 4]

for grade in grades:
    if grade == 2:
        print("Есть двойка, разбираемся!")
        break
    print(f"Оценка {grade} — норм")
```

**Результат:**
```
Оценка 5 — норм
Оценка 4 — норм
Оценка 3 — норм
Есть двойка, разбираемся!
```

### Пример 5. `continue` для фильтрации 🧹

Выведем только чётные числа:

```python
for i in range(1, 11):
    if i % 2 != 0:
        continue
    print(i)
```

**Результат:** `2 4 6 8 10`

То же самое можно записать через `if i % 2 == 0: print(i)` — но `continue`
иногда делает код «плоским» и читаемым при сложных условиях.

## 📌 `else` у цикла (сюрприз!)

В Python у циклов есть необычная конструкция: `for ... else` и `while ... else`.
Блок `else` выполняется, **если цикл завершился нормально** (не через `break`).

```python
for n in [2, 4, 6, 8]:
    if n == 5:
        print("Нашли 5!")
        break
else:
    print("Пятёрки в списке нет")
```

**Результат:** `Пятёрки в списке нет`

Это удобно для поиска: если `break` не сработал — значит, искомого нет.

!!! warning "Не путайте с `else` у `if`"
    `else` у `if` — «иначе, если условие ложно».
    `else` у `for`/`while` — «если цикл дошёл до конца без `break`».
    
    Это разные вещи! Не смущайтесь, если сначала кажется странным.

## ⚠️ Частые ошибки

!!! warning "Ошибка 1. `break` вне цикла"
    ```python
    break   # ❌ SyntaxError: 'break' outside loop
    ```
    `break` и `continue` работают **только внутри** цикла.

!!! warning "Ошибка 2. `break` в неправильном месте"
    ```python
    for i in range(10):
        if i > 3:
            break
        print(i)
        # сюда уже не дойдём после break
    ```
    `break` прерывает цикл немедленно. Код после него в **той же итерации**
    не выполнится.

!!! warning "Ошибка 3. `continue` не пропускает всё"
    ```python
    for i in range(5):
        print("начало", i)
        if i == 2:
            continue
        print("конец", i)
    ```
    Для `i = 2` напечатается только «начало 2». Вторая строка пропущена.

!!! warning "Ошибка 4. Забыть выйти из `while True`"
    ```python
    while True:
        print("я тут навсегда")
    ```
    Если внутри нет `break` или `return` — цикл бесконечный. Только `Ctrl + C`.
