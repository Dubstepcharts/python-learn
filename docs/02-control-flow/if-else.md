## 🍎 Объясняем просто

!!! example "Программа учится выбирать"
    Представь светофор: если горит зелёный — иди, иначе — стой. В Python
    это записывается почти по-русски:
    ```python
    if свет_зелёный:
        идти()
    else:
        стоять()
    ```
    Ключевое слово `if` значит «если», `else` — «иначе».

---

## 📖 Теория

**Условие** — это выражение, которое может быть `True` или `False`. Если `True` — программа выполняет один блок, если `False` — другой (или ничего).

```python
age = 16

if age >= 18:
    print("Доступ разрешён")
else:
    print("Доступ запрещён")
```

**Результат:** `Доступ запрещён`

!!! info "Подробнее: отступы — это не украшение 🔬"
    Python — один из немногих языков, где **отступы имеют значение**.
    Блок кода после `if` или `else` отмечается **четырьмя пробелами**
    (стандарт PEP 8). Это не «для красоты» — это синтаксис.
    
    ```python
    if x > 0:
        print("положительное")   # ← 4 пробела
        print("и не ноль")       # ← тоже 4 пробела
    print("а это уже вне блока") # ← без отступа
    ```
    
    Если отступы поедут — Python выдаст `IndentationError`.
    **Совет:** не расставляйте отступы вручную — в VS Code
    после строки с `:` нажмите Enter, отступ появится сам.

## ✍️ Синтаксис

### Полная форма

```python
if условие:
    # выполняется, если условие True
elif другое_условие:
    # выполняется, если первое False, а это True
else:
    # выполняется, если все условия False
```

- `if` — обязательно
- `elif` (сокращение от `else if`) — сколько угодно штук или ни одного
- `else` — один раз или ни одного

### Короткая форма

```python
if условие:
    # только если True
```

Никакого `else` может не быть вовсе.

## 💡 Примеры

### Пример 1. Чётное или нечётное 🎲

```python
number = 7

if number % 2 == 0:
    print("Чётное")
else:
    print("Нечётное")
```

**Результат:** `Нечётное`

### Пример 2. Оценки 🎓

```python
score = 78

if score >= 90:
    print("Отлично")
elif score >= 75:
    print("Хорошо")
elif score >= 60:
    print("Удовлетворительно")
else:
    print("Надо подтянуть")
```

**Результат:** `Хорошо`

Python проверяет условия **сверху вниз** и останавливается на первом `True`. Поэтому `else` ловит всё, что «упало» мимо предыдущих проверок.

### Пример 3. Сюжетный — школа 🏫

```python
day = "суббота"

if day == "суббота" or day == "воскресенье":
    print("Ура, выходной!")
else:
    print("Пора в школу.")
```

### Пример 4. Сюжетный — космос 🚀

```python
fuel = 45
crew_ready = True

if fuel < 30:
    print("Не хватает топлива, старт отменён")
elif not crew_ready:
    print("Экипаж не готов")
elif fuel < 60:
    print("Полёт возможен, но рискованно")
else:
    print("Все системы в норме, старт!")
```

**Результат:** `Полёт возможен, но рискованно`

### Пример 5. Вложенные условия 🪆

```python
age = 15
has_permission = True

if age >= 14:
    if has_permission:
        print("Можно пойти на кружок")
    else:
        print("Нужно разрешение родителей")
else:
    print("Слишком рано")
```

!!! tip "Можно упростить!"
    Вложенные условия часто объединяют через `and`:
    ```python
    if age >= 14 and has_permission:
        print("Можно пойти на кружок")
    ```

## 📌 Оператор `in`

Иногда нужно проверить, есть ли что-то внутри строки или коллекции:

```python
word = "программирование"

if "грамм" in word:
    print("Есть!")   # → Есть!
```

Это тоже условие — возвращает `True` или `False`.

## ⚠️ Частые ошибки

!!! warning "Ошибка 1. Забыли двоеточие"
    ```python
    if x > 0       # ❌ SyntaxError
        print(x)
    ```
    **Правильно:** после условия — `:`.

!!! warning "Ошибка 2. Забыли отступ"
    ```python
    if x > 0:
    print(x)   # ❌ IndentationError
    ```
    Строка под `if` должна быть с отступом.

!!! warning "Ошибка 3. `=` вместо `==`"
    ```python
    if x = 5:    # ❌ SyntaxError
    ```
    В условии — только `==`.

!!! warning "Ошибка 4. Сравнение строк с числами"
    ```python
    age = "12"       # это строка!
    if age > 10:     # ❌ TypeError
    ```
    `int(input(...))` — не забывайте!

!!! warning "Ошибка 5. Бесполезное условие"
    ```python
    if x > 5:       # x равен 3
        pass        # что-то делаем
    elif x < 5:
        pass
    else:
        pass
    ```
    Если все ветви одинаковы — условие не нужно.

1. ⭐ Спросите у пользователя число. Выведите «положительное», «отрицательное» или «ноль».
2. ⭐ Спросите возраст. Если ≥ 18 — «взрослый», иначе — «ребёнок».
3. ⭐⭐ Спросите три числа. Выведите наибольшее из них (используйте `if`/`elif`/`else`).
