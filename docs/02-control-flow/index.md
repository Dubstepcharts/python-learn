# Управление потоком

Пока наши программы выполнялись строго сверху вниз: одна строка за другой. Но настоящие программы умеют **принимать решения** и **повторять действия**. Этот раздел — про то, как «управлять потоком выполнения».

!!! tip "Как учиться"
    Проходите по порядку. Условия (`if`) — основа, без них циклы будут
    непонятны. После каждого раздела — пробуйте решать упражнения сами,
    не подглядывая в решения.

## 🎯 Что вы сможете после раздела

- Писать условия вида «если … то …, иначе …»
- Повторять действия нужное количество раз
- Проходить по спискам, строкам, диапазонам чисел
- Управлять циклами: выходить досрочно, пропускать шаги
- Решать классические задачи: сумма чисел, поиск максимума, таблица умножения
