# Игровая разработка

Кроме pygame есть **более современные** движки на Python. Они дают 3D, физику, удобный API — и при этом остаются «питонячьими».

| Движок | Особенности |
|---|---|
| **Ursina** | Простой 3D на движке Panda3D |
| **Panda3D** | Полноценный 3D-движок от Disney |
| **Arcade** | 2D, современнее pygame, с OpenGL |

!!! tip "Кому подходит"
    **9–11 класс**, интересуется играми. Нужны: классы, pygame (желательно).
