# Синтаксические ошибки

Python не может «прочитать» вашу программу. Это как опечатка в слове —
компьютер останавливается и не идёт дальше.

**Хорошая новость:** такие ошибки ловятся **до запуска**, сразу при
нажатии Enter/▶.

---

## ❌ `SyntaxError: invalid syntax`

**Что видишь:**

```
  File "app.py", line 3
    print("Привет)
          ^
SyntaxError: unterminated string literal (detected at line 3)
```

или просто:

```
SyntaxError: invalid syntax
```

**Почему:** очень общая ошибка. Причин много — перепутаны скобки, забыты
кавычки, лишний символ.

**Примеры:**

```python
print("Привет)                # ❌ незакрытая кавычка
print(Привет)                 # ❌ нет кавычек вокруг строки
if x = 5:                     # ❌ = вместо ==
for i in range(10)            # ❌ нет двоеточия
    print(i)
```

**Как найти:**

1. Смотрите на `^` под строкой — Python показывает **где именно** не так.
2. Если `^` в конце строки — проблема **в строке выше** (забыли закрыть скобку).
3. Считайте скобки, кавычки.

**Как исправить:**

```python
print("Привет")                # ✅ закрыли кавычку
print("Привет")                # ✅ обернули в кавычки
if x == 5:                     # ✅ сравнение через ==
for i in range(10):            # ✅ добавили двоеточие
    print(i)
```

## ❌ `IndentationError: expected an indented block`

**Что видишь:**

```
  File "app.py", line 3
    print("Привет")
    ^
IndentationError: expected an indented block after 'if' statement on line 2
```

**Почему:** после `if`/`for`/`while`/`def`/`class` нужен **отступ**
(4 пробела). Вы его не поставили.

```python
# ❌ Плохо
if x > 0:
print("Положительное")

# ✅ Хорошо
if x > 0:
    print("Положительное")
```

**Как исправить:**

- В VS Code — поставьте курсор в конец строки с `:` и нажмите Enter.
  **Отступ появится сам**.
- Или выделите блок и нажмите `Tab`.

**Совет:** включите расширение **indent-rainbow** в VS Code — каждый
уровень отступа станет цветным. Сразу видно «съехавшие» строки.

## ❌ `IndentationError: unexpected indent`

**Что видишь:**

```
  File "app.py", line 4
      print("Привет")
      ^
IndentationError: unexpected indent
```

**Почему:** отступ стоит **там, где не нужен**. Например, вне блока
`if`/`for`.

```python
# ❌ Плохо
print("Раз")
    print("Два")        # ← отступ без причины
print("Три")

# ✅ Хорошо
print("Раз")
print("Два")
print("Три")
```

**Как исправить:** убрать лишние пробелы в начале строки.

---

## ❌ `IndentationError: unindent does not match`

**Что видишь:**

```
IndentationError: unindent does not match any outer indentation level
```

**Почему:** «съехали» отступы внутри одного блока. Обычно смешали
**пробелы и табы**.

```
if x > 0:
    print("А")          # 4 пробела
	print("Б")          # таб (визуально — 8 пробелов)
```

**Как исправить:**

1. **Никогда не смешивайте табы и пробелы.**
2. В VS Code: `Ctrl + Shift + P` → `Convert Indentation to Spaces`.
3. Удалите «плохую» строку и введите заново.

---

## ❌ `TabError: inconsistent use of tabs and spaces`

То же самое — смесь табов и пробелов. Python не понимает, что имелось
в виду.

**Как исправить:** `Convert Indentation to Spaces` в VS Code, либо
настроить `"editor.insertSpaces": true` в настройках.

## ❌ `SyntaxError: 'return' outside function`

**Что видишь:**

```
SyntaxError: 'return' outside function
```

**Почему:** `return` написан **вне функции**.

```python
# ❌ Плохо
return 5            # на верхнем уровне файла

# ✅ Хорошо
def get_value():
    return 5

get_value()
```

---

## ❌ `SyntaxError: 'break' outside loop`

**Что видишь:**

```
SyntaxError: 'break' outside loop
```

**Почему:** `break` и `continue` работают **только внутри** `for`/`while`.

```python
# ❌ Плохо
break

# ✅ Хорошо
for i in range(10):
    if i == 5:
        break
```

---

## ❌ `SyntaxError: cannot assign to literal`

**Что видишь:**

```
SyntaxError: cannot assign to literal
```

**Почему:** пытаетесь присвоить значение тому, что не может его хранить.
Например, числу, строке или `True`.

```python
# ❌ Плохо
5 = x
"имя" = "Аня"
True = False

# ✅ Хорошо
x = 5
name = "Аня"
flag = False
```

**Частая причина:** перепутали переменную и значение местами.

```python
# ❌ Плохо
"Аня" = name        # думaли, что это «имя = Аня»

# ✅ Хорошо
name = "Аня"
```

## ❌ `SyntaxError: invalid character '«' (U+00AB)`

**Что видишь:**

```
SyntaxError: invalid character '«' (U+00AB)
```

**Почему:** вставили **русские кавычки** `«»` или `„"` вместо английских
`"` или `'`. Часто это делает редактор Word или где-то скопированный код.

```python
print(«Привет»)            # ❌ русские кавычки
print("Привет")             # ✅ английские
```

**Как исправить:** заменить на прямые кавычки `"` или `'`.

**Совет:** в VS Code настройте: `files.autoGuessEncoding: true` и следите,
чтобы раскладка не подменяла символы.

---

## ❌ `SyntaxError: EOL while scanning string literal`

**Что видишь:**

```
SyntaxError: EOL while scanning string literal
```

**Почему:** строка не закрыта — Python дошёл до конца строки, а кавычки
так и не встретил.

```python
print("Привет             # ❌ нет закрывающей кавычки
print("Привет")              # ✅
```

**Частая причина:** забыли закрыть **многострочную** строку `"""..."""`.

---

## ❌ `SyntaxError: f-string: expecting '}'`

**Что видишь:**

```
SyntaxError: f-string: expecting '}'
```

**Почему:** в f-строке забыли закрыть `{}`.

```python
name = "Аня"
print(f"Привет, {name!")     # ❌
print(f"Привет, {name}!")     # ✅
```

**Частая причина:** случайно поставили кавычку внутри `{}`.

```python
print(f"Привет, {"Аня"}!")    # ❌ вложенные кавычки
print(f"Привет, {'Аня'}!")    # ✅ разные типы кавычек
print(f"Привет, {'Аня'}!")    # ✅ или так
```

## 📌 Как быстро найти синтаксическую ошибку

1. **Читайте номер строки и `^`** — Python показывает место.
2. **Проверьте строку ВЫШЕ** — часто проблема там.
3. **Считайте скобки** — их должно быть поровну.
4. **Проверьте кавычки** — открыта и закрыта.
5. **Сравните с рабочим примером** — что отличается.

**VS Code подсвечивает** синтаксические ошибки красным **сразу**, ещё до
запуска. Смотрите на «полосу проблем» внизу.

## ⚠️ Частые ошибки в этой категории

!!! warning "Запустил не тот файл"
    Если ошибка в файле, который вы **не редактировали**, — проверьте,
    что запускаете именно свой файл: `python app.py`.

!!! warning "Сохранил не тот файл"
    VS Code не запускает несохранённый файл. `Ctrl + S` перед запуском.

!!! warning "Ошибка в середине длинного кода"
    Используйте **комментарии** чтобы «отключить» части кода и найти
    виновника.
