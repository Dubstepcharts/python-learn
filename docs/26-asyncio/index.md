# asyncio — асинхронность

**asyncio** — стандартная библиотека для **асинхронного** программирования. Позволяет выполнять несколько задач «одновременно», не создавая новых потоков.

Это то, что делает современные боты, веб-API, парсеры быстрыми — они не ждут, пока одна операция завершится, а переключаются на другую.

!!! tip "Кому подходит"
    **10–11 класс**. Нужны: функции, генераторы, `async` в общих чертах.

## 🍎 Объясняем просто

!!! example "Официант в кафе"
    **Синхронный код** — один официант: принял заказ → пошёл на кухню →
    ждёт → принёс → пошёл к следующему. Клиенты ждут.
    
    **Асинхронный код** — официант принял заказ, пока повар готовит — пошёл
    к другому столику. Все довольны, все быстро.
    
    `await` — это «я жду, но ты, event loop, займись пока другими делами».

## 📌 Где это нужно

- **Телеграм-боты** (aiogram)
- **Веб-API** (FastAPI, aiohttp)
- **Парсинг** десятков сайтов одновременно
- **Чат-серверы**, WebSocket
- **Работа с БД** (asyncpg, motor)

Для обычных скриптов (обработка файлов, вычисления) asyncio не обязателен.
