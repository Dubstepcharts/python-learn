# Работа с интернетом

Python умеет **общаться с сайтами** — получать данные, отправлять формы, скачивать файлы. Это основа для парсеров, ботов, интеграций с API.

В разделе три инструмента:

| Библиотека | Для чего |
|---|---|
| **requests** | HTTP-запросы: получить/отправить данные |
| **BeautifulSoup** | Разбор HTML: вытащить нужное со страницы |
| **Selenium** | Управление настоящим браузером (для сайтов с JS) |

## ⚠️ Этика и закон

Прежде чем парсить сайт:
- Проверьте **robots.txt** (например, `https://site.com/robots.txt`)
- Читайте **условия использования**
- Делайте паузы между запросами (`time.sleep(1)`)
- Не выдавайте чужой контент за свой
- Уважайте авторские права

Нарушение может привести к блокировке IP или **юридическим последствиям**.
