# pygame — 2D-игры

**pygame** — библиотека для создания **2D-игр** и интерактивных программ: платформеры, аркады, стрелялки, головоломки. Работает поверх SDL, поддерживает звук, спрайты, физику.

На pygame сделаны тысячи игр — от простых учебных до коммерческих проектов.

!!! tip "Кому подходит"
    **8–11 класс**. Нужны: циклы, функции, классы.

## 🎯 Что можно сделать

- **Аркады**: тетрис, змейка, понг
- **Платформеры**: марио-подобные

- **Головоломки**: сапёр, пятнашки, 2048
- **Симуляции**: шарики, частицы, физика

## 🚀 Минимальная игра

```python
import pygame

pygame.init()
screen = pygame.display.set_mode((800, 600))
pygame.display.set_caption("Моя игра")

running = True
while running:
    for event in pygame.event.get():
        if event.type == pygame.QUIT:
            running = False

    screen.fill((30, 30, 30))
    pygame.display.flip()

pygame.quit()
```

Это «пустая» игра — окно, которое можно закрыть. Всё остальное — детали.
