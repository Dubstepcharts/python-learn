# Криптография и безопасность

Программисту важно **защищать** данные: пароли, токены, файлы. Здесь — основы **криптографии** и **безопасной разработки**, которые нужны каждому.

!!! warning "Не изобретайте криптографию"
    Это правило №1. Используйте **проверенные библиотеки**. Своя реализация
    AES почти всегда содержит уязвимости.
