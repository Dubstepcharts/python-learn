## 🍎 Объясняем просто

!!! example "Диалог с компьютером"
    Пока наши программы только «говорили» — выводили текст через `print`.
    Но настоящая программа умеет и **слушать**: спросить у пользователя имя,
    возраст, число — и что-то с этим сделать.
    
    За «слушание» отвечает функция **`input()`**.

---

## 📤 Вывод: `print()`

Уже знакомая функция:

```python
print("Привет!")           # просто текст
print("Возраст:", 12)      # несколько значений через запятую
print("Сумма:", 2 + 3)     # можно считать прямо внутри
```

---

## 📥 Ввод: `input()`

`input()` **останавливает программу** и ждёт, пока пользователь что-то введёт и нажмёт Enter.

```python
name = input("Как тебя зовут? ")
print("Привет, " + name + "!")
```

**Как это работает:**
```
Как тебя зовут? Аня      ← пользователь ввёл «Аня» и нажал Enter
Привет, Аня!
```

- Строка в скобках — **подсказка** для пользователя (её видно на экране)
- То, что ввёл пользователь, попадает в переменную слева от `=`

!!! info "Подробнее: `input()` всегда возвращает строку 🔬"
    Даже если пользователь ввёл `12`, `input()` вернёт **строку** `"12"`.
    
    Если нужно число — обязательно преобразуйте:
    ```python
    age = int(input("Сколько тебе лет? "))
    print(f"Через год тебе будет {age + 1}")
    ```
    
    Без `int(...)` Python выдаст `TypeError` при попытке сложить строку с числом.

## 💡 Примеры

### Пример 1. Знакомство 👋

```python
name = input("Как тебя зовут? ")
city = input("Из какого ты города? ")

print(f"Привет, {name} из города {city}!")
```

### Пример 2. Калькулятор возраста 🎂

```python
age = int(input("Сколько тебе лет? "))
print(f"Через 10 лет тебе будет {age + 10}")
```

### Пример 3. Площадь прямоугольника 📐

```python
width = float(input("Ширина: "))
height = float(input("Высота: "))

area = width * height
print(f"Площадь: {area}")
```

**Пример работы:**
```
Ширина: 4.5
Высота: 2
Площадь: 9.0
```

### Пример 4. Сюжетный — пицца 🍕

```python
price = float(input("Цена одной пиццы: "))
count = int(input("Сколько пицц: "))
discount = 0.1   # 10% скидка

total = price * count * (1 - discount)
print(f"Итог со скидкой: {total:.2f} руб.")
```

!!! tip "Что такое `:.2f`?"
    `{total:.2f}` — «выведи число с двумя знаками после точки».
    Очень удобно для денег: `127.5` → `127.50`.

## 🔄 Полный цикл: спросили — посчитали — показали

```python
# 1. Спрашиваем
a = int(input("Введите первое число: "))
b = int(input("Введите второе число: "))

# 2. Считаем
сумма = a + b
произведение = a * b

# 3. Показываем
print(f"Сумма: {сумма}")
print(f"Произведение: {произведение}")
```

Эта схема — **«ввод → обработка → вывод»** — основа почти любой программы.

## ⚠️ Частые ошибки

!!! warning "Ошибка 1. Забыли `int()`"
    ```python
    age = input("Возраст: ")
    print(age + 1)   # ❌ TypeError: can only concatenate str
    ```
    **Правильно:**
    ```python
    age = int(input("Возраст: "))
    print(age + 1)
    ```

!!! warning "Ошибка 2. Пользователь ввёл не число"
    ```python
    age = int(input("Возраст: "))   # пользователь ввёл «двенадцать»
    ```
    → `ValueError`. Что с этим делать — узнаем в разделе «Исключения».

!!! warning "Ошибка 3. Слишком длинная подсказка"
    Пользователь видит ровно то, что в кавычках. Пишите ясно:
    ```python
    n = int(input("Сколько тебе лет? "))   # ✅
    n = int(input("n: "))                  # ❌ непонятно
    ```

!!! tip "Пробел в конце подсказки"
    Обычно пишут `"Возраст: "` — с пробелом в конце. Тогда курсор окажется
    после двоеточия, а не вплотную к нему.
