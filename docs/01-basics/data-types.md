## 🍎 Объясняем просто

!!! example "В коробках лежит разное"
    В коробку-переменную можно положить **число**, **текст**, **да/нет** —
    в общем, что угодно. Но Python важно знать, **что именно** лежит внутри:
    от этого зависит, что с этим можно делать.
    
    `5 + 3` — сложит числа. `"5" + "3"` — склеит строки и получит `"53"`.

## 📖 Основные типы

В Python, как и в жизни, есть разные «виды» значений. Вот главные:

| Тип | Название | Пример | Зачем |
|---|---|---|---|
| `int` | Целое число | `42`, `-7`, `0` | Считать предметы |
| `float` | Дробное число | `3.14`, `-0.5`, `2.0` | Измерять, делить |
| `str` | Строка (текст) | `"Привет"`, `'42'` | Имена, фразы |
| `bool` | Логическое (да/нет) | `True`, `False` | Проверки |

!!! info "Подробнее: ещё типы 🔬"
    - `list` — список: `[1, 2, 3]`
    - `tuple` — кортеж: `(1, 2, 3)`
    - `dict` — словарь: `{"имя": "Аня", "возраст": 12}`
    - `set` — множество: `{1, 2, 3}`
    - `NoneType` — «ничего»: `None`
    
    Про них будет отдельный большой раздел «Коллекции».

## ✍️ Как узнать тип

Функция `type()` показывает тип значения:

```python
print(type(42))       # <class 'int'>
print(type(3.14))     # <class 'float'>
print(type("Привет")) # <class 'str'>
print(type(True))     # <class 'bool'>
```

**Результат:**
```
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
```

## 💡 Примеры

### Пример 1. Числа (int и float) 🧮

```python
apples = 5          # int
apple_price = 25.5  # float
total = apples * apple_price

print(total)              # 127.5
print(type(total))        # <class 'float'>
```

!!! tip "Когда int превращается в float"
    Если перемножить `int` и `float`, получится `float`. Python автоматически
    расширяет тип, чтобы не потерять дробную часть.

### Пример 2. Строки 🎒

```python
name = "Аня"
hobby = "робототехника"

print(name + " любит " + hobby)
```

**Результат:** `Аня любит робототехника`

Обратите внимание: **строки складываются**, а не суммируются как числа.

### Пример 3. Логический тип — школа 🏫

```python
is_school_day = True
is_weekend = False

print("Сегодня в школу?", is_school_day)   # Сегодня в школу? True
print("Сегодня выходной?", is_weekend)     # Сегодня выходной? False
```

### Пример 4. Сюжетный — космос 🚀

```python
planet = "Марс"                  # str
distance_million_km = 225        # int
flight_time_days = 210.5         # float
has_life = False                 # bool

print(f"Летим на {planet}")
print(f"Расстояние: {distance_million_km} млн км")
print(f"Время: {flight_time_days} дней")
print(f"Есть ли жизнь: {has_life}")
```

**Результат:**
```
Летим на Марс
Расстояние: 225 млн км
Время: 210.5 дней
Есть ли жизнь: False
```

## 🔄 Преобразование типов

Иногда нужно превратить одно в другое:

| Функция | Что делает | Пример |
|---|---|---|
| `int(x)` | В целое число | `int("42")` → `42` |
| `float(x)` | В дробное | `float("3.14")` → `3.14` |
| `str(x)` | В строку | `str(42)` → `"42"` |
| `bool(x)` | В да/нет | `bool(0)` → `False` |

```python
age_text = "12"
age_number = int(age_text)
print(age_number + 1)   # 13 — теперь это число!
```

!!! warning "Ошибка: `int("привет")`"
    ```python
    int("привет")   # ❌ ValueError
    ```
    Из букв число не сделать. А из `"42"` — можно.

!!! info "Подробнее: f-строки 🔬"
    `f"текст {переменная}"` — самый удобный способ вставлять значения в текст.
    Буква `f` перед кавычками включает «форматирование», а `{...}` внутри
    подставляет значение переменной. Работает с любым типом — Python сам
    превратит число в текст, не нужно вручную писать `str()`.

## ⚠️ Частые ошибки

!!! warning "Ошибка 1. Сложение строки и числа"
    ```python
    age = 12
    print("Мне " + age + " лет")   # ❌ TypeError
    ```
    **Правильно:**
    ```python
    print("Мне " + str(age) + " лет")
    print(f"Мне {age} лет")           # ещё лучше
    ```

!!! warning "Ошибка 2. Кавычки меняют тип"
    ```python
    a = 5      # int
    b = "5"    # str
    print(a + b)   # ❌ TypeError
    ```
    `5` и `"5"` — разные вещи! Одно число, другое текст.

!!! warning "Ошибка 3. `True` с большой буквы"
    ```python
    x = true    # ❌ NameError
    ```
    Только `True` и `False`, строго с большой.
