## 🍎 Объясняем просто

!!! example "Оператор — это знак действия"
    `+` значит «сложи», `-` — «вычти», `==` — «сравни». В Python этих
    знаков много, и они делятся на группы: **арифметические** (для чисел),
    **сравнения** (для проверок) и **логические** (для объединения условий).

---

## 🔢 Арифметические операторы

| Оператор | Что делает | Пример | Результат |
|---|---|---|---|
| `+` | Сложение | `7 + 3` | `10` |
| `-` | Вычитание | `7 - 3` | `4` |
| `*` | Умножение | `7 * 3` | `21` |
| `/` | Деление | `7 / 2` | `3.5` |
| `//` | Целое деление | `7 // 2` | `3` |
| `%` | Остаток от деления | `7 % 2` | `1` |
| `**` | Возведение в степень | `2 ** 3` | `8` |

```python
print(7 + 3)    # 10
print(7 / 2)    # 3.5
print(7 // 2)   # 3  (целая часть)
print(7 % 2)    # 1  (остаток)
print(2 ** 10)  # 1024
```

!!! tip "Зачем нужен `%`?"
    Остаток от деления — очень полезная штука:
    - `x % 2 == 0` → число чётное
    - `x % 10` → последняя цифра числа
    - `x % 3 == 0` → делится на 3

## ⚖️ Операторы сравнения

Сравнения возвращают **`True`** или **`False`**:

| Оператор | Значит | Пример | Результат |
|---|---|---|---|
| `==` | Равно | `5 == 5` | `True` |
| `!=` | Не равно | `5 != 3` | `True` |
| `>` | Больше | `5 > 3` | `True` |
| `<` | Меньше | `5 < 3` | `False` |
| `>=` | Больше или равно | `5 >= 5` | `True` |
| `<=` | Меньше или равно | `5 <= 3` | `False` |

!!! warning "Не путайте `=` и `==`"
    - `=` — **присваивание**: `x = 5` (положи в x пятёрку)
    - `==` — **сравнение**: `x == 5` (x равен пятёрке?)

    Это самая частая ошибка новичков!

## 🔗 Логические операторы

Объединяют несколько условий:

| Оператор | Значит | Пример | Результат |
|---|---|---|---|
| `and` | И (оба) | `True and False` | `False` |
| `or` | Или (хотя бы одно) | `True or False` | `True` |
| `not` | Не (отрицание) | `not True` | `False` |

```python
age = 14
has_pass = True

print(age >= 12 and has_pass)   # True — оба условия выполнены
print(age >= 18 or has_pass)    # True — второе выполнено
print(not has_pass)             # False — отрицание True даёт False
```

!!! info "Подробнее: таблицы истинности 🔬"
    **`A and B`** — истина, только если **оба** истинны:
    
    | A | B | A and B |
    |---|---|---|
    | True | True | True |
    | True | False | False |
    | False | True | False |
    | False | False | False |
    
    **`A or B`** — истина, если **хотя бы одно** истинно:
    
    | A | B | A or B |
    |---|---|---|
    | True | True | True |
    | True | False | True |
    | False | True | True |
    | False | False | False |

## 💡 Примеры

### Пример 1. Магазин 🛒

```python
apple_price = 25
count = 4
total = apple_price * count
print(f"К оплате: {total} руб.")
```

**Результат:** `К оплате: 100 руб.`

### Пример 2. Чётное или нет 🎲

```python
number = 42
print(number % 2 == 0)   # True — чётное
```

### Пример 3. Проверка возраста 🎢

```python
age = 12
print(age >= 6 and age <= 14)   # True — подходит для детского билета
```

### Пример 4. Сюжетный — космос 🚀

```python
fuel = 80          # % топлива
crew_ready = True
weather_ok = False

can_launch = fuel > 50 and crew_ready and weather_ok
print("Можно запускать?", can_launch)   # False — погода не лётная
```

## 📌 Приоритет операторов

Python выполняет операции в определённом порядке (как в математике):

1. `**` — степень
2. `*`, `/`, `//`, `%` — умножение и деление
3. `+`, `-` — сложение и вычитание
4. `==`, `!=`, `<`, `>`, `<=`, `>=` — сравнения
5. `not`
6. `and`
7. `or`

**Скобки меняют порядок:**

```python
print(2 + 2 * 2)     # 6
print((2 + 2) * 2)   # 8
```

## ⚠️ Частые ошибки

!!! warning "Ошибка 1. `=` вместо `==`"
    ```python
    if x = 5:      # ❌ SyntaxError
    if x == 5:     # ✅
    ```

!!! warning "Ошибка 2. `and`/`or` со строками"
    ```python
    print("5" + 5)   # ❌ TypeError
    ```
    Складывать строку и число нельзя.

!!! warning "Ошибка 3. Целочисленное деление на 0"
    ```python
    print(5 / 0)     # ❌ ZeroDivisionError
    ```
