## 🍎 Объясняем просто

!!! example "Комментарий — заметка на полях"
    Представь, что ты читаешь книгу и на полях видишь карандашные пометки:
    «здесь важно», «см. страницу 42». Эти пометки не часть текста — их
    написал человек для человека.
    
    В коде комментарии — то же самое. Python их **пропускает** и не выполняет.

---

## 📖 Что такое комментарий

Комментарий — это текст, который:
- Начинается с символа `#`
- Продолжается **до конца строки**
- **Полностью игнорируется** Python

```python
# Это комментарий. Python его не увидит.
print("Привет!")   # А это тоже комментарий — после кода

# Строка ниже закомментирована — она не выполнится:
# print("Этого не будет на экране")
```

**Результат:**
```
Привет!
```

## ✍️ Синтаксис

| Способ | Как выглядит | Когда использовать |
|---|---|---|
| Отдельная строка | `# пояснение` | Объяснить блок кода выше или ниже |
| В конце строки | `x = 5  # пояснение` | Короткая сноска к конкретной строке |
| Многострочный блок | `#` на каждой строке | Временно «выключить» код |

!!! info "Подробнее: многострочные комментарии 🔬"
    В Python **нет** отдельного синтаксиса для многострочных комментариев
    (как `/* */` в C). Но есть два приёма:
    
    **1. Ставить `#` в каждой строке:**
    ```python
    # Это длинный
    # комментарий
    # на несколько строк
    ```
    
    **2. Использовать «докстроку»** — текст в тройных кавычках:
    ```python
    """
    Это тоже считается многострочным текстом,
    но формально — это не комментарий, а строка,
    которую Python создаёт и сразу забывает.
    """
    ```
    
    Докстроки обычно применяют для **документации функций и модулей**.
    Про них — в разделе «Функции».

## 💡 Примеры

### Пример 1. Пояснить сложную формулу 🧮

```python
# Площадь круга: π * r²
radius = 5
area = 3.14159 * radius ** 2
print(area)
```

### Пример 2. Разметить блоки кода 🏗️

```python
# --- Ввод ---
name = input("Имя: ")
age = int(input("Возраст: "))

# --- Обработка ---
next_year = age + 1

# --- Вывод ---
print(f"{name}, через год тебе будет {next_year}")
```

### Пример 3. Временно «выключить» код 🔇

```python
print("Раз")
print("Два")
# print("Три")      # ← не выполнится
print("Четыре")
```

**Результат:**
```
Раз
Два
Четыре
```

Очень удобно при отладке — не нужно удалять строку, просто ставите `#`.

### Пример 4. Пометить «сделать позже» 📌

```python
# TODO: добавить проверку на отрицательные числа
def calculate(x):
    return x * 2
```

!!! tip "Соглашения в команде"
    Часто используют специальные пометки:
    - `# TODO:` — что-то надо сделать
    - `# FIXME:` — здесь баг, надо починить
    - `# NOTE:` — важное замечание
    
    В больших проектах такие пометки ищут автоматически.

## 🤔 Когда комментарии полезны, а когда — нет

**Полезно:**
- Объяснить **зачем**, а не **что** (что — видно из кода)
- Пояснить неочевидную формулу, «магическое» число
- Оставить заметку на будущее
- Временно отключить код

**Не полезно:**
```python
x = 5   # присваиваем x значение 5   ← и так видно
y = x + 1  # прибавляем 1 к x        ← тоже очевидно
```

!!! warning "Правило хорошего тона"
    Хороший код понятен **без** комментариев. Комментарий нужен только там,
    где логика не очевидна. Не превращайте код в «пересказ самого себя».

**Плохо:**
```python
# Увеличиваем счётчик на 1
counter = counter + 1
```

**Хорошо:**
```python
# Счётчик копий: увеличиваем на каждое сохранение
counter = counter + 1
```

## ⚠️ Частые ошибки

!!! warning "Ошибка 1. `#` внутри строки"
    ```python
    print("Цена: #500")    # ✅ это просто текст, # тут не работает
    ```
    Внутри кавычек `#` — обычный символ.

!!! warning "Ошибка 2. `#` съедает код"
    ```python
    x = 5  # комментарий с числом 42 в тексте
    ```
    Всё после `#` — комментарий, включая упоминания чисел. Это безопасно,
    но иногда новичок думает, что код «увидит» то, что написано в комментарии.
    Нет — комментарий целиком игнорируется.

!!! warning "Ошибка 3. Забыли закрыть докстроку"
    ```python
    """
    Начал писать и забыл закрыть...
    print("не выполнится никогда")
    ```
    Python будет ждать закрывающие `"""` и выдаст `SyntaxError` в конце файла.

## 🧪 Упражнения

1. ⭐ Добавьте комментарий в свою программу «Hello, World», объясняющий, что она делает.
2. ⭐ «Закомментируйте» одну из строк своей программы и убедитесь, что она не выполняется.
3. ⭐⭐ Напишите программу из 3–4 строк с комментариями, которые объясняют **зачем**, а не **что**.
4. ⭐⭐ Добавьте в код пометку `# TODO:` с идеей, что улучшить.
5. ⭐⭐⭐ Возьмите свою прошлую программу и добавьте комментарии-«шапки»: `# --- Ввод ---`, `# --- Обработка ---`, `# --- Вывод ---`.
