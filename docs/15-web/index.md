# Веб-разработка

**Веб-фреймворк** — библиотека, которая помогает создавать сайты и веб-API на Python: принимать запросы, отдавать страницы, обрабатывать формы.

В Python три главных фреймворка, и все три мы разберём:

| Фреймворк | Для чего | Сложность |
|---|---|---|
| **Flask** | Небольшие сайты, API, прототипы | ⭐ |
| **FastAPI** | Быстрые современные API, асинхронность | ⭐⭐ |
| **Django** | Большие сайты «под ключ»: блог, магазин, соцсеть | ⭐⭐⭐ |
