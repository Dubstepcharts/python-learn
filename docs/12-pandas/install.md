# Установка pandas

!!! abstract "Уровень: ⭐"

---

## 🚀 Установка

```bash
pip install pandas
```

С графиками (рекомендуется):

```bash
pip install pandas matplotlib
```

С Excel:

```bash
pip install pandas openpyxl
```

Проверка:

```python
import pandas as pd
print(pd.__version__)     # например, 2.2.0
```

---

## 📌 Соглашение

Почти весь мир импортирует pandas как `pd`:

```python
import pandas as pd
```

Так же и мы будем.
