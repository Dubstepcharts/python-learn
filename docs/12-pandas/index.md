# pandas — работа с данными

`pandas` — библиотека для работы с **табличными данными**: как Excel, но в коде. Читает CSV, Excel, JSON, SQL; фильтрует, группирует, объединяет; считает статистику и строит графики.

Применяется в анализе данных, машинном обучении, научных исследованиях, отчётах.

!!! tip "Кому подходит"
    **9–11 класс**. Нужны знания: [списки](../04-collections/lists.md), [словари](../04-collections/dicts.md), [файлы](../06-files-errors/files.md).
