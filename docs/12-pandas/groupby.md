## 🍎 Объясняем просто

!!! example "groupby — как «сложить по группам»"
    Раздели данные на группы по какому-то признаку (класс, город, категория)
    и посчитай что-то для каждой группы: сумму, среднее, количество.

    ```python
    df.groupby("класс")["оценка"].mean()
    ```

    «Сгруппируй по классу и посчитай среднюю оценку».

---

## 📖 Паттерн «split — apply — combine»

1. **Split** — разделить на группы по ключу
2. **Apply** — применить функцию к каждой группе
3. **Combine** — собрать результаты

pandas делает это одной командой.

## 📖 Основы

```python
import pandas as pd

df = pd.DataFrame({
    "класс": ["7А", "7А", "7Б", "7Б", "7А", "7Б"],
    "ученик": ["Аня", "Борис", "Вика", "Глеб", "Даша", "Егор"],
    "оценка": [5, 4, 5, 3, 5, 4],
})

# Средняя оценка по классам
print(df.groupby("класс")["оценка"].mean())
# класс
# 7А    4.67
# 7Б    4.00
# Name: оценка, dtype: float64
```

### Группировка по нескольким колонкам

```python
df.groupby(["класс", "пол"])["оценка"].mean()
```

### Группировка целого DataFrame

```python
df.groupby("класс").mean(numeric_only=True)   # усредняет все числовые колонки
```

## 📖 Все виды агрегации

| Метод | Что считает |
|---|---|
| `.sum()` | Сумма |
| `.mean()` | Среднее |
| `.median()` | Медиана |
| `.min()`, `.max()` | Мин/макс |
| `.count()` | Количество (не-NaN) |
| `.size()` | Количество (включая NaN) |
| `.std()`, `.var()` | σ и дисперсия |
| `.first()`, `.last()` | Первое / последнее |
| `.nunique()` | Сколько уникальных |
| `.describe()` | Сводка |
| `.quantile(q)` | Квантиль |
| `.agg(...)` | Любая из выше + своя |

### `agg` — несколько агрегаций сразу

```python
df.groupby("класс")["оценка"].agg(["mean", "min", "max", "count"])
```

### Разные функции для разных колонок

```python
df.groupby("класс").agg({
    "оценка": ["mean", "max"],
    "ученик": "count",
})
```

### Свои функции

```python
df.groupby("класс")["оценка"].agg(lambda x: x.max() - x.min())
df.groupby("класс")["оценка"].agg(разброс="std", среднее="mean")
```

## 📖 `transform` и `filter`

### `transform`

Возвращает результат **той же формы**, что и исходный DataFrame:

```python
df["среднее_класса"] = df.groupby("класс")["оценка"].transform("mean")
```

Добавляет колонку со средним по группе для каждой строки.

### `filter`

Оставляет **только целые группы**, прошедшие проверку:

```python
df.groupby("класс").filter(lambda g: g["оценка"].mean() >= 4.5)
```

Оставит только строки классов со средним ≥ 4.5.

## 📖 Объединение таблиц: `merge`

Как SQL JOIN:

```python
students = pd.DataFrame({"id": [1, 2, 3], "имя": ["Аня", "Борис", "Вика"]})
grades = pd.DataFrame({"id": [1, 2, 4], "оценка": [5, 4, 5]})

merged = students.merge(grades, on="id", how="inner")
```

**Типы join:**

| `how` | Что оставляет |
|---|---|
| `"inner"` | Только совпадающие (по умолчанию) |
| `"left"` | Все из левого |
| `"right"` | Все из правого |
| `"outer"` | Все из обоих |

### `concat` — склеивание

```python
# Вертикально (по строкам)
pd.concat([df1, df2], ignore_index=True)

# Горизонтально (по колонкам)
pd.concat([df1, df2], axis=1)
```

## 💡 Примеры

### Пример 1. Продажи по магазинам 🏪

```python
sales = pd.DataFrame({
    "магазин": ["А", "Б", "А", "Б", "А", "Б"],
    "товар": ["хлеб", "хлеб", "сыр", "сыр", "хлеб", "молоко"],
    "сумма": [100, 120, 300, 250, 90, 80],
})

print(sales.groupby("магазин")["сумма"].sum())
print(sales.groupby("товар")["сумма"].agg(["sum", "mean", "count"]))
```

### Пример 2. Сюжетный — школьный журнал 📓

```python
grades = pd.DataFrame({
    "класс": ["7А", "7А", "7Б", "7Б", "7А"],
    "ученик": ["Аня", "Борис", "Вика", "Глеб", "Даша"],
    "математика": [5, 4, 5, 3, 5],
    "русский": [4, 4, 5, 3, 4],
})

# Средние оценки по классу
print(grades.groupby("класс")[["математика", "русский"]].mean())

# Добавить колонку «средний» по классу
grades["средний_по_классу"] = grades.groupby("класс")["математика"].transform("mean")
print(grades)
```

### Пример 3. Объединение таблиц 🔗

```python
users = pd.DataFrame({
    "user_id": [1, 2, 3],
    "имя": ["Аня", "Борис", "Вика"],
})
orders = pd.DataFrame({
    "user_id": [1, 1, 2, 3, 3, 3],
    "сумма": [500, 300, 200, 100, 400, 600],
})

merged = users.merge(orders, on="user_id")
print(merged.groupby("имя")["сумма"].sum())
```

### Пример 4. Сводная таблица 📊

```python
pivot = sales.pivot_table(
    index="магазин",
    columns="товар",
    values="сумма",
    aggfunc="sum",
    fill_value=0,
)
print(pivot)
```

## ⚠️ Частые ошибки

!!! warning "Ошибка 1. `groupby` + обращение по имени"
    ```python
    df.groupby("класс").оценка.mean()       # работает
    df.groupby("класс")["оценка"].mean()    # ✅ универсально
    ```

!!! warning "Ошибка 2. `mean()` на строках"
    ```python
    df.groupby("класс").mean()             # ❌ может упасть
    df.groupby("класс").mean(numeric_only=True)  # ✅
    ```

!!! warning "Ошибка 3. `transform` vs `agg`"
    - `agg` — результат на группу
    - `transform` — результат на **каждую строку**
    Перепутаете — не получится добавить колонку.

!!! warning "Ошибка 4. `merge` без `on`"
    Если колонки называются по-разному:
    ```python
    left.merge(right, left_on="id", right_on="user_id")
    ```

!!! warning "Ошибка 5. Забыли `reset_index()` после groupby"
    ```python
    result = df.groupby("класс").mean().reset_index()
    ```
