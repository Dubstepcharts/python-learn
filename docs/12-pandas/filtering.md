## 🍎 Объясняем просто

!!! example "Фильтр — это «оставить только нужные строки»"
    Как в Excel: «показать только тех, у кого оценка ≥ 4». В pandas это
    делается булевой **маской** — колонкой из `True`/`False`.

    ```python
    df[df["оценка"] >= 4]
    ```

---

## 📖 Булевы маски

```python
import pandas as pd

df = pd.DataFrame({
    "имя": ["Аня", "Борис", "Вика", "Глеб"],
    "возраст": [12, 11, 13, 10],
    "оценка": [5, 4, 5, 3],
})

# Одна маска
df[df["оценка"] >= 4]

# Читается: df["оценка"] >= 4 → [True, True, True, False]
# df[...] оставляет только True-строки
```

### Операторы

| Оператор | Значит |
|---|---|
| `==` | Равно |
| `!=` | Не равно |
| `>` `<` `>=` `<=` | Больше/меньше |
| `&` | И (скобки обязательны!) |
| `\|` | Или |
| `~` | Не |

!!! warning "Скобки обязательны"
    ```python
    df[(df["a"] > 0) & (df["b"] < 10)]   # ✅
    df[df["a"] > 0 & df["b"] < 10]        # ❌ SyntaxError
    ```

### Комбинирование

```python
df[(df["возраст"] > 10) & (df["оценка"] == 5)]
df[(df["возраст"] < 11) | (df["оценка"] > 4)]
df[~(df["оценка"] == 3)]              # не тройка
```

### `isin`, `between`

```python
df[df["имя"].isin(["Аня", "Вика"])]          # в списке
df[df["возраст"].between(11, 13)]            # в диапазоне
df[df["имя"].str.contains("а")]              # содержит букву
df[df["имя"].str.startswith("А")]            # начинается
```

## 📖 `.loc` и `.iloc` для срезов

```python
# .loc — по метке
df.loc[df["возраст"] > 11, ["имя", "оценка"]]
df.loc[0:2, "имя":"оценка"]

# .iloc — по позиции
df.iloc[0:2, 0:2]
df.iloc[:, [0, 2]]        # все строки, колонки 0 и 2
```

### Изменение через `.loc`

```python
df.loc[df["оценка"] < 4, "оценка"] = 4     # поднять всем троечникам до 4
```

---

## 📖 `.query()` — SQL-подобный синтаксис

```python
df.query("возраст > 11 and оценка == 5")
df.query("имя in ['Аня', 'Вика']")
df.query("возраст > @min_age")               # @ — переменная из Python
```

Сравните:

```python
df[(df["возраст"] > 11) & (df["оценка"] == 5)]   # обычный
df.query("возраст > 11 and оценка == 5")         # читается лучше
```

## 📖 Сортировка и срез

```python
df.sort_values("возраст")                       # по возрастанию
df.sort_values("возраст", ascending=False)      # по убыванию
df.sort_values(["оценка", "возраст"], ascending=[False, True])

df.nlargest(2, "оценка")                        # 2 лучших
df.nsmallest(2, "возраст")                      # 2 младших

df.head(2)                                      # первые 2
df.sample(2)                                    # 2 случайных
df.sample(frac=0.5)                             # 50% случайных
```

## 📖 Работа с дубликатами

```python
df.duplicated()                       # какие строки — дубликаты
df.drop_duplicates()                  # удалить полные дубликаты
df.drop_duplicates(subset=["имя"])    # дубликаты по колонке
df.drop_duplicates(keep="last")       # оставить последний
```

## 💡 Примеры

### Пример 1. Отличники 🏅

```python
df = pd.DataFrame({
    "имя": ["Аня", "Борис", "Вика", "Глеб", "Даша"],
    "оценка": [5, 4, 5, 3, 5],
    "возраст": [12, 11, 13, 10, 12],
})

отличники = df[df["оценка"] == 5]
print(отличники)
```

### Пример 2. Молодые с хорошими оценками 🎯

```python
young_and_good = df[(df["возраст"] <= 12) & (df["оценка"] >= 4)]
print(young_and_good)
```

### Пример 3. Сюжетный — магазин 🛒

```python
products = pd.DataFrame({
    "товар": ["хлеб", "молоко", "сыр", "колбаса", "масло"],
    "цена": [40, 80, 350, 280, 150],
    "категория": ["хлеб", "молочное", "молочное", "мясное", "молочное"],
})

# Товары до 200 руб
cheap = products.query("цена < 200")
print(cheap)

# Молочное или дешевле 100
milk_or_cheap = products[(products["категория"] == "молочное") | (products["цена"] < 100)]
print(milk_or_cheap)
```

### Пример 4. Изменение через маску ✏️

```python
products.loc[products["цена"] > 300, "премиум"] = True
products["премиум"] = products["премиум"].fillna(False)
print(products)
```

### Пример 5. Поиск по строке 🔍

```python
df[df["имя"].str.contains("и", case=False)]
df[df["имя"].str.startswith("А")]
df[df["имя"].str.len() > 4]
```

## ⚠️ Частые ошибки

!!! warning "Ошибка 1. `and` / `or` вместо `&` / `|`"
    ```python
    df[(df["a"] > 0) and (df["b"] < 5)]   # ❌
    df[(df["a"] > 0) & (df["b"] < 5)]     # ✅
    ```

!!! warning "Ошибка 2. Забыли скобки"
    ```python
    df[df["a"] > 0 & df["b"] < 5]     # ❌ приоритет не тот
    ```

!!! warning "Ошибка 3. `df[df["a"] > 0] = 0`"
    Заменяет **все** колонки. Для одной колонки — `.loc`:
    ```python
    df.loc[df["a"] > 0, "b"] = 0
    ```

!!! warning "Ошибка 4. `SettingWithCopyWarning`"
    ```python
    subset = df[df["a"] > 0]
    subset["b"] = 10                 # ⚠️ может не повлиять на df
    ```
    **Решение:** `subset = df[df["a"] > 0].copy()`.

!!! warning "Ошибка 5. Фильтрация по отсутствующей колонке"
    ```python
    df[df["сумма"] > 0]     # ❌ KeyError, если нет колонки
    ```
    Проверьте `df.columns`.
