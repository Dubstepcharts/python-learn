# Этика и закон скрапинга

!!! warning "Это не юридическая консультация"
    Законы различаются по странам. Если вы делаете коммерческий скрапинг —
    консультируйтесь с юристом.

---

## 📌 Три правила вежливого парсера

1. **Соблюдайте `robots.txt`**
2. **Делайте паузы** между запросами
3. **Не перегружайте сервер**

---

## 📌 `robots.txt`

Файл `https://site.com/robots.txt` говорит, что можно и нельзя парсить.

**Пример:**
```
User-agent: *
Disallow: /admin/
Disallow: /private/
Allow: /
Crawl-delay: 2

User-agent: BadBot
Disallow: /
```

**Как проверить в Python:**

```python
from urllib.robotparser import RobotFileParser

rp = RobotFileParser()
rp.set_url("https://example.com/robots.txt")
rp.read()

url = "https://example.com/page"
print(rp.can_fetch("*", url))          # True / False
print(rp.crawl_delay("*"))              # рекомендуется пауза
```

**Соблюдайте.** Нарушение — как игнорировать знак «кирпич».

## 📌 Авторские права

**Факты не защищены**, но их **подборка** — может быть.

| Можно | Нельзя |
|---|---|
| Парсить публичные страницы | Копировать тексты целиком и выдавать за свои |
| Собирать факты, цены | Копировать фотографии без разрешения |
| Анализировать данные | Обходить платный доступ |
| Ссылаться на источник | Выдавать чужие данные за свои |

**Правило:** ссылка на источник — обязательна. Контент — переработать,
а не копировать.

## 📌 Персональные данные

В России — **152-ФЗ**. В Европе — **GDPR**. В США — законы штатов.

**Что считается персональными данными:**
- Имя + телефон/email
- Адрес
- Паспортные данные
- Фото
- IP-адрес (в некоторых юрисдикциях)

**Нельзя** собирать персональные данные без согласия. Нельзя хранить,
если не нужно. Нельзя передавать третьим лицам.

Даже если данные **публичны** — это не значит, что их можно **собирать
и хранить** массово.

## 📌 Terms of Service (ToS)

На каждом сайте есть «Условия использования». Часто там **прямо запрещён**
скрапинг. Нарушение ToS — не уголовное, но:
- вас могут забанить
- могут подать в суд (**гражданский иск**)
- в отдельных случаях — уголовная ответственность

**Проверьте ToS** перед крупным проектом.

## 📌 Rate limiting — вежливые паузы

**Не долбите сервер.** Даже если не запрещено — некрасиво и чревато
баном.

```python
import time
import random

for url in urls:
    response = requests.get(url)
    process(response)
    time.sleep(random.uniform(1, 3))     # пауза 1–3 секунды
```

**Нормы:**
- 1 запрос в 1–3 секунды — вежливо
- 10+ в секунду — почти всегда бан
- Асинхронный парсер — обязательно ограничивайте `Semaphore`

## 📌 Кеширование

Один раз скачали — не качайте второй.

```python
from pathlib import Path
import requests, hashlib

CACHE = Path("cache")
CACHE.mkdir(exist_ok=True)

def fetch_cached(url):
    key = hashlib.md5(url.encode()).hexdigest()
    path = CACHE / key
    if path.exists():
        return path.read_text(encoding="utf-8")

    r = requests.get(url, timeout=10)
    r.raise_for_status()
    path.write_text(r.text, encoding="utf-8")
    return r.text
```

Экономит время, трафик и вежлив к серверу.

## 📌 Свой User-Agent

Стандартный `python-requests/2.x` легко блокируется. Многие сайты
**ожидают настоящего UA**.

```python
headers = {
    "User-Agent": (
        "Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
        "AppleWebKit/537.36 (KHTML, like Gecko) "
        "Chrome/120.0.0.0 Safari/537.36"
    )
}
```

**Но!** Не притворяйтесь браузером, чтобы **скрыть** парсер — это уже
неэтично. Указывайте `User-Agent` честно: `MyBot/1.0 (+https://mysite.ru/bot)`.

---

## 📌 Что делать, если заблокировали

1. **Проверьте причину** — возможно, вы слишком частые запросы
2. **Уменьшите частоту**
3. **Почините парсер**, чтобы не долбить несуществующие страницы
4. **Кешируйте**
5. **Свяжитесь с владельцем сайта** — может, есть API
6. Только **после** — прокси и обход (и то, если это не ToS-нарушение)

---

## 📌 Как правильно

1. **Проверьте `robots.txt`**
2. **Прочитайте ToS**
3. **Узнайте, нет ли официального API** (обычно есть!)
4. **Делайте паузы**
5. **Кешируйте**
6. **Соблюдайте авторские права**
7. **Не собирайте персональные данные**
8. **Указывайте источник**

Если сомневаетесь — **спросите разрешения у владельца**. Одно письмо
может сэкономить месяцы суда.

## ⚠️ Частые ошибки

!!! warning "«Это же публично, значит, можно»"
    Публичный доступ ≠ разрешение на массовый сбор и хранение.

!!! warning "Игнорирование `robots.txt`"
    Прямая демонстрация неуважения. Лог сервера всё видит.

!!! warning "DDoS-эффект"
    Многопоточный парсер без ограничений = атака. Забанят и предъявят.

!!! warning "Копирование контента"
    Переписывайте своими словами. Ссылайтесь на источник. Не используйте
    чужие фото.
