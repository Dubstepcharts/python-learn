# Git — подробно

**Git** — система контроля версий. Это **самый важный инструмент** программиста после самого языка. Без Git не бывает ни одного проекта.

Вы уже использовали базовые команды (`git add`, `commit`, `push`). Здесь — **полный разбор**: ветки, слияния, конфликты, откаты, работа в команде.

!!! tip "Кому подходит"
    **8–11 класс**. Нужно знать: базовые команды Git (мы их использовали при деплое сайта).
