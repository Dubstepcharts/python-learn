# Работа с данными / ETL

**ETL** = **E**xtract, **T**ransform, **L**oad. Это «конвейер данных»: собрать из источников → преобразовать → положить в хранилище.

Это то, чем занимаются **data-инженеры** — одна из самых востребованных профессий в IT.

## 📌 Примеры реальных задач

- Собрать погоду за год → посчитать климат → загрузить в БД
- Скачать сайты → распарсить цены → сравнить → уведомить
- Выгрузить из 1С → преобразовать → залить в дашборд
- Собирать логи серверов → агрегировать → хранить
