# Нейросети с нуля

!!! abstract "Уровень: ⭐⭐⭐"
    Нужно знать: [NumPy](../16-numpy/index.md).

---

## 🍎 Объясняем просто

!!! example "Нейрон — как маленький решатель"
    Один **нейрон** берёт числа, умножает каждое на свой **вес**, складывает,
    добавляет **смещение** и пропускает через **функцию активации**.
    
    ```
    вход → ×w₁, ×w₂, ... → сумма + b → активация → выход
    ```
    
    **Нейросеть** — много нейронов, соединённых в слои.
    
    **Обучение** — подбор весов так, чтобы на выходе получалось правильно.

---

## 📖 Из чего состоит нейросеть

**Слой** — набор нейронов. Бывают:
- **Входной** (input) — принимает данные
- **Скрытые** (hidden) — преображают
- **Выходной** (output) — даёт ответ

```
Вход → [Слой 1] → [Слой 2] → Выход
  4      8 нейронов  3 класса
```

**Полносвязная сеть (MLP)** — каждый нейрон слоя связан со всеми нейронами предыдущего.

---

## 📖 Функции активации

Без активации сеть — просто линейное преобразование (что сводится к одной
матрице). Активация добавляет **нелинейность** — и сеть может «учить» сложные
зависимости.

| Функция | Формула | Где |
|---|---|---|
| ReLU | max(0, x) | Скрытые слои (по умолчанию) |
| Sigmoid | 1/(1+e⁻ˣ) | Бинарная классификация |
| Tanh | (eˣ−e⁻ˣ)/(eˣ+e⁻ˣ) | Скрытые слои (устаревает) |
| Softmax | eˣᵢ/Σeˣⱼ | Мультиклассификация |
| Leaky ReLU | x если x>0, иначе 0.01x | Защита от «мёртвых» нейронов |

**Правило:** в скрытых слоях — **ReLU**, на выходе — **sigmoid** или **softmax**.

---

## 📖 Как обучается сеть

1. **Forward pass** — данные проходят через сеть, получаем предсказание
2. **Loss** — сравниваем с правильным ответом, считаем ошибку
3. **Backward pass** — по правилу цепочки считаем градиенты (влияние весов на ошибку)
4. **Optimizer step** — обновляем веса в сторону уменьшения ошибки

Повторяем на батчах.

## 📌 Реализация с нуля

Один нейрон, регрессия:

```python
import numpy as np

# Данные: y = 2x + 3
X = np.random.randn(100, 1)
y = 2 * X + 3 + np.random.randn(100, 1) * 0.1

w = np.random.randn(1, 1)
b = np.zeros(1)
lr = 0.01

for epoch in range(1000):
    # Forward
    y_pred = X @ w + b

    # Loss (MSE)
    loss = ((y_pred - y) ** 2).mean()

    # Backward
    grad_w = 2 * (X.T @ (y_pred - y)) / len(X)
    grad_b = 2 * (y_pred - y).mean()

    # Update
    w -= lr * grad_w
    b -= lr * grad_b

print(f"w = {w[0,0]:.3f}, b = {b[0]:.3f}")   # ~2.0, ~3.0
```

Это **вся суть** нейросетей. Реальные сети — то же самое, но слоёв много.

## ⚠️ Частые ошибки

!!! warning "Забыли нормализовать данные"
    Нейросети плохо учатся на «сырых» данных. Масштабируйте признаки.

!!! warning "Слишком большой learning rate"
    Loss «прыгает», расходится. Уменьшайте: 1e-2, 1e-3, 1e-4.

!!! warning "Мало данных, большая сеть"
    Переобучение. Добавьте dropout, регуляризацию, аугментацию.

!!! warning "Нет валидации"
    Смотрите не только на train loss — она может падать, а модель ухудшаться.
