# Продвинутое машинное обучение

После классических моделей (sklearn) — **нейронные сети**. Они дают лучшие
результаты в задачах, где данные «сложные»: изображения, текст, звук.

В разделе — два фреймворка:

| Фреймворк | Особенности |
|---|---|
| **PyTorch** | Гибкий, любимый исследователями |
| **TensorFlow / Keras** | Промышленный, есть готовые модели |

!!! tip "Кому подходит"
    **11 класс**, интерес к ML, олимпиады по ИИ. Нужны: NumPy, sklearn, немного математики.
