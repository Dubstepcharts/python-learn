# Старт

Прежде чем писать код, нужно подготовить «рабочее место»: установить Python и редактор, написать первую программу. Это займёт 15–20 минут — один раз и навсегда.

!!! tip "Для кого этот раздел"
    Для всех, кто только начинает. Если Python уже установлен — можно сразу
    к [первой программе](first-program.md).

---

## 📚 Что в разделе

| Страница | Что узнаете |
|---|---|
| [Установка Python](install.md) | Скачать и установить Python на Windows / macOS / Linux |
| [Редактор кода](ide.md) | Thonny, VS Code или PyCharm — что выбрать |
| [Первая программа](first-program.md) | `print`, кавычки, комментарии |

**Порядок такой:**

1. Сначала **установите Python** — это «движок», который выполняет ваши программы.
2. Потом **выберите редактор** — где удобно писать код.
3. Затем **напишите первую программу** — и почувствуйте, как это работает.

## 🤔 Частые вопросы новичков

!!! question "Мне 10 лет — я справлюсь?"
    Да. Установка Python простая, а в разделе [Редактор кода](ide.md)
    для 5–7 класса рекомендуем **Thonny** — он специально сделан для
    начинающих: одна кнопка ▶ — и код запущен.

!!! question "У меня старый компьютер. Python потянет?"
    Да. Python работает даже на слабых машинах. Ему хватит 100 МБ на
    диске и любого процессора из последних 15 лет.

!!! question "Можно учиться без установки?"
    Можно — в онлайн-редакторах вроде **Replit** или **Google Colab**
    (см. [Редактор кода](ide.md#-онлайн-варианты-если-не-хочется-ставить)).
    Но для серьёзной работы лучше поставить всё локально.

!!! question "С чего начать — Windows, macOS или Linux?"
    Разницы нет — Python одинаковый везде. Выбирайте инструкцию под свою
    систему в разделе [Установка Python](install.md).

## ⚠️ Не пропускайте шаги

Иногда хочется сразу писать код. Но если Python не установлен — программа
не запустится. Уделите 15 минут установке — потом всё пойдёт быстро.
