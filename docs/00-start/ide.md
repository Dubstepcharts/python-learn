# Редактор кода

!!! abstract "Уровень: ⭐ Начальный"
    Подойдёт для всех. Нужно знать: [установку Python](install.md).

---

## 🍎 Объясняем просто

!!! example "Редактор — это «тетрадка для кода»"
    Программу можно писать даже в Блокноте. Но в настоящем редакторе удобнее:
    подсветка синтаксиса (как разноцветные ручки), подсказки, автодополнение,
    возможность запустить код одной кнопкой.

    Есть три хороших варианта — выберите один.

---

## 🏆 Сравнение

| Редактор | Кому | Плюсы | Минусы |
|---|---|---|---|
| **Thonny** | 5–7 класс | Простой, Python «внутри», русский интерфейс | Меньше возможностей |
| **VS Code** | 7–11 класс | Универсальный, все расширения, стандарт индустрии | Нужно чуть настроить |
| **PyCharm Community** | 9–11 класс | Мощный, специально под Python | Тяжелее, дольше запускается |

Для большинства — **VS Code**. Для самых младших — **Thonny**.

## 🐣 Вариант A. Thonny (для 5–7 класса)

### Почему Thonny

- Устанавливается как обычная программа
- **Python уже внутри** — отдельно ставить не нужно
- Простой интерфейс: одна кнопка ▶ — и код запущен
- Есть русский язык
- Показывает переменные прямо во время выполнения

### Установка

1. Откройте **https://thonny.org/**
2. Нажмите **Download** для своей системы (Windows / macOS / Linux)
3. Запустите установщик, жмите «Далее» до конца
4. Откройте Thonny — увидите редактор и **Shell** (окно вывода) снизу

### Первая программа

1. В верхнем поле напишите:

   ```python
   print("Привет, мир!")
   ```

2. Сохраните: **Файл → Сохранить как** → назовите `hello.py`
3. Нажмите **▶ Run** (или `F5`) — внизу появится `Привет, мир!`

Всё. Thonny готов.

!!! tip "Полезные горячие клавиши Thonny"
    - `F5` — запустить
    - `Ctrl + S` — сохранить
    - `Ctrl + N` — новый файл

## 💻 Вариант B. VS Code (рекомендую с 7 класса)

### Почему VS Code

- Один редактор для **всех** языков — пригодится и дальше
- Огромное количество расширений
- Стандарт в реальной работе
- Бесплатный, от Microsoft

### Установка

1. Откройте **https://code.visualstudio.com/**
2. Нажмите **Download** для своей системы
3. Установите, все галочки по умолчанию подходят
4. Откройте VS Code

### Установка расширения Python

1. Слева нажмите на иконку **Extensions** (четыре квадратика) — или `Ctrl + Shift + X`
2. В поиске введите `Python`
3. Найдите расширение **Python** от Microsoft
4. Нажмите **Install**
5. Дождитесь установки

### Выбор интерпретатора Python

1. Нажмите `Ctrl + Shift + P` — откроется «палитра команд»
2. Введите `Python: Select Interpreter`
3. Выберите из списка свой Python (например, `Python 3.12.x`)

Если пусто — значит Python не установлен. См. [Установку Python](install.md).

### Первая программа в VS Code

1. **Файл → Новая папка проекта** — создайте где-нибудь папку `python-projects`
2. В VS Code: **Файл → Открыть папку** → выберите эту папку
3. Создайте файл `hello.py`:
   - Наведите на панель слева → правый клик → **New File** → назовите `hello.py`
4. Напишите:

   ```python
   print("Привет, мир!")
   ```

5. Сохраните `Ctrl + S`
6. Откройте терминал: **Terminal → New Terminal** (или `Ctrl + ~`)
7. Введите:

   ```bash
   python hello.py
   ```

   Должно вывести `Привет, мир!`.

### Полезные расширения (по желанию)

| Расширение | Для чего |
|---|---|
| **Python** (Microsoft) | Обязательное |
| **Pylance** | Умные подсказки |
| **Russian Language Pack** | Русский интерфейс |
| **Material Icon Theme** | Красивые иконки файлов |
| **indent-rainbow** | Цветные отступы (наглядно!) |

!!! tip "Почему `indent-rainbow` — для школьников"
    Python чувствителен к отступам. Расширение делает каждый уровень
    цветным — сразу видно, где съехало.

### Горячие клавиши VS Code

| Комбинация | Что делает |
|---|---|
| `Ctrl + ~` | Открыть/закрыть терминал |
| `Ctrl + S` | Сохранить |
| `Ctrl + /` | Закомментировать строку |
| `Ctrl + Shift + P` | Палитра команд |
| `Ctrl + D` | Выделить следующее такое же слово |
| `Alt + ↑ / ↓` | Переместить строку |
| `Shift + Alt + ↓` | Дублировать строку |

## 🧠 Вариант C. PyCharm Community (для продвинутых)

### Почему PyCharm

- Специально создан под Python
- Очень умные подсказки и рефакторинг
- Отладчик, тесты, интеграция с базами данных — всё в комплекте

### Минусы

- Тяжёлый — требует больше ресурсов
- Дольше запускается
- Для школьного уровня — избыточно

### Установка

1. Откройте **https://www.jetbrains.com/pycharm/download/**
2. Скачайте **Community Edition** (бесплатную)
3. Установите, при первом запуске выберите **New Project**

Для 5–9 класса — не рекомендуется. VS Code достаточно.

## 💡 Онлайн-варианты (если не хочется ставить)

Можно писать код прямо в браузере — ничего не устанавливая:

| Сервис | Ссылка | Плюсы |
|---|---|---|
| **Replit** | replit.com | Онлайн, много языков |
| **Google Colab** | colab.research.google.com | Хорош для pandas,数据分析 |
| **OnlineGDB** | onlinegdb.com | Простой запуск Python |
| **Trinket** | trinket.io | Удобен для turtle |

!!! warning "Онлайн-редакторы — не замена локальному"
    Работают, только когда есть интернет. Не сохраняют ваши файлы
    надёжно. Для **учёбы** — хорошо. Для **проектов** — ставьте VS Code.

## 🧪 Проверка после установки

Откройте свой редактор и запустите:

```python
print("Привет!")
print("Я учу Python")
print("И у меня всё получится")
```

Если увидели три строки — редактор настроен правильно. Переходите к
[первой программе](first-program.md).

## ⚠️ Частые проблемы

!!! warning "«Python not found» в VS Code"
    1. Откройте `Ctrl + Shift + P` → `Python: Select Interpreter`
    2. Выберите ваш Python
    3. Если пусто — переустановите Python с галочкой **Add python.exe to PATH**

!!! warning "Русские буквы превращаются в «кракозябры»"
    Всегда сохраняйте файлы в **UTF-8**. В VS Code это по умолчанию.
    В Thonny — тоже.

!!! warning "В Thonny нет кнопки Run"
    Сначала сохраните файл. Несохранённый файл запустить нельзя.

!!! warning "Терминал в VS Code на другом языке"
    Это нормально. Команды всё равно на английском.
