# Установка Python

!!! abstract "Уровень: ⭐ Начальный"
    Подойдёт для 5–11 класса. Ничего знать заранее не нужно — просто выполняйте шаги.

---

## 🍎 Объясняем просто

!!! example "Python — это программа, как игра"
    Чтобы играть в игру, ты её сначала устанавливаешь. С Python то же самое:
    сначала его надо «поселить» на компьютер. После установки ты сможешь
    писать свои программы и запускать их.

    Установка занимает 5–10 минут. Один раз — и навсегда.

---

## 📖 Что мы будем устанавливать

Нам понадобятся **две вещи**:

| Что | Зачем |
|---|---|
| **Python** | Сам «движок» — он выполняет наши программы |
| **Редактор кода** | Удобное место, где мы будем писать программы |

Для Python у нас один вариант — **Python 3** (не 2, он устарел).
Для редактора — на выбор **VS Code** или **Thonny** (для самых младших).

!!! info "Подробнее: почему Python 3, а не Python 2? 🔬"
    Python 2 «умер» 1 января 2020 года — его больше не обновляют и не поддерживают.
    Все современные проекты пишутся на Python 3. Иногда в интернете можно
    встретить старые уроки на Python 2 — не пользуйтесь ими, синтаксис там
    местами другой. Сейчас актуальная версия — **Python 3.12 или новее**.

## 💻 Установка Python на Windows

### Шаг 1. Скачать установщик
1. Откройте **https://www.python.org/downloads/**
2. Нажмите жёлтую кнопку **Download Python 3.x.x**
3. Скачается файл вида `python-3.12.x-amd64.exe`

### Шаг 2. Установить

!!! warning "Самое важное — поставьте галочку!"
    В первом окне установщика **обязательно** отметьте галочку
    **«Add python.exe to PATH»** внизу окна. Без неё Python не будет
    находиться из терминала и придётся всё переустанавливать.

4. Галочка **«Add python.exe to PATH»** — поставьте ✅
5. Нажмите **Install Now** и дождитесь окончания
6. По завершении нажмите **Close**

### Шаг 3. Проверка
Откройте **Пуск** → напишите `cmd` → откройте **Командную строку**.
Напишите:

```bash
python --version
```

Если увидите что-то вроде `Python 3.12.5` — всё отлично.

!!! warning "Если пишет «python не является внутренней командой…»"
    Значит, галочку при установке не поставили. Переустановите Python,
    обязательно отметив **«Add python.exe to PATH»**.

## 🍏 Установка Python на macOS

1. Откройте **https://www.python.org/downloads/**
2. Нажмите **Download Python 3.x.x**
3. Откройте скачанный `.pkg`, пройдите по шагам установки
4. Проверьте в **Terminal** (найдите через Spotlight — `Cmd + Пробел`):

```bash
python3 --version
```

Должно вывести что-то вроде `Python 3.12.5`.

!!! info "Подробнее: почему на Mac команда `python3`, а не `python`? 🔬"
    На macOS слово `python` исторически закреплено за системным Python 2.7,
    который нельзя трогать (он нужен самой системе). Поэтому «новый» Python
    называется `python3`. На Windows и Linux обычно работает просто `python`.

## 🐧 Установка Python на Linux

На большинстве современных дистрибутивов Python 3 уже предустановлен. Проверьте:

```bash
python3 --version
```

Если версия ≥ 3.10 — можно ничего не ставить. Если хочется обновить:

```bash
# Ubuntu / Debian
sudo apt update
sudo apt install python3 python3-pip

# Fedora
sudo dnf install python3 python3-pip
```

## 📝 Устанавливаем редактор кода

### Вариант A — VS Code (от 7 класса и старше)

1. Откройте **https://code.visualstudio.com/**
2. Скачайте и установите
3. После запуска: слева иконка «Extensions» (квадратики) → в поиске `Python` → установите расширение от Microsoft
4. Готово. Можно писать код.

### Вариант B — Thonny (для 5–6 класса)

1. Откройте **https://thonny.org/**
2. Скачайте установщик под свою систему
3. Установите и запустите
4. Thonny сразу готов к работе — Python уже внутри

!!! tip "Совет"
    Если не уверены, какой выбрать: **Thonny** — проще для самых младших,
    **VS Code** — универсальный и то, что используется в реальной работе.

## 🧪 Проверяем, что всё работает

1. Откройте редактор (Thonny или VS Code)
2. Создайте новый файл `hello.py`
3. Напишите:

```python
print("Привет, Python!")
```

4. Сохраните файл (`Ctrl + S`)
5. Запустите:
   - **Thonny** — кнопка ▶ **Run** (или `F5`)
   - **VS Code** — откройте терминал и напишите `python hello.py`

Если увидели строку `Привет, Python!` — вы справились! 🎉

## ⚠️ Частые проблемы

!!! warning "«python не является внутренней командой»"
    - Проверьте, что при установке была галочка **Add python.exe to PATH**
    - Перезапустите терминал или VS Code
    - Если не помогло — переустановите Python

!!! warning "Установил Python 3.12, но `python --version` пишет 2.7"
    На macOS/Linux системный Python 2.7 «встроен». Используйте команду
    `python3 --version` и запускайте программы через `python3 файл.py`.

!!! warning "Расширение Python в VS Code не находит интерпретатор"
    - Откройте палитру команд (`Ctrl + Shift + P`)
    - Введите `Python: Select Interpreter`
    - Выберите из списка установленный Python 3.12
