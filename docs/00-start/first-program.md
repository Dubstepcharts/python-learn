## 🍎 Объясняем просто

!!! example "Программа — это записка компьютеру"
    Ты пишешь записку на языке, который компьютер понимает, — Python.
    Компьютер читает её сверху вниз и делает то, что написано.
    
    Самая первая команда, которую узнают все программисты, — **`print`**.
    Она говорит компьютеру: «Покажи это на экране».

---

## 📖 Что такое `print()`

`print()` — это **функция**, которая выводит текст на экран.
То, что нужно вывести, пишется **внутри скобок**.

```python
print("Привет, мир!")
```

Разберём по частям:

| Что | Что это значит |
|---|---|
| `print` | Имя функции — «напечатай» |
| `(` и `)` | Скобки — внутри них пишется то, что надо вывести |
| `"Привет, мир!"` | Текст (строка). Кавычки обязательны! |

**Результат на экране:**
```
Привет, мир!
```

!!! info "Подробнее: почему кавычки? 🔬"
    Компьютер не знает «по-человечески», что такое `Привет`. Для него это просто
    буквы. Кавычки говорят Python: «это текст, выведи его буквально».
    
    Без кавычек Python подумает, что `Привет` — это **имя переменной**, и
    выдаст ошибку `NameError`, потому что такой переменной нет:
    ```python
    print(Привет)   # ❌ NameError: name 'Привет' is not defined
    ```

## ✍️ Синтаксис

```python
print(что_вывести)
```

- **Кавычки** бывают одинарные `'...'` и двойные `"..."` — работают одинаково
- Можно вывести **число** без кавычек: `print(42)`
- Можно вывести **несколько вещей** через запятую: `print("Мне", 13, "лет")`

## 💡 Примеры

### Пример 1. Классика — «Hello, World!» 🌍

```python
print("Hello, World!")
```

**Результат:**
```
Hello, World!
```

!!! tip "Почему «Hello, World!»?"
    Традиция: почти каждый программист в мире первым делом пишет программу,
    которая выводит `Hello, World!`. Это как «раз-два-три» у пианиста.

### Пример 2. Знакомство 👋

```python
print("Привет, меня зовут Аня")
print("Мне 12 лет")
print("Я учу Python")
```

**Результат:**
```
Привет, меня зовут Аня
Мне 12 лет
Я учу Python
```

Каждый `print` выводит текст **с новой строки**.

### Пример 3. Сюжетный — космический корабль 🚀

```python
print("Запуск через...")
print("3")
print("2")
print("1")
print("Поехали!")
```

**Результат:**
```
Запуск через...
3
2
1
Поехали!
```

### Пример 4. Несколько значений в одном `print` 🐘

```python
print("Слон весит", 4000, "кг")
print("У него", 4, "ноги")
```

**Результат:**
```
Слон весит 4000 кг
У него 4 ноги
```

Python сам поставит **пробелы** между значениями.

### Пример 5. Числа без кавычек 🧮

```python
print(2 + 2)
print(10 - 3)
print(6 * 7)
```

**Результат:**
```
4
7
42
```

!!! info "Подробнее: разница между `"2 + 2"` и `2 + 2` 🔬"
    - `print("2 + 2")` выведет текст: `2 + 2` (буквально, как строку)
    - `print(2 + 2)` выведет результат сложения: `4`
    
    Кавычки означают «это текст». Без кавычек Python считает математику.

## 💬 Комментарии

**Комментарий** — это текст в программе, который Python **игнорирует**.
Он нужен для людей: чтобы объяснить, что делает код.

```python
# Это комментарий — Python его не выполняет
print("Привет!")  # А это тоже комментарий, после строки
```

**Правила:**
- Начинается с `#`
- Всё после `#` до конца строки — комментарий
- Строка может быть только из комментария — тогда она пустая для Python

!!! tip "Зачем нужны комментарии?"
    - Объяснить себе через месяц, что ты имел в виду
    - Показать другу, что делает код
    - «Выключить» часть кода, не удаляя его (временно)
    
    Хороший код — это код, который понятен **без** комментариев. Но
    иногда комментарий реально помогает. Не бойся их писать.

## ⚠️ Частые ошибки

!!! warning "Ошибка 1. Забыли кавычки"
    ```python
    print(Привет)   # ❌ NameError
    ```
    **Правильно:**
    ```python
    print("Привет")
    ```

!!! warning "Ошибка 2. Непарные кавычки"
    ```python
    print("Привет)   # ❌ SyntaxError
    ```
    Кавычки — всегда **парами**, одинаковые.

!!! warning "Ошибка 3. Забыли скобки"
    ```python
    print "Привет"   # ❌ SyntaxError (в Python 3)
    ```
    В Python 3 скобки обязательны: `print("Привет")`.

!!! warning "Ошибка 4. Русские кавычки"
    Иногда редактор автоматически подставляет «ёлочки» `«»` или `„"`.
    Python их не понимает:
    ```python
    print(«Привет»)   # ❌ SyntaxError
    ```
    **Правильно:** обычные прямые кавычки `"..."` или `'...'`.

!!! warning "Ошибка 5. Слово `print` написано с большой буквы"
    ```python
    Print("Привет")   # ❌ NameError
    ```
    Python **чувствителен к регистру**. Только `print`, только с маленькой.

## 🧪 Упражнения

1. ⭐ Напишите программу, которая выводит `Привет, мир!`.
2. ⭐ Выведите своё имя, фамилию и возраст на трёх отдельных строках.
3. ⭐ Выведите фразу: `Мой любимый предмет — математика`.
4. ⭐⭐ Выведите результат выражений `7 + 8`, `15 - 4`, `6 * 5` без кавычек.
5. ⭐⭐ Сделайте «ёлочку» из звёздочек:
   ```
   *
   ***
   *****
   ```
   (подсказка: используйте три `print` с `*`)
6. ⭐⭐⭐ Выведите картинку из символов — например, домик:
   ```
      /\
     /  \
    /____\
    |    |
    |____|
   ```
   (подсказка: поможет `\` — но его придётся написать дважды, `\\`, потому что
   одиночный `\` — служебный символ)
