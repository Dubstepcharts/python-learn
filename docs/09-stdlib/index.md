# Стандартная библиотека

«Батарейки в комплекте» — так говорят про Python. Вместе с ним уже идёт
**стандартная библиотека** — сотни модулей на все случаи жизни. Здесь мы
разберём самые полезные: `math`, `random`, `statistics`, `datetime`, `time`,
`os`, `sys`, `json`.

Всё это доступно **без установки** — только импортируй.

!!! tip "Как учиться"
    Начните с `math` и `random` — их проще всего применить. Дальше `datetime`
    для дат. `os` и `sys` — когда пишете «взрослые» программы. `json` —
    когда нужно сохранять структурированные данные.
