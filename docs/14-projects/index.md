# Проекты

Теория без практики — как учебник по плаванию без воды. Здесь — **идеи проектов** разного уровня: от «Угадай число» до телеграм-бота. Каждый проект опирается на то, что вы уже прошли.

!!! tip "Как выбрать"
    Начните с одного проекта из своего уровня. Доведите до конца — пусть
    даже простой. **Законченный маленький проект полезнее десяти недоделанных.**

## 🎯 Как работать над проектом

1. **Спланируйте** — что должно быть на входе и что на выходе
2. **Разбейте на шаги** — «сначала X, потом Y»
3. **Начните с простого** — работающий минимум, потом улучшения
4. **Тестируйте** после каждого шага
5. **Комментируйте** свой код
6. **Сохраните на GitHub** — это ваше портфолио
