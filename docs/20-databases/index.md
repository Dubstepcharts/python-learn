# Базы данных

**База данных (БД)** — организованное хранилище данных, к которому программы обращаются за информацией. Если переменная хранит одно значение, файл — блок текста, то БД хранит **миллионы связанных записей** и умеет быстро их находить.

Почти любое серьёзное приложение использует БД: соцсети, магазины, банки, игры, мессенджеры.

## 🗂️ Виды баз данных

| Тип | Примеры | Для чего |
|---|---|---|
| **Реляционные (SQL)** | SQLite, PostgreSQL, MySQL, MS SQL, Oracle | Строгие данные, связи, транзакции |
| **Документные (NoSQL)** | MongoDB, CouchDB | Гибкая структура, JSON-документы |
| **Key-value** | Redis, Memcached | Быстрый кеш, счётчики |
| **Колоночные** | ClickHouse, Cassandra | Аналитика, большие данные |
| **Графовые** | Neo4j | Связи между объектами |

Для школьных проектов хватит **SQLite** (встроенный) и, если хочется «взрослого» — **PostgreSQL** или **MongoDB**.
