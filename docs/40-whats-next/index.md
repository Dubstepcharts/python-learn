## 🎯 Куда двигаться

### Если вам 5–7 класс

- **Углубитесь в Turtle и pygame** — сделайте 5–10 своих игр
- **Изучите tkinter** — простые оконные приложения
- **Попробуйте олимпиадные задачи** на **acmp.ru** — начните с простых
- **Читайте код других** — найдите похожие проекты на GitHub
- **Участвуйте в конкурсах** (например, «Код-класс», «Урок цифры»)

### Если вам 8–9 класс

- **Выберите направление**: web, data, mobile, games
- **Сделайте pet-проект**: бот, сайт, игра
- **Начните Codeforces**: 100 задач — база
- **Учите английский** — без него серьёзно не вырасти
- **Попробуйте олимпиады** — школьный, муниципальный этап ВсОШ

### Если вам 10–11 класс

- **Олимпиады**: регион, финал, перечневые — шанс поступить без ЕГЭ
- **Pet-проекты** на GitHub — 3–5 серьёзных
- **Стажировки** в IT-компаниях (Яндекс, ВК, Тинькофф принимают школьников)
- **Собеседования**: пробуйте junior-позиции
- **Подготовка к ЕГЭ** — если олимпиады не сработали

## 💡 Советы, которые сэкономят годы

1. **Регулярность важнее интенсивности.** 1 час в день > 10 часов раз в неделю.
2. **Учите через проекты.** Теория без практики забывается.
3. **Читайте чужой код.** GitHub — лучший учитель.
4. **Не сравнивайте себя с другими.** Сравнивайте с собой год назад.
5. **Спрашивайте.** Stack Overflow, Telegram-чаты, Discord.
6. **Ошибайтесь.** Каждая ошибка — шаг вперёд.
7. **Доводите до конца.** Законченный проект = 10 незаконченных.
8. **Пишите о том, что делаете.** Хабр, блог, Telegram-канал.
9. **Отдыхайте.** Выгорание — реальная проблема.
10. **Учитесь всю жизнь.** Технологии меняются за 3–5 лет.
