# PyQt5 — оконные приложения

`PyQt5` — библиотека для создания **оконных приложений** на Python: с кнопками, полями, меню, таблицами. Это «взрослый» GUI — на нём делают программы для Windows, macOS и Linux.

Отличие от `turtle`: там рисование, здесь — полноценные интерфейсы, как у Word, Paint или калькулятора.

!!! tip "Кому подходит"
    **9–11 класс**. Нужны знания ООП: классы, `__init__`, наследование.
    Если ещё не проходили — сначала [раздел ООП](../08-oop/index.md).
