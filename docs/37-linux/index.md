# Linux для программиста

**Linux** — операционная система, на которой работает **интернет**. 90% серверов, большинство облаков, Android, суперкомпьютеры — всё это Linux.

Программисту Linux нужен потому что:
- Серверы — Linux
- Docker — Linux
- GitHub Actions — Linux
- DevOps — Linux
- Собеседования часто про Linux

Не обязательно ставить Linux основным. Но **уметь пользоваться терминалом** — обязательно.

!!! tip "Кому подходит"
    **9–11 класс**. Понадобится для DevOps, деплоя, работы в команде.

## 🎯 Как попробовать

- **Windows 10/11**: **WSL 2** — Ubuntu внутри Windows
- **macOS**: почти всё то же (это тоже Unix)
- **Виртуальная машина**: VirtualBox + Ubuntu
- **Docker**: `docker run -it ubuntu bash`

**WSL 2** — самый простой путь:

```powershell
wsl --install
```

Одна команда — и у вас Ubuntu.
