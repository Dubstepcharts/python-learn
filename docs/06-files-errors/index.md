# Файлы и ошибки

Программа, которая только печатает в консоль, — это учебный пример. Настоящие программы **читают и пишут файлы** (тексты, конфиги, отчёты) и **умеют справляться с ошибками** вместо того, чтобы падать.

В этом разделе — работа с файлами и все виды исключений Python.

!!! tip "Как учиться"
    Начните с чтения и записи простого текстового файла. Когда почувствуете
    уверенность — переходите к `pathlib` и `with`. Исключения — вторая
    страница, к ней возвращайтесь, когда ваша программа «падает» на непонятном
    сообщении.
