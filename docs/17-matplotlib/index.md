# matplotlib и seaborn

`matplotlib` — главная библиотека для **графиков** на Python. Работает везде: от научных статей до дашбордов. `seaborn` — надстройка над matplotlib с красивыми стилями по умолчанию.

!!! tip "Кому подходит"
    **8–11 класс**. Нужны списки, желательно NumPy.

## 🎯 Зачем это

- **Учёным** — публикация графиков
- **Аналитикам** — визуализация данных
- **Школьникам** — наглядные отчёты по проектам
- **Разработчикам** — дашборды

Один и тот же `plt.plot(...)` — и у вас картинка.
