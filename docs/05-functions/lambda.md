## 🍎 Объясняем просто

!!! example "Функция без имени"
    Иногда функция нужна всего на одну строчку и в одном месте. Давать ей
    имя через `def` — как-то громоздко. Для таких случаев есть `lambda`.

    ```python
    # Обычная функция
    def square(x):
        return x ** 2

    # То же через lambda
    square = lambda x: x ** 2
    ```

    Лямбда — это **функция-однострочник без имени**. Внутри неё только
    **одно выражение** и **неявный `return`**.

---

## ✍️ Синтаксис

```python
lambda аргументы: выражение
```

- `lambda` — ключевое слово
- Аргументы — как в `def` (позиционные, со значениями по умолчанию, `*args`, `**kwargs`)
- **Одно выражение** после `:`, оно же и результат
- **Нет `return`** — что написано, то и вернётся

```python
add = lambda a, b: a + b
print(add(2, 3))         # 5

square = lambda x: x ** 2
print(square(5))         # 25

greet = lambda name: f"Привет, {name}!"
print(greet("Аня"))      # Привет, Аня!
```

## 💡 Где используют `lambda`

Лямбда почти всегда передаётся как **аргумент** другой функции: `sorted`,
`filter`, `map`, `min`, `max`.

### `sorted` с ключом

```python
words = ["банан", "яблоко", "киви", "груша"]

# Сортировка по длине
print(sorted(words, key=lambda w: len(w)))
# ['киви', 'груша', 'банан', 'яблоко']

# Сортировка по последней букве
print(sorted(words, key=lambda w: w[-1]))
```

### `filter` — оставить подходящие

```python
nums = [1, 2, 3, 4, 5, 6]

evens = list(filter(lambda x: x % 2 == 0, nums))
print(evens)   # [2, 4, 6]
```

### `map` — преобразовать

```python
nums = [1, 2, 3, 4, 5]

squared = list(map(lambda x: x ** 2, nums))
print(squared)   # [1, 4, 9, 16, 25]
```

### `max` / `min` с ключом

```python
students = [
    ("Аня", 12),
    ("Борис", 11),
    ("Вика", 13),
]

oldest = max(students, key=lambda s: s[1])
print(oldest)   # ('Вика', 13)
```

### Словарь из лямбд

Иногда лямбды кладут в словарь — маленький «диспетчер» команд:

```python
operations = {
    "+": lambda a, b: a + b,
    "-": lambda a, b: a - b,
    "*": lambda a, b: a * b,
    "/": lambda a, b: a / b if b != 0 else None,
}

print(operations["+"](10, 5))   # 15
print(operations["/"](10, 5))   # 2.0
```

## 📊 `lambda` vs `def`

| Свойство | `lambda` | `def` |
|---|---|---|
| Имя | анонимная | обязательно |
| Строк | одна | много |
| Возврат | неявный | через `return` |
| Документация | ❌ | ✅ докстрока |
| Ветвления | только тернарник | любой код |
| Отладка | плохо видно в трейсе | нормально |

!!! warning "Не пытайтесь запихнуть в `lambda` сложную логику"
    ```python
    # Плохо
    f = lambda x: x * 2 if x > 0 else x ** 2 if x < -10 else 0
    ```
    
    Если логика требует `if/elif/else` или цикла — пишите `def`.
    Лямбда хороша, когда код реально умещается в одну короткую строку.

---

## 📌 Когда `lambda` — правильный выбор

✅ **Передать в `sorted`/`filter`/`map`** — самое частое
✅ **Словарь-«диспетчер» функций**
✅ **Короткие ключи для `max`/`min`**
✅ **Коллбэк в GUI (`tkinter`/`PyQt`)**

## ❌ Когда лучше `def`

- Логика многострочная
- Нужны докстроки
- Функция используется больше одного раза в разных местах
- Хочется нормально отлаживать

**Правило:** если сомневаешься — пиши `def`. `lambda` нужна для «здесь и сейчас».

## 🔍 Лямбды и замыкания

Лямбда «запоминает» переменные из внешней области:

```python
def multiply_by(n):
    return lambda x: x * n

double = multiply_by(2)
triple = multiply_by(3)

print(double(10))   # 20
print(triple(10))   # 30
```

Классическая ловушка — лямбда в цикле:

```python
funcs = [lambda x: x + i for i in range(3)]
print([f(0) for f in funcs])   # [2, 2, 2] — все видят i=2!
```

**Исправление — зафиксировать значение через значение по умолчанию:**

```python
funcs = [lambda x, i=i: x + i for i in range(3)]
print([f(0) for f in funcs])   # [0, 1, 2]
```

!!! info "Подробнее: почему `[2, 2, 2]` 🔬"
    Все три лямбды «смотрят» на одну и ту же переменную `i` из внешней
    области. Цикл закончился, `i = 2`, и все три возвращают одно и то же.
    Значение по умолчанию `i=i` копирует текущее `i` «в момент создания».

## ⚠️ Частые ошибки

!!! warning "Ошибка 1. Несколько выражений"
    ```python
    f = lambda x: x + 1; x * 2   # ❌ SyntaxError
    ```

!!! warning "Ошибка 2. `print` внутри lambda"
    ```python
    f = lambda x: print(x)   # работает, но обычно это не то, что нужно
    ```
    Лямбда возвращает `None` (результат `print`), а не значение.

!!! warning "Ошибка 3. Присваивание внутри lambda"
    ```python
    f = lambda x: y = x   # ❌ SyntaxError
    ```
    В лямбде нельзя `=`. Только выражения.

!!! warning "Ошибка 4. Ловушка замыкания"
    ```python
    [lambda: i for i in range(3)]   # все вернут 2
    ```
