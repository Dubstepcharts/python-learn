## 🍎 Объясняем просто

!!! example "Функция — как рецепт"
    Ты один раз записываешь рецепт блинов. Потом «вызываешь» его, когда
    захочешь: не переписываешь каждый раз, а просто говоришь «печём блины».
    
    ```python
    def hello():
        print("Привет!")

    hello()      # вызывает функцию
    hello()      # снова
    hello()      # и снова — сколько хочешь
    ```

## ✍️ Синтаксис

```python
def имя_функции(аргументы):
    """Необязательная докстрока."""
    # тело функции
    return значение   # необязательно
```

- `def` — ключевое слово (от define — «определить»)
- `имя` — по правилам именования переменных, обычно **глагол**: `calculate`, `print_menu`
- `(...)` — список аргументов, может быть пустым
- `:` — конец заголовка
- Тело — с отступом 4 пробела
- `return` — необязателен; без него функция вернёт `None`

## 💡 Примеры

### Пример 1. Простейшая функция

```python
def greet():
    print("Привет, мир!")

greet()      # Привет, мир!
```

### Пример 2. С аргументом

```python
def greet(name):
    print(f"Привет, {name}!")

greet("Аня")     # Привет, Аня!
greet("Борис")   # Привет, Борис!
```

### Пример 3. С возвратом значения

```python
def add(a, b):
    return a + b

result = add(2, 3)
print(result)   # 5
print(add(10, 20))   # 30
```

### Пример 4. Несколько аргументов

```python
def introduce(name, age, city):
    print(f"{name}, {age} лет, из города {city}")

introduce("Аня", 12, "Москва")
```

### Пример 5. Функция с циклом

```python
def print_table(n):
    for i in range(1, 10):
        print(f"{n} × {i} = {n * i}")

print_table(7)
```

## 📖 Докстроки

**Докстрока** — это строка в тройных кавычках **сразу после `def`**. Она описывает, что делает функция.

```python
def area(width, height):
    """Возвращает площадь прямоугольника."""
    return width * height

# Докстроку можно прочитать
print(area.__doc__)   # "Возвращает площадь прямоугольника."
help(area)            # покажет докстроку в справке
```

!!! tip "Хорошая докстрока"
    ```python
    def divide(a, b):
        """Делит a на b.
        
        Аргументы:
            a (float): делимое
            b (float): делитель, не ноль
        
        Возвращает:
            float: результат деления
        
        Пример:
            >>> divide(10, 2)
            5.0
        """
        return a / b
    ```
    Такой стиль — почти стандарт в реальных проектах.

## 📌 Аннотации типов

Можно указать, каких типов аргументы и что возвращает функция:

```python
def add(a: int, b: int) -> int:
    return a + b

def greet(name: str) -> str:
    return f"Привет, {name}!"
```

Python **не проверяет** эти типы при запуске — они для людей и IDE. Это «документация в коде».

!!! info "Подробнее: зачем аннотации 🔬"
    - **Читаемость:** сразу видно, что функция ждёт и что вернёт
    - **IDE подсказывает:** VS Code предупредит о несоответствии
    - **Инструменты** (`mypy`, `pyright`) проверяют типы без запуска
    - **Не влияют на скорость:** это просто метаданные
    
    Современный стандарт в больших проектах — аннотировать всё.

## 🔁 Функция без `return`

Если функция ничего не возвращает явно, она возвращает `None`:

```python
def log(message):
    print(f"[LOG] {message}")

result = log("привет")
print(result)   # None
```

`None` — специальное значение «ничего». Оно не равно `0`, `""` или `False`.
Проверяется через `is None`:

```python
if result is None:
    print("Функция ничего не вернула")
```

## 📏 Правила хороших функций

1. **Одно действие** — функция должна делать одну вещь
2. **Понятное имя** — `calculate_area`, а не `calc` или `f1`
3. **Мало аргументов** — больше 4-х — уже сложно
4. **Докстрока** — коротко: что делает
5. **Не слишком длинная** — если больше 30–40 строк, разбей на части

**Плохо:**
```python
def do_everything(x):
    # читает файл, считает, пишет в БД, отправляет email...
```

**Хорошо:**
```python
def read_data(path): ...
def calculate(data): ...
def save_result(result): ...
```

## ⚠️ Частые ошибки

!!! warning "Ошибка 1. Забыли скобки при вызове"
    ```python
    def hello():
        print("hi")

    hello     # ❌ ничего не вызовется, просто ссылка на функцию
    hello()   # ✅
    ```

!!! warning "Ошибка 2. Функция определена после вызова"
    ```python
    hello()   # ❌ NameError

    def hello():
        print("hi")
    ```
    Python выполняет код сверху вниз. Функцию надо определить **до** вызова.

!!! warning "Ошибка 3. Отступы"
    ```python
    def hello():
    print("hi")   # ❌ IndentationError
    ```

!!! warning "Ошибка 4. `return` вне функции"
    ```python
    return 5   # ❌ SyntaxError
    ```
    `return` работает только внутри функции.
