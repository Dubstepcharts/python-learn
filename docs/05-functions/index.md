# Функции

Функция — это «мини-программа внутри программы». Ты даёшь ей имя, описываешь, что делать, — и потом вызываешь сколько угодно раз.

Функции — главный инструмент **против повторения**. Написал один раз — используешь везде.

В этом разделе: как определять функции, все виды аргументов, возврат значений, область видимости, лямбды и декораторы.

!!! tip "Как учиться"
    Функции — то, без чего не бывает серьёзного кода. Разберитесь в
    аргументах (`arguments.md`) — это самое сложное. Дальше всё пойдёт легко.
