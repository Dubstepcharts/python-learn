## 🍎 Объясняем просто

!!! example "Почему один алгоритм быстрее другого"
    Поиск в **отсортированном** списке из миллиона элементов занимает
    **20 шагов** (бинарный поиск). В **неотсортированном** — до **миллиона**
    (линейный). Разница — в 50 000 раз.

    **Big O** — способ описать эту разницу «в общем виде», не привязываясь
    к компьютеру.

---

## 📖 Что такое Big O

**Big O** показывает, **как растёт время работы** алгоритма при увеличении
входных данных. Константы и мелкие детали опускаются — важно только
**поведение в пределе**.

| Обозначение | Название | Если n = 1000 |
|---|---|---|
| O(1) | Константная | 1 операция |
| O(log n) | Логарифмическая | ~10 операций |
| O(n) | Линейная | 1000 операций |
| O(n log n) | Линейно-логарифмическая | ~10 000 |
| O(n²) | Квадратичная | 1 000 000 |
| O(n³) | Кубическая | 1 миллиард |
| O(2ⁿ) | Экспоненциальная | не сосчитать |
| O(n!) | Факториальная | катастрофа |

Для n = 1 000 000 «страшные» строки становятся **неприемлемыми**:

```
O(log n)   — 20
O(n)       — 1 000 000
O(n log n) — 20 000 000
O(n²)      — 1 000 000 000 000  ← не дождётесь
```

## 📌 Примеры по коду

### O(1) — константа

```python
def first(lst):
    return lst[0]
```

Один доступ, независимо от размера.

### O(n) — линейная

```python
def find_max(lst):
    m = lst[0]
    for x in lst:
        if x > m:
            m = x
    return m
```

Один проход по всем элементам.

### O(n²) — квадратичная

```python
def has_duplicates(lst):
    for i in range(len(lst)):
        for j in range(i + 1, len(lst)):
            if lst[i] == lst[j]:
                return True
    return False
```

Два вложенных цикла. При 1000 элементов — миллион операций.

### O(log n) — логарифмическая

```python
def binary_search(lst, target):
    lo, hi = 0, len(lst) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if lst[mid] == target:
            return mid
        elif lst[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

Каждый шаг вдвое сокращает область поиска.

### O(n log n)

Классические эффективные сортировки: **merge sort**, **quick sort**, **heap sort**. Работают через «разделяй и властвуй».

## 📌 Как определить сложность

**Правила:**

1. **Последовательные блоки — складываются, берём максимум.**
   ```
   O(n) + O(n²) = O(n²)
   ```

2. **Вложенные циклы — умножаются.**
   ```
   цикл по n { цикл по m { ... } }  → O(n · m)
   ```
   Если оба по n → O(n²).

3. **Условия внутри цикла не меняют сложность.**
   ```
   цикл { if ... }  → O(n)
   ```

4. **Константы отбрасываются.**
   ```
   O(2n) = O(n), O(n/2) = O(n), O(5) = O(1)
   ```

5. **Логарифм — когда каждый шаг делит вход.**
   ```
   while n > 1: n = n // 2     → O(log n)
   ```

## 📌 Амортизированная сложность

Некоторые операции **редко дорогие, но обычно дешёвые**. Тогда говорят
о средней (амортизированной) оценке.

**Пример:** `list.append()` — обычно O(1), иногда O(n), когда массив
пересоздаётся. **Амортизированно — O(1)**.

---

## 📌 Сложности встроенных операций Python

| Операция | Сложность |
|---|---|
| `lst[i]` | O(1) |
| `lst[i:j]` | O(j - i) |
| `lst.append(x)` | O(1) аморт. |
| `lst.insert(0, x)` | O(n) |
| `lst.pop()` | O(1) |
| `lst.pop(0)` | O(n) |
| `x in lst` | O(n) |
| `lst.sort()` | O(n log n) |
| `d[key]` | O(1) |
| `key in d` | O(1) |
| `d.items()` | O(1) → O(n) обход |
| `s.add(x)` (множество) | O(1) |
| `x in s` (множество) | O(1) |
| `len(lst)` | O(1) |

**Важно:** `x in lst` — медленно, `x in d` / `x in s` — быстро!

## 📌 Память

Big O работает и для памяти:

```python
# O(n) памяти
result = [x * 2 for x in big_list]

# O(1) памяти — генератор
result = sum(x * 2 for x in big_list)
```

Генераторы — ваш друг, когда данных много.

## ⚠️ Частые ошибки

!!! warning "Преждевременная оптимизация"
    Сначала **правильно**, потом **быстро**. 90% времени тратится в 10%
    кода — оптимизируйте только **горячие места**.

!!! warning "Игнорирование «маленьких» констант"
    O(n²) на n < 100 может быть **быстрее** O(n log n) — из-за константы.
    Big O говорит о **порядке**, а не о секундах.

!!! warning "`in` для списка в цикле"
    ```python
    for x in huge_list:
        if x in other_huge_list:  # O(n) × O(n) = O(n²)
    ```
    Замените `other_huge_list` на `set` → O(n).
