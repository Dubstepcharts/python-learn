# Алгоритмы и структуры данных

**Алгоритм** — точная последовательность шагов для решения задачи. **Структура данных** — способ организации данных, от которого зависит скорость работы алгоритма.

Это **фундамент информатики**. Любая программа — это алгоритм + данные. Чем лучше вы понимаете алгоритмы, тем эффективнее ваши решения.

!!! tip "Кому подходит"
    **9–11 класс**, подготовка к олимпиадам, будущая работа в IT. Нужны: списки, словари, функции, рекурсия.
