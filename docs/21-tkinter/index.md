# tkinter — GUI из коробки

**tkinter** — стандартная библиотека Python для создания **оконных приложений**. Входит в поставку Python — устанавливать ничего не нужно.

Это самый простой способ сделать «окно с кнопками» на Python. Идеально для первых проектов: калькулятор, заметки, викторина, рисовалка.

!!! tip "Кому подходит"
    **7–10 класс**. Нужны: функции, классы, немного ООП.

## 🎯 Чем tkinter отличается от PyQt5

| | tkinter | PyQt5 |
|---|---|---|
| Установка | Встроен в Python | `pip install PyQt5` |
| Размер | Маленький | Большой (~50 МБ) |
| Вид | Простой, «олдскульный» | Современный, нативный |
| Сложность | Очень простая | Средняя |
| Виджеты | Базовые | Богатый набор |
| Для чего | Учебные проекты, утилиты | Настоящие приложения |

**Правило:** начать с tkinter. Если нужен «взрослый» интерфейс — перейти на PyQt5.

---

## 🚀 Минимальное приложение

```python
import tkinter as tk

root = tk.Tk()
root.title("Моё окно")
root.geometry("400x300")

label = tk.Label(root, text="Привет, мир!")
label.pack()

root.mainloop()
```

Десять строк — и у вас работает окно. Разберём это подробно на следующей странице.
