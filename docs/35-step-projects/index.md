## 🎯 Как работать

1. **Прочитайте весь туториал** один раз, чтобы понять структуру.
2. **Делайте шаг за шагом.** После каждого — запускайте и проверяйте.
3. **Экспериментируйте.** Меняйте параметры, добавляйте своё.
4. **Не бойтесь ошибок.** Они — нормальная часть процесса.
5. **Сохраните в Git.** Каждый значимый шаг — отдельный коммит.
