## 🍎 Объясняем просто

!!! example "Строка — как поезд из вагонов"
    Представь слово `"Python"` как поезд из 6 вагонов:
    ```
    P  y  t  h  o  n
    0  1  2  3  4  5     ← индексы с начала
   -6 -5 -4 -3 -2 -1     ← индексы с конца
    ```
    Срез — это способ взять несколько вагонов подряд: например, вагоны с 1 по 3
    (не включая 3) — `yt`. Синтаксис: `строка[начало:конец:шаг]`.

## 📖 Индексы и срезы

### Получить один символ — индекс

```python
word = "Python"
print(word[0])    # P
print(word[1])    # y
print(word[-1])   # n (последний)
print(word[-2])   # o (второй с конца)
```

### Срез `[start:stop]`

**Правило:** `start` включается, `stop` **не** включается.

```python
word = "Python"

print(word[0:3])   # Pyt   (индексы 0, 1, 2)
print(word[1:4])   # yth
print(word[2:])    # thon  (до конца)
print(word[:3])    # Pyt   (с начала)
print(word[:])     # Python (копия)
```

!!! warning "Самая частая ошибка — «не включая конец»"
    `word[0:3]` даёт **3 символа** (индексы 0, 1, 2), а не 4.
    Если нужно 4 символа — `word[0:4]`. Это правило среза:
    `start ≤ i < stop`.

### Отрицательные индексы

```python
word = "Python"
print(word[-3:])    # hon  (последние 3)
print(word[:-3])    # Pyt  (всё, кроме последних 3)
print(word[-5:-2])  # yth
```

### Шаг `[start:stop:step]`

```python
word = "Python"

print(word[::2])     # Pto  (каждый второй)
print(word[1::2])    # yhn
print(word[::-1])    # nohtyP  (переворот строки!)
print(word[5:0:-1])  # nohty
print(word[::-2])    # nhy  (обратный порядок, каждый второй)
```

!!! info "Подробнее: как работает `[::-1]` 🔬"
    `[::-1]` — идиоматический способ **перевернуть строку** в Python.
    Расшифровка:
    - `start` — пусто → начало с конца (потому что `step` отрицательный)
    - `stop` — пусто → до начала
    - `step = -1` → идём назад по одному символу
    
    Более явно: `word[-1::-1]` или `word[len(word)-1::-1]`.

### Срез не падает на выходе за границы

```python
word = "Python"
print(word[0:100])   # Python   (не ошибка!)
print(word[100:])    # ""       (пустая строка)
```

В отличие от `word[100]` (это `IndexError`), срез **безопасен** — просто вернёт то, что есть.

## 📊 Полная таблица примеров

Для `s = "Python"` (индексы 0–5):

| Срез | Что получится | Почему |
|---|---|---|
| `s[0]` | `P` | Первый символ |
| `s[-1]` | `n` | Последний |
| `s[0:3]` | `Pyt` | 0, 1, 2 |
| `s[:3]` | `Pyt` | То же |
| `s[3:]` | `hon` | С 3 до конца |
| `s[:]` | `Python` | Копия |
| `s[::2]` | `Pto` | Через один |
| `s[::-1]` | `nohtyP` | Переворот |
| `s[2:5]` | `tho` | 2, 3, 4 |
| `s[-3:]` | `hon` | Последние 3 |
| `s[:-3]` | `Pyt` | Всё до 3-го с конца |
| `s[10:20]` | `""` | За границами — пусто |

## 💡 Примеры

### Пример 1. Первая и последняя буква 🔤

```python
word = "программирование"
print(word[0])      # п
print(word[-1])     # е
```

### Пример 2. Переворот строки 🔄

```python
s = "привет"
print(s[::-1])   # тевирп
```

### Пример 3. Палиндром? 🪞

```python
word = input("Слово: ")
if word == word[::-1]:
    print("Палиндром!")
else:
    print("Нет")
```

### Пример 4. Сюжетный — выделить домен 🖥️

```python
email = "user@example.com"
domain = email[email.find("@") + 1:]
print(domain)      # example.com
```

### Пример 5. Убрать последний символ ✂️

```python
path = "file.txt\n"
clean = path[:-1]     # убираем \n
print(clean)          # file.txt
```

### Пример 6. Взять каждый второй символ 🎲

```python
s = "abcdefgh"
print(s[::2])    # aceg
print(s[1::2])   # bdfh
```

## ⚠️ Частые ошибки

!!! warning "Ошибка 1. `s[5]` вместо `s[5:6]`"
    `s[5]` — один символ. `s[5:6]` — срез из одного символа.
    Разница видна, когда работаешь с `len`: `len(s[5])` = 1, `len(s[5:6])` = 1,
    но `len(s[5:5])` = 0.

!!! warning "Ошибка 2. Забыли, что `stop` не включается"
    ```python
    "Python"[0:3]     # 'Pyt', а не 'Pyth'
    ```
    Для «с 0 по 3 включительно» нужен `[0:4]`.

!!! warning "Ошибка 3. Срез вне границ возвращает пусто, а не ошибку"
    ```python
    "Python"[100:200]   # '' — не IndexError
    ```
    Проверяйте длину заранее, если нужна валидация.

!!! warning "Ошибка 4. Срез без копии — на самом деле копия"
    ```python
    s = "abc"
    t = s[:]      # это НЕ ссылка, а копия (для строк — не важно, они неизменяемы)
    ```
    Со строками путаницы не будет, но с списками `list[:]` — реально копия.

## 📌 Срез vs `slice()`

Можно создать «объект среза» заранее:

```python
s = "Python"
sl = slice(1, 4)
print(s[sl])   # yth
```

Иногда удобно для повторного использования одного среза к разным строкам.
