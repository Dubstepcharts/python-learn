# Форматирование строк

!!! abstract "Уровень: ⭐ Начальный → ⭐⭐ Средний"
    Подойдёт для 7–11 класса. Нужно знать: [типы данных](../01-basics/data-types.md).

## 🍎 Объясняем просто

!!! example "Зачем форматирование?"
    Раньше мы склеивали текст через `+`:
    ```python
    print("Привет, " + name + "! Тебе " + str(age) + " лет.")
    ```
    Много кавычек, плюсов, `str(...)` — легко ошибиться. Форматирование
    позволяет записать то же самое чище:
    ```python
    print(f"Привет, {name}! Тебе {age} лет.")
    ```

    В Python **четыре** способа форматирования. Разберём все — от старого к
    новому.

---

## 1️⃣ `%` — старый способ (стиль C)

Самый старый метод, пришёл из языка C. Работает через оператор `%`.

```python
name = "Аня"
age = 12
print("Меня зовут %s, мне %d лет" % (name, age))
```

**Результат:** `Меня зовут Аня, мне 12 лет`

**Основные спецификаторы:**

| Спецификатор | Что подставляет |
|---|---|
| `%s` | Строку (или что угодно) |
| `%d` | Целое число |
| `%f` | Дробное число |
| `%x` | Шестнадцатеричное |
| `%o` | Восьмеричное |
| `%e` | Экспоненциальная запись |
| `%%` | Знак `%` |

```python
print("%s — %d лет" % ("Аня", 12))
print("%.2f" % 3.14159)        # 3.14
print("%10s" % "hi")            # "        hi"
print("%-10s|" % "hi")          # "hi        |"
print("%04d" % 42)              # 0042
print("100%% готово")           # 100% готово
```

!!! info "Подробнее: когда ещё используют `%` 🔬"
    - В старых проектах и коде до Python 3.0
    - В библиотеке `logging`: `logging.info("Пользователь %s вошёл", user)`
    - В некоторых API, где формат строки задан извне
    
    В новом коде лучше использовать f-строки.

## 2️⃣ `str.format()` — способ Python 3.0+

Метод `.format()` вызывается у строки. В строке — «плейсхолдеры» `{}`.

```python
print("Меня зовут {}, мне {} лет".format("Аня", 12))
```

### Позиционные аргументы

```python
print("{0} + {1} = {2}".format(2, 3, 5))     # 2 + 3 = 5
print("{2} + {1} = {0}".format(5, 3, 2))     # 2 + 3 = 5
print("{} {}".format("а", "б"))               # а б
```

### Именованные аргументы

```python
print("{name} — {age} лет".format(name="Аня", age=12))
```

### Словарь через `**`

```python
data = {"name": "Аня", "age": 12}
print("{name} — {age} лет".format(**data))
```

### Форматирование чисел

```python
pi = 3.14159
print("{:.2f}".format(pi))       # 3.14
print("{:10.2f}".format(pi))     # "      3.14"
print("{:>10.2f}".format(pi))    # "      3.14" (вправо)
print("{:<10.2f}".format(pi))    # "3.14      " (влево)
print("{:^10.2f}".format(pi))    # "   3.14   " (по центру)

print("{:,}".format(1000000))    # 1,000,000
print("{:.1%}".format(0.256))    # 25.6%
print("{:b}".format(42))         # 101010 (двоичное)
print("{:x}".format(255))        # ff (шестнадцатеричное)
```

!!! info "Подробнее: мини-язык формата 🔬"
    После `:` можно задать:
    - **Выравнивание:** `<` влево, `>` вправо, `^` по центру
    - **Ширина:** число
    - **Точность:** `.N` для чисел с точкой
    - **Тип:** `f` (float), `d` (int), `s` (str), `%` (процент), `b`, `x`, `o`, `e`
    
    Пример: `{:^10.2f}` = «по центру, ширина 10, две цифры после точки».

## 3️⃣ f-строки — современный способ (Python 3.6+)

**Рекомендуемый способ.** Буква `f` перед кавычками включает форматирование, а `{...}` подставляет значения.

```python
name = "Аня"
age = 12
print(f"Меня зовут {name}, мне {age} лет")
```

Внутри `{}` можно писать **любое выражение**:

```python
a, b = 5, 3
print(f"{a} + {b} = {a + b}")           # 5 + 3 = 8
print(f"Квадрат {a} = {a ** 2}")        # Квадрат 5 = 25
print(f"Верхний регистр: {'привет'.upper()}")  # Верхний регистр: ПРИВЕТ
```

### Формат — как у `str.format()`

```python
pi = 3.14159
print(f"{pi:.2f}")         # 3.14
print(f"{pi:10.2f}")       # "      3.14"
print(f"{pi:^10.2f}")      # "   3.14   "
print(f"{1000000:,}")      # 1,000,000
```

### Отладка: `f"{x=}"` (Python 3.8+)

Очень удобно для отладки:

```python
x = 42
print(f"{x=}")              # x=42
print(f"{x + 1=}")          # x + 1=43
```

### Многострочные f-строки

```python
name = "Аня"
age = 12
text = f"""
Имя: {name}
Возраст: {age}
Через год: {age + 1}
"""
print(text)
```

## 4️⃣ `string.Template` — шаблоны для «опасных» данных

Самый редкий способ. Используется, когда формат строки задают пользователи (например, из файла конфигурации).

```python
from string import Template

t = Template("Привет, $name! Тебе $age лет.")
print(t.substitute(name="Аня", age=12))
```

**Что даёт:**
- `$name` — простая подстановка, не может выполнять код (безопаснее f-строк)
- `$$` — экранированный `$`
- Подходит для интернационализации (i18n), когда шаблоны переводят люди

!!! info "Подробнее: почему `Template`, а не f-строка 🔬"
    В f-строках `{...}` — это **код**, который выполнится. Если шаблон
    контролирует пользователь, это опасно (инъекция). `Template` же только
    подставляет значения, никакого кода. Поэтому для переводов, конфигов,
    пользовательских шаблонов используют именно его.

## 📊 Сравнение четырёх способов

| Способ | Плюсы | Минусы | Когда использовать |
|---|---|---|---|
| `%` | Работает везде, быстрый | Устаревший, неудобный | Старый код, logging |
| `.format()` | Гибкий, именованные аргументы | Длинный синтаксис | Шаблоны со сложной логикой |
| **f-строки** | Читаемые, короткие, быстрые | Python 3.6+ | **99% случаев** |
| `Template` | Безопасный | Ограниченный | Пользовательские шаблоны |

**Золотое правило:** используй **f-строки**. Остальные — когда есть конкретная причина.

## 🎯 Полный список опций формата

Указываются после `:` внутри `{}`:

| Опция | Что делает | Пример |
|---|---|---|
| `:.2f` | 2 знака после точки | `f"{3.14159:.2f}"` → `3.14` |
| `:,` | Разделять тысячи | `f"{1000000:,}"` → `1,000,000` |
| `:.1%` | Процент с 1 знаком | `f"{0.256:.1%}"` → `25.6%` |
| `:>10` | Вправо в поле 10 | `f"{'hi':>10}"` → `"        hi"` |
| `:<10` | Влево | `f"{'hi':<10}"` → `"hi        "` |
| `:^10` | По центру | `f"{'hi':^10}"` → `"    hi    "` |
| `:08d` | Дополнить нулями | `f"{42:08d}"` → `00000042` |
| `:b` | Двоичная | `f"{42:b}"` → `101010` |
| `:o` | Восьмеричная | `f"{42:o}"` → `52` |
| `:x` | Шестнадцатеричная | `f"{255:x}"` → `ff` |
| `:e` | Экспонента | `f"{12345:e}"` → `1.234500e+04` |
| `:g` | Короткая запись числа | `f"{0.0001:g}"` → `0.0001` |
| `:_` | Подчёркивания | `f"{1000000:_}"` → `1_000_000` |

## ⚠️ Частые ошибки

!!! warning "Ошибка 1. Забыли `f` перед строкой"
    ```python
    name = "Аня"
    print("{name} пришла")     # ❌ выведет буквально "{name} пришла"
    print(f"{name} пришла")    # ✅
    ```

!!! warning "Ошибка 2. Кавычки внутри f-строки"
    ```python
    f"{'привет'}"     # ✅ одинарные внутри двойных
    f'{"привет"}'     # ✅ двойные внутри одинарных
    f"{"привет"}"     # ❌ в старых Python, в 3.12+ разрешено
    ```

!!! warning "Ошибка 3. `%d` для строки"
    ```python
    "%d" % "abc"      # ❌ TypeError
    ```

!!! warning "Ошибка 4. Неэкранированные фигурные скобки в f-строках"
    ```python
    f"{{literal}}"    # ✅ выведет {literal}
    ```
