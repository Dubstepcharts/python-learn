!!! abstract "Уровень: ⭐ Начальный → ⭐⭐⭐ Продвинутый"
    Подойдёт для всех классов. Младшие пусть смотрят на ⭐-методы, старшие —
    на всю таблицу целиком.

---

## 🍎 Объясняем просто

!!! example "Метод — это «умение» строки"
    У строки, как у человека, есть умения. Она умеет превращаться в верхний
    регистр (`.upper()`), искать буквы (`.find()`), заменять одно на другое
    (`.replace()`).

    Запись `"привет".upper()` читается как «у строки `привет` вызови умение
    `upper`». Результат — новая строка `ПРИВЕТ`.

    **Важно:** методы **не меняют** исходную строку. Строки в Python неизменяемы
    (immutable). Метод **возвращает новую** строку.

## 🔤 Регистр: изменение регистра

| Метод | Что делает | Пример | ⭐ |
|---|---|---|---|
| `upper()` | Все буквы — заглавные | `"привет".upper()` → `"ПРИВЕТ"` | ⭐⭐⭐ |
| `lower()` | Все буквы — строчные | `"ПРИВЕТ".lower()` → `"привет"` | ⭐⭐⭐ |
| `capitalize()` | Первая буква заглавная, остальные строчные | `"привет мир".capitalize()` → `"Привет мир"` | ⭐⭐ |
| `title()` | Каждое слово с заглавной | `"привет мир".title()` → `"Привет Мир"` | ⭐⭐ |
| `swapcase()` | Меняет регистр каждой буквы на противоположный | `"Привет".swapcase()` → `"пРИВЕТ"` | ⭐ |
| `casefold()` | Агрессивный нижний регистр, для сравнения строк | `"Straße".casefold()` → `"strasse"` | ⭐ |

!!! info "Подробнее: зачем `casefold()`, если есть `lower()`? 🔬"
    Для немецкой `ß` метод `lower()` вернёт `ß`, а `casefold()` — `ss`.
    `casefold()` — это «сравнительно-регистронезависимый» вариант. Используется,
    когда надо сравнить две строки без учёта регистра, с полным Unicode-смыслом.
    В обычном коде достаточно `lower()`.

## 🔍 Поиск и замена

| Метод | Что делает | Пример | ⭐ |
|---|---|---|---|
| `find(sub)` | Позиция подстроки, или `-1` | `"banana".find("na")` → `2` | ⭐⭐⭐ |
| `rfind(sub)` | То же, но ищет справа | `"banana".rfind("na")` → `4` | ⭐⭐ |
| `index(sub)` | Как `find`, но ошибка, если нет | `"banana".index("na")` → `2` | ⭐⭐ |
| `rindex(sub)` | Как `rfind`, но ошибка, если нет | `"banana".rindex("na")` → `4` | ⭐ |
| `count(sub)` | Сколько раз встречается | `"banana".count("a")` → `3` | ⭐⭐⭐ |
| `replace(old, new)` | Заменить все вхождения | `"banana".replace("a", "o")` → `"bonono"` | ⭐⭐⭐ |
| `startswith(s)` | Начинается ли с | `"python".startswith("py")` → `True` | ⭐⭐⭐ |
| `endswith(s)` | Заканчивается ли на | `"python".endswith("on")` → `True` | ⭐⭐⭐ |
| `removesuffix(s)` | Убрать суффикс (Python 3.9+) | `"test.py".removesuffix(".py")` → `"test"` | ⭐ |
| `removeprefix(s)` | Убрать префикс (Python 3.9+) | `"Mr. Smith".removeprefix("Mr. ")` → `"Smith"` | ⭐ |

```python
text = "Я люблю Python, Python — это весело"

print(text.find("Python"))        # 8
print(text.rfind("Python"))       # 18
print(text.count("Python"))       # 2
print(text.replace("Python", "код"))  # Я люблю код, код — это весело
print(text.startswith("Я"))       # True
print(text.endswith("весело"))    # True
print("test.py".removesuffix(".py"))   # test
print("Mr. Smith".removeprefix("Mr. "))  # Smith
```

!!! warning "`find` vs `index`"
    - `find` вернёт `-1`, если подстрока не найдена — программа продолжит работу
    - `index` выбросит `ValueError` — программа упадёт, если не обработать
    
    **Совет:** если не уверены, что подстрока есть, — используйте `find`.

## ✂️ Разрезание и склейка

| Метод | Что делает | Пример | ⭐ |
|---|---|---|---|
| `split(sep)` | Разбить по разделителю (по умолчанию — пробелы) | `"a b c".split()` → `['a','b','c']` | ⭐⭐⭐ |
| `rsplit(sep)` | То же, но справа | `"a b c".rsplit(maxsplit=1)` → `['a b', 'c']` | ⭐ |
| `splitlines()` | Разбить по строкам | `"a\nb".splitlines()` → `['a','b']` | ⭐⭐ |
| `join(iter)` | Склеить элементы через разделитель | `", ".join(["a","b"])` → `"a, b"` | ⭐⭐⭐ |
| `partition(sep)` | Разбить на 3 части по первому sep | `"a=b=c".partition("=")` → `('a','=','b=c')` | ⭐ |
| `rpartition(sep)` | То же, но по последнему sep | `"a=b=c".rpartition("=")` → `('a=b','=','c')` | ⭐ |

```python
sentence = "Python — это здорово"
words = sentence.split()          # ['Python', '—', 'это', 'здорово']

fruits = ["яблоко", "банан", "груша"]
print(", ".join(fruits))          # яблоко, банан, груша

csv = "1,2,3,4,5"
print(csv.split(","))             # ['1', '2', '3', '4', '5']

print("a=b=c".partition("="))     # ('a', '=', 'b=c')
print("a=b=c".rpartition("="))    # ('a=b', '=', 'c')
```

!!! tip "Мощная пара `split` + `join`"
    Часто используется для нормализации текста:
    ```python
    text = "  много   лишних    пробелов  "
    clean = " ".join(text.split())
    print(clean)   # "много лишних пробелов"
    ```

## 🧹 Очистка (strip-семейство)

| Метод | Что делает | Пример | ⭐ |
|---|---|---|---|
| `strip(chars)` | Убрать символы с **обоих** концов | `"  hi  ".strip()` → `"hi"` | ⭐⭐⭐ |
| `lstrip(chars)` | Только слева | `"  hi  ".lstrip()` → `"hi  "` | ⭐⭐ |
| `rstrip(chars)` | Только справа | `"  hi  ".rstrip()` → `"  hi"` | ⭐⭐ |

```python
print("  привет  ".strip())        # "привет"
print("  привет  ".lstrip())       # "привет  "
print("  привет  ".rstrip())       # "  привет"

# Можно указать, какие именно символы убирать:
print("...привет...".strip("."))   # "привет"
print("xyxhelloxyx".strip("xy"))   # "hello"
```

!!! info "Подробнее: `strip("xy")` — это не «убрать суффикс xy» 🔬"
    `strip("xy")` убирает **любые** символы из набора `{x, y}` с обоих концов.
    Поэтому `"xyxhelloxyx".strip("xy")` даёт `"hello"`, но `"helloxy".strip("xy")`
    тоже даст `"hello"` — потому что `xy` в конце. Если нужно убрать именно
    суффикс — используйте `removesuffix()`.

## 📏 Выравнивание и заполнение

| Метод | Что делает | Пример | ⭐ |
|---|---|---|---|
| `center(w, fill)` | Центрировать в поле ширины `w` | `"hi".center(6, "-")` → `"--hi--"` | ⭐ |
| `ljust(w, fill)` | Прижать влево, дополнить справа | `"hi".ljust(5, ".")` → `"hi..."` | ⭐ |
| `rjust(w, fill)` | Прижать вправо, дополнить слева | `"hi".rjust(5, ".")` → `"...hi"` | ⭐ |
| `zfill(w)` | Дополнить нулями слева | `"42".zfill(5)` → `"00042"` | ⭐⭐ |

```python
print("hi".center(6, "*"))    # **hi**
print("hi".ljust(5, "."))     # hi...
print("hi".rjust(5, "."))     # ...hi
print("42".zfill(5))          # 00042
print("-7".zfill(5))          # -0007
```

!!! tip "Где это нужно?"
    `zfill` — классика для нумерации файлов: `file_001.txt`, `file_002.txt`.
    `rjust` — для табличных отчётов. `center` — для красивых заголовков.

## ❓ Проверки: из чего состоит строка

| Метод | Что проверяет | Пример | ⭐ |
|---|---|---|---|
| `isalpha()` | Только буквы | `"abc".isalpha()` → `True` | ⭐⭐ |
| `isdigit()` | Только цифры | `"123".isdigit()` → `True` | ⭐⭐⭐ |
| `isalnum()` | Буквы и цифры | `"ab12".isalnum()` → `True` | ⭐⭐ |
| `isspace()` | Только пробельные | `"  \t".isspace()` → `True` | ⭐ |
| `islower()` | Все буквы строчные | `"abc".islower()` → `True` | ⭐ |
| `isupper()` | Все буквы заглавные | `"ABC".isupper()` → `True` | ⭐ |
| `istitle()` | Каждое слово с заглавной | `"Hello World".istitle()` → `True` | ⭐ |
| `isnumeric()` | Числовые символы (в т.ч. римские, дроби) | `"Ⅷ".isnumeric()` → `True` | ⭐ |
| `isdecimal()` | Только десятичные цифры | `"123".isdecimal()` → `True` | ⭐ |
| `isidentifier()` | Годится ли как имя переменной | `"my_var".isidentifier()` → `True` | ⭐ |
| `isprintable()` | Все символы печатаемые | `"hi\n".isprintable()` → `False` | ⭐ |
| `isascii()` | Все символы ASCII (Python 3.7+) | `"hello".isascii()` → `True` | ⭐ |

```python
print("abc".isalpha())        # True
print("123".isdigit())        # True
print("ab12".isalnum())       # True
print("  ".isspace())         # True
print("Hello".istitle())      # True
print("my_var".isidentifier()) # True
```

!!! info "Подробнее: `isdigit` vs `isnumeric` vs `isdecimal` 🔬"
    Это классический вопрос-ловушка.
    - `isdecimal()` — только `0-9` (и аналоги в других языках)
    - `isdigit()` — `0-9` + верхние индексы (`²`), но не дроби
    - `isnumeric()` — вообще всё числовое: `½`, `Ⅷ`, `²`
    
    Для обычного кода достаточно `isdigit()`.

## 🔬 Редкие методы (почти не используются, но полезно знать)

| Метод | Что делает | Пример | ⭐ |
|---|---|---|---|
| `encode(enc)` | Превратить в байты | `"hi".encode("utf-8")` → `b'hi'` | ⭐⭐ |
| `expandtabs(n)` | Заменить `\t` на пробелы | `"a\tb".expandtabs(4)` → `"a   b"` | ⭐ |
| `format()` | Форматирование строк | см. [страницу про форматирование](formatting.md) | ⭐⭐⭐ |
| `format_map(d)` | `format()` со словарём напрямую | `"{name}".format_map({"name":"Аня"})` → `"Аня"` | ⭐ |
| `maketrans(a, b)` | Создать таблицу перевода | см. ниже | ⭐ |
| `translate(table)` | Применить таблицу перевода | `"abc".translate(t)` | ⭐ |
| `partition()` | См. «Разрезание и склейка» | — | ⭐ |
| `rpartition()` | См. «Разрезание и склейка» | — | ⭐ |

### `translate` + `maketrans` — пример

Это «продвинутая замена». Сначала создаётся таблица перевода, потом она применяется:

```python
# Таблица: 'a' → '1', 'b' → '2', 'c' → '3'
table = str.maketrans("abc", "123")
print("abcabc".translate(table))   # 123123

# Можно удалять символы, указав третий аргумент:
table2 = str.maketrans("abc", "123", "xyz")   # x, y, z удалить
print("axbyc".translate(table2))   # 123
```

!!! info "Подробнее: зачем это нужно 🔬"
    `translate` быстрее, чем `replace` в цикле. Применяется в задачах
    шифрования, замены «непечатных» символов, нормализации Unicode.
    В обычном коде — редкость.

### `expandtabs` — пример

```python
print("a\tb\tc".expandtabs(4))
# a   b   c
```

По умолчанию таб «разворачивается» в 8 пробелов. Полезно при выводе таблиц.

| Задача | Метод |
|---|---|
| Сделать заглавными | `upper()` |
| Сделать строчными | `lower()` |
| Убрать пробелы | `strip()` |
| Найти подстроку | `find()` / `index()` |
| Заменить | `replace()` |
| Разбить по пробелам | `split()` |
| Склеить | `join()` |

| Заменить много символов сразу | `translate()` |

## ⚠️ Частые ошибки

!!! warning "Ошибка 1. Строки неизменяемы"
    ```python
    s = "привет"
    s.upper()      # ничего не произошло!
    print(s)       # "привет"
    ```
    **Правильно:**
    ```python
    s = s.upper()
    print(s)       # "ПРИВЕТ"
    ```

!!! warning "Ошибка 2. `strip("ab")` убирает любые a и b"
    ```python
    "baba".strip("ab")    # '' — а не 'ba'
    ```
    Хотите убрать именно суффикс — используйте `removesuffix`.

!!! warning "Ошибка 3. `find` вернул `-1`, а вы думаете, что ноль"
    ```python
    if text.find("xyz"):        # ❌ -1 это True, а 0 это False!
    ```
    **Правильно:**
    ```python
    if text.find("xyz") != -1:
    # или
    if "xyz" in text:
    ```

!!! warning "Ошибка 4. `index` падает, если не нашёл"
    ```python
    "привет".index("xyz")   # ❌ ValueError
    ```
    Если не уверены — используйте `find`.

!!! warning "Ошибка 5. `replace` не меняет исходную строку"
    ```python
    s = "банан"
    s.replace("а", "о")     # "бонон" — но в s всё ещё "банан"
    ```
    **Правильно:**
    ```python
    s = s.replace("а", "о")
    ```

## 🧪 Упражнения

1. ⭐ Дана строка `"Python — это круто"`. Выведите её в верхнем регистре.
2. ⭐ Спросите имя пользователя и выведите его с заглавной буквы (`.capitalize()`).
3. ⭐⭐ Проверьте, начинается ли строка `"test@mail.ru"` на `"test"`.
4. ⭐⭐ Разбейте `"яблоко,банан,груша"` на список по запятой.
5. ⭐⭐ Склейте `["2024", "01", "15"]` через дефис, чтобы получилось `"2024-01-15"`.

7. ⭐⭐⭐ Уберите все пробелы по краям, потом разбейте по пробелам, потом склейте через один пробел — «нормализация».
