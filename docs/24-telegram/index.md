# Telegram-боты

**Telegram-бот** — программа, которая общается с пользователями в мессенджере. Боты умеют отправлять сообщения, принимать команды, показывать кнопки, отправлять картинки, работать с БД.

Это **самый доступный способ** сделать «настоящее» приложение, которое увидят другие люди: не нужно публиковать на хостинге, не нужен свой сервер — достаточно Python и токена.

!!! tip "Кому подходит"
    **8–11 класс**. Нужны: функции, словари, JSON, желательно requests.

## 🤖 Что делают боты

- **Утилиты**: напоминалки, погода, курс валют, таймеры
- **Игры**: викторины, «угадай число», квесты
- **Магазины**: каталог, заказы, оплата
- **Оповещения**: подписки, уведомления
- **Админ-панели**: управление сервисом

## 🚀 Первый шаг — получить токен

1. Откройте Telegram, найдите **@BotFather**
2. Напишите `/newbot`
3. Задайте **имя** бота (видно пользователям), например `Мой первый бот`
4. Задайте **username** — должен заканчиваться на `bot`: `my_python_test_bot`
5. BotFather выдаст **токен** вида:
   ```
   1234567890:ABCdefGHIjklMNOpqrsTUVwxyz-1234567
   ```

**Никому не показывайте токен!** Через него можно управлять ботом.

!!! warning "Токен в Git"
    Никогда не коммитьте токен в открытый репозиторий. Храните в
    переменной окружения или `.env`-файле, а `.env` добавьте в `.gitignore`.

## 🚀 Первый запуск

```python
import asyncio
from aiogram import Bot, Dispatcher
from aiogram.filters import CommandStart

BOT_TOKEN = "ВСТАВЬТЕ_ТОКЕН"
bot = Bot(token=BOT_TOKEN)
dp = Dispatcher()

@dp.message(CommandStart())
async def start(message):
    await message.answer(f"Привет, {message.from_user.first_name}!")

async def main():
    await dp.start_polling(bot)

if __name__ == "__main__":
    asyncio.run(main())
```

Запустите — и напишите боту `/start`.
