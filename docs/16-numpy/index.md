# NumPy

`NumPy` (**Num**erical **Py**thon) — фундамент всей научной работы на Python. Это библиотека для **быстрых вычислений над массивами чисел**.

Если pandas — это таблицы, то NumPy — их «сердце». Под ним работают
matplotlib, scikit-learn, TensorFlow, pandas и сотни других библиотек.

!!! tip "Кому подходит"
    **9–11 класс**. Нужны списки и циклы. Остальное разберём.

## 🎯 Зачем NumPy

Сравните — сложить два миллиона чисел:

```python
# Обычный Python: ~0.1 секунды
a = list(range(1_000_000))
b = list(range(1_000_000))
c = [x + y for x, y in zip(a, b)]

# NumPy: ~0.005 секунды — в 20 раз быстрее
import numpy as np
a = np.arange(1_000_000)
b = np.arange(1_000_000)
c = a + b
