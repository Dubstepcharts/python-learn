# Kivy — мобильные приложения

`Kivy` — библиотека для создания **кроссплатформенных** приложений с
графическим интерфейсом: Windows, macOS, Linux, **Android**, **iOS**.
Особенность — «жесты», мультитач, поддержка мобильной вёрстки.

На Kivy можно сделать мобильную игру или приложение и **собрать APK для
Android** — установить на телефон.

!!! tip "Кому подходит"
    **9–11 класс**. Нужны знания: ООП, классы. Kivy активно использует
    наследование и свойства.
