# scikit-learn — машинное обучение

`scikit-learn` (`sklearn`) — **главная библиотека машинного обучения** на Python. Работает с готовыми алгоритмами: классификация, регрессия, кластеризация, уменьшение размерности.

Если pandas — таблицы, matplotlib — графики, то sklearn — **модели**.

!!! tip "Кому подходит"
    **10–11 класс**. Нужны: NumPy, pandas, базовое понимание статистики.
    Настоящее ML — это отдельная профессия, но **основы** осваиваются быстро.

## 🎯 Типы задач ML

| Тип | Что делает | Примеры |
|---|---|---|
| **Классификация** | Отнести к категории | Спам/не спам, сорт ириса |
| **Регрессия** | Предсказать число | Цена квартиры, температура |
| **Кластеризация** | Разбить на группы | Сегментация клиентов |
| **Уменьшение размерности** | Сжать признаки | PCA |
| **Обучение с учителем** | Есть правильные ответы | Классификация, регрессия |
| **Обучение без учителя** | Ответов нет | Кластеризация, PCA |
