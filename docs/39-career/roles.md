## 📌 Основные направления

### Backend-разработчик

**Что делает:** серверная логика, API, базы данных, интеграции.

**Стек:** Python (Django/FastAPI), PostgreSQL, Redis, Docker, Linux.

**Зарплата (Россия, junior):** 80–150 тыс. руб.

**Кому подходит:** любит алгоритмы, структуры, оптимизацию.

---

### Frontend-разработчик

**Что делает:** интерфейс сайта, который видит пользователь.

**Стек:** HTML, CSS, JavaScript/TypeScript, React/Vue.

**Зарплата:** 80–150 тыс. руб.

**Кому подходит:** любит визуал, UX, дизайн.

---

### Fullstack-разработчик

**Что делает:** и frontend, и backend. Универсал.

**Стек:** Python + JS, или JS везде (Node.js).

**Зарплата:** 100–180 тыс. руб.

**Кому подходит:** хочет делать проект целиком.

---

### Data Scientist / ML Engineer

**Что делает:** строит модели машинного обучения, анализирует данные.

**Стек:** Python, NumPy, pandas, scikit-learn, PyTorch, SQL.

**Зарплата:** 100–200 тыс. руб.

**Кому подходит:** любит математику, статистику, данные.

---

### Data Engineer

**Что делает:** строит пайплайны данных, ETL.

**Стек:** Python, SQL, Airflow, Spark, Kafka.

**Зарплата:** 100–200 тыс. руб.

**Кому подходит:** любит инфраструктуру, автоматизацию.

---

### DevOps / SRE

**Что делает:** автоматизирует развёртывание, следит за стабильностью.

**Стек:** Linux, Docker, Kubernetes, CI/CD, Terraform, Prometheus.

**Зарплата:** 120–250 тыс. руб.

**Кому подходит:** любит Linux, сети, автоматизацию.

---

### Mobile-разработчик

**Что делает:** приложения для iOS/Android.

**Стек:**
- iOS: Swift, SwiftUI
- Android: Kotlin, Jetpack Compose
- Кросс-платформа: Flutter (Dart), React Native

**Зарплата:** 80–180 тыс. руб.

**Кому подходит:** хочет делать мобильные приложения.

---

### QA-инженер (тестировщик)

**Что делает:** тестирует ПО вручную и автоматизированно.

**Стек:** Python, Selenium, Playwright, pytest, Postman.

**Зарплата:** 60–150 тыс. руб.

**Кому подходит:** внимательный, любит находить баги.

---

### Game Developer

**Что делает:** игры.

**Стек:** Unity (C#), Unreal Engine (C++), Godot.

**Зарплата:** 80–200 тыс. руб.

**Кому подходит:** любит игры, графика, физика.

---

### Security Engineer

**Что делает:** защищает системы, ищет уязвимости.

**Стек:** Linux, сети, криптография, Burp Suite, Metasploit.

**Зарплата:** 100–250 тыс. руб.

**Кому подходит:** любит «взламывать», CTF.

---

### Технический писатель

**Что делает:** пишет документацию.

**Стек:** Markdown, Git, знание продукта.

**Зарплата:** 60–150 тыс. руб.

**Кому подходит:** любит писать, объяснять.

---

### Product Manager

**Что делает:** решает, **что** делать, руководит разработкой.

**Стек:** аналитика, метрики, интервью с пользователями.

**Зарплата:** 120–250 тыс. руб.

**Кому подходит:** нравится общение, стратегия.

## 📌 С чего начать (для школьника)

**Python — хорошая база для всего.** Дальше:

- **Backend** → Django/FastAPI, БД, Docker
- **Data Science** → pandas, sklearn, PyTorch
- **DevOps** → Linux, Docker, CI/CD
- **Mobile** → Kotlin или Swift
- **Frontend** → JavaScript, React

**Не надо учить всё.** Выберите одно, углубитесь.

## 📌 Что важно для всех

- **Английский** — без него никак. Документация, статьи, конференции.

## ⚠️ Частые ошибки

!!! warning "Учить всё сразу"
    Выберите **одно** направление. Распыление — путь в никуда.

!!! warning "«Выучу 10 языков»"
    Лучше **один язык** до уровня middle, чем 10 языков на уровне «hello world».

!!! warning "Игнорировать математику"
    Для ML и алгоритмов — **критично**. Для frontend — можно меньше.

!!! warning "Ждать «идеального» момента"
    Начинать нужно **сейчас**. Даже с малого проекта.

!!! warning "Только курсы, без практики"
    Видео смотреть — не программировать. **Пишите код** параллельно.
