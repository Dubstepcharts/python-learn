## 📌 Из чего состоит интервью

**Типичный процесс** (для junior-разработчика):

1. **Screening** — звонок с HR, 15–30 минут
2. **Тестовое задание** — 1–5 дней, делаете дома
3. **Техническое интервью** — 1–2 часа, live coding
4. **Финальное** — с тимлидом, о вас и целях
5. **Оффер**

## 📌 Классические задачи

### FizzBuzz

Вывести числа от 1 до 100: если кратно 3 — «Fizz», 5 — «Buzz», 15 — «FizzBuzz».

```python
for i in range(1, 101):
    if i % 15 == 0:
        print("FizzBuzz")
    elif i % 3 == 0:
        print("Fizz")
    elif i % 5 == 0:
        print("Buzz")
    else:
        print(i)
```

### Two Sum

Найти два числа, сумма которых равна target.

```python
def two_sum(nums, target):
    seen = {}
    for i, n in enumerate(nums):
        if target - n in seen:
            return [seen[target - n], i]
        seen[n] = i
```

### Reverse String

```python
def reverse(s):
    return s[::-1]
```

### Palindrome

```python
def is_palindrome(s):
    s = "".join(c.lower() for c in s if c.isalnum())
    return s == s[::-1]
```

### Анаграммы

```python
from collections import Counter

def is_anagram(a, b):
    return Counter(a) == Counter(b)
```

### FizzBuzz на графах: DFS

```python
def dfs(graph, start):
    visited = set()
    stack = [start]
    while stack:
        node = stack.pop()
        if node in visited:
            continue
        visited.add(node)
        print(node)
        stack.extend(graph[node])
```

## 📌 Pet-проекты

**Что ценно:**

- Решает **реальную** задачу
- Есть README с описанием, скриншотами, инструкцией
- Есть тесты (pytest)
- Есть CI (GitHub Actions)
- Использует **несколько** технологий (Python + БД + API)
- Чистая история коммитов

**Примеры сильных проектов:**

- Telegram-бот с БД и аналитикой
- FastAPI-сервис с авторизацией и Docker
- Парсер, который пишет в БД и строит графики
- Свой маленький движок игр на pygame
- Чат на WebSocket

**Слабые:**
- Todo-list без тестов и деплоя
- Копия туториала (если добавили своё — ок)
- 10 проектов, все брошены

## 📌 Что спрашивать у компании

- Какие задачи будут?
- Какой стек?
- Кто ментор? Как проходит onboarding?
- Какой график? (для школьника — важно)
- Удалёнка или офис?

**Помните:** интервью — **двусторонний** процесс. Компания выбирает вас,
но и вы — её.

## 📌 План подготовки (6 месяцев)

**Месяц 1–2:**

- Python: углубиться в ООП, исключения, модули
- Git: ветки, PR
- SQL: SELECT, JOIN, GROUP BY

**Месяц 3:**

- Алгоритмы: массивы, строки, hash-table
- 50 задач на LeetCode Easy
- Свой pet-проект

**Месяц 4:**

- Flask или FastAPI
- SQLAlchemy
- Docker
- Deploy

**Месяц 5:**

- LeetCode Medium: 50 задач
- System design (базовое)
- Резюме, GitHub-профиль

**Месяц 6:**

- Отклики
- Тестовые задания
- Интервью

**Реальный срок для школьника — 1–2 года.** Не спешите.

## 📌 Soft skills на интервью

- **Не паникуйте**, если не знаете. Скажите: «Могу порассуждать вслух?»
- **Думайте вслух.** Интервьюер хочет видеть **как** вы думаете.
- **Задавайте уточняющие вопросы.** Это плюс, а не минус.
- **Тестируйте код** после написания. Краевые случаи.
- **Признавайте ошибки.** Все их делают.
- **Будьте честны.** Лучше «не знаю, но могу разобраться», чем блеф.

## ⚠️ Частые ошибки

!!! warning "Зубрить решения"
    Заучивать бесполезно. Понимать **подход**.

!!! warning "Игнорировать pet-проекты"
    Резюме без проектов = резюме без шансов.

!!! warning "Врать в резюме"
    Спросят на интервью — сгорит. Пишите только правду.

!!! warning "Не задавать вопросы"
    Согласие на всё — плохой сигнал. Компания тоже должна подойти **вам**.

!!! warning "Откликаться в 50 мест одновременно"
    Лучше 10 качественных. Иначе не хватит сил на тестовые.

!!! warning "Сдаваться после первого отказа"
    Обычно нужно 5–20 попыток. Каждый отказ — урок.
