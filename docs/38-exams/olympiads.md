## 📌 Зачем олимпиады

- **Поступление в вуз без ЕГЭ** (победа в перечневой олимпиаде)

- **Работа**: IT-компании ценят олимпиадников (Яндекс, Google)

## 📌 Что решают на олимпиадах

Задачи **значительно сложнее** ЕГЭ. Типичные темы:

- Динамическое программирование (DP)
- Графы: BFS, DFS, Dijkstra, минимальное остовное дерево
- Деревья отрезков (segment tree)
- Префиксные суммы
- Хеширование
- Жадные алгоритмы
- Теория чисел
- Комбинаторика
- Геометрия

**Языки:** C++ (почти всегда), реже Python, Java.

!!! tip "Python на олимпиадах"
    Python **разрешён** на большинстве олимпиад, но **медленнее** C++ в
    20–100 раз. Для сложных задач — только C++.
    
    **Но:** начинать с Python можно и нужно. Освоив алгоритмы на Python,
    легко перейти на C++.

## 📌 Классические задачи

### Задача 1. Сумма на отрезке

Даны массив и запросы «сумма с L по R». Нужно отвечать за O(1).

**Префиксные суммы:**

```python
a = [1, 2, 3, 4, 5]

prefix = [0] * (len(a) + 1)
for i in range(len(a)):
    prefix[i + 1] = prefix[i] + a[i]

def range_sum(l, r):
    return prefix[r + 1] - prefix[l]

print(range_sum(1, 3))    # 2 + 3 + 4 = 9
```

### Задача 2. Кратчайший путь

Взвешенный граф, найти кратчайший путь от A до B.

**Алгоритм Дейкстры:**

```python
import heapq

def dijkstra(graph, start):
    dist = {node: float("inf") for node in graph}
    dist[start] = 0
    pq = [(0, start)]

    while pq:
        d, node = heapq.heappop(pq)
        if d > dist[node]:
            continue
        for neighbor, weight in graph[node]:
            new_dist = d + weight
            if new_dist < dist[neighbor]:
                dist[neighbor] = new_dist
                heapq.heappush(pq, (new_dist, neighbor))

    return dist

graph = {
    "A": [("B", 1), ("C", 4)],
    "B": [("C", 2), ("D", 5)],
    "C": [("D", 1)],
    "D": [],
}
print(dijkstra(graph, "A"))
```

### Задача 3. Рюкзак

Даны предметы с весом и ценой. Максимальная стоимость при вместимости W.

**Динамическое программирование:**

```python
def knapsack(items, capacity):
    n = len(items)
    dp = [[0] * (capacity + 1) for _ in range(n + 1)]

    for i in range(1, n + 1):
        w, v = items[i - 1]
        for c in range(capacity + 1):
            dp[i][c] = dp[i - 1][c]
            if c >= w:
                dp[i][c] = max(dp[i][c], dp[i - 1][c - w] + v)

    return dp[n][capacity]

items = [(2, 3), (3, 4), (4, 5), (5, 6)]
print(knapsack(items, 5))    # 7
```

### Задача 4. Longest Increasing Subsequence

Найти самую длинную возрастающую подпоследовательность.

```python
import bisect

def lis(nums):
    tails = []
    for x in nums:
        i = bisect.bisect_left(tails, x)
        if i == len(tails):
            tails.append(x)
        else:
            tails[i] = x
    return len(tails)

print(lis([10, 9, 2, 5, 3, 7, 101, 18]))    # 4
```

## 📌 Процесс решения задачи

1. **Прочитать** условие **дважды**
2. **Понять**, что дано и что найти
3. **Разобрать пример** вручную
4. **Придумать** наивное решение
5. **Оценить** сложность — проходит?
6. **Если нет** — искать более эффективное
7. **Написать код**, проверить на примере
8. **Придумать краевые случаи** (пустой ввод, 0, максимум)
9. **Проверить** на них
10. **Отправить**

**Не сдавайтесь на 30 минут.** Если застряли — переходите к другой
задаче, вернитесь позже.

## 📌 Codeforces: как начать

1. Зарегистрируйтесь
2. Решайте **архив**: **Problemset → по тегам → по сложности**
3. Начните с **800** рейтинга
4. Участвуйте в **Div. 4** раундах
5. Смотрите **разборы** после раундов — даже если решили

**Цель:** 100–200 решённых задач до 1200 рейтинга.

## ⚠️ Частые ошибки

!!! warning "Решать только лёгкое"
    Рост происходит на границе. Берите задачи, где застреваете на 20–60
    минут.

!!! warning "Смотреть решение сразу"
    Помучайтесь 30–60 минут. Потом смотрите разбор — он запомнится лучше.

!!! warning "Не разбирать ошибки"
    Лучший урок — из WA (Wrong Answer). Что не учли? Какой крайний случай?

!!! warning "Прыгнуть на C++ сразу"
    Python проще для алгоритмов. C++ — когда упрётесь в производительность.

!!! warning "Забросить на месяц"
    Регулярность важнее интенсивности. 1 час в день лучше, чем 10 часов
    раз в неделю.
