## 📌 Типичные задачи на программирование

### Задача 24 — обработка строк

**Пример:** дан текст, найти самую длинную последовательность символов,
не содержащую букву «A».

```python
with open("24.txt", encoding="utf-8") as f:
    s = f.readline().strip()

max_len = 0
current = 0
for ch in s:
    if ch != "A":
        current += 1
        max_len = max(max_len, current)
    else:
        current = 0

print(max_len)
```

**Стратегия:** внимательно прочитать условие. «Самая длинная цепочка, где
выполняется X» → один проход по строке.

### Задача 25 — поиск чисел

**Пример:** найти все числа в диапазоне `[a, b]`, у которых ровно 4
делителя.

```python
def count_divisors(n):
    count = 0
    i = 1
    while i * i <= n:
        if n % i == 0:
            count += 1
            if i != n // i:
                count += 1
        i += 1
    return count

for n in range(1000, 10000):
    if count_divisors(n) == 4:
        print(n)
```

**Стратегия:** эффективные переборы. Проверка делителей — до √n.

### Задача 27 — сложная обработка данных

Классика: кластеры, поиск max/min, группировки, оптимизация.

**Пример** (упрощённо): найти кластер с максимальным средним.

```python
points = []
with open("27-A.txt") as f:
    for line in f:
        x, y = map(int, line.split())
        points.append((x, y))

# Группировка по квадрантам (условие обычно в задаче)
clusters = {
    "top_left": [], "top_right": [],
    "bottom_left": [], "bottom_right": [],
}
for x, y in points:
    if x < 0 and y > 0:
        clusters["top_left"].append((x, y))
    # ...

# Для каждого кластера — среднее
for name, pts in clusters.items():
    if pts:
        cx = sum(x for x, _ in pts) / len(pts)
        cy = sum(y for _, y in pts) / len(pts)
        print(f"{name}: ({cx:.2f}, {cy:.2f})")
```

**Стратегия:** разбить на этапы. Сначала загрузить, потом сгруппировать,
потом посчитать. **Часто есть подвох** — например, кластеры пересекаются
и нужен ещё один фильтр.

## 📌 Разбор одной задачи (№ 27)

**Условие (упрощённо):** дан файл с парами чисел `(x, y)`. Найти
кластер с максимальным числом точек, зная, что кластеры не пересекаются.

**Решение:**

```python
with open("27.txt") as f:
    points = [tuple(map(float, line.split())) for line in f if line.strip()]

# Кластеризация: каждый новый кластер — если точка далеко от всех
clusters = []
for x, y in points:
    placed = False
    for c in clusters:
        cx, cy = c["center"]
        if ((x - cx) ** 2 + (y - cy) ** 2) ** 0.5 < 5:
            c["points"].append((x, y))
            c["center"] = (
                sum(p[0] for p in c["points"]) / len(c["points"]),
                sum(p[1] for p in c["points"]) / len(c["points"]),
            )
            placed = True
            break
    if not placed:
        clusters.append({"center": (x, y), "points": [(x, y)]})

biggest = max(clusters, key=lambda c: len(c["points"]))
print(f"Больший кластер: {len(biggest['points'])} точек")
print(f"Центр: ({biggest['center'][0]:.2f}, {biggest['center'][1]:.2f})")
```

**Что важно:**
- Не торопиться, разбить задачу на этапы
- Проверить **на малом** файле вручную
- Проверить **на большом** — не падает ли
- Округлить **так, как просят**
