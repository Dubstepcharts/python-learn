# Turtle — рисование черепашкой 🐢

`turtle` — встроенный модуль Python для рисования. По экрану ползёт «черепашка», оставляя за собой след. Ты командуешь: «вперёд 100», «направо 90», — и черепашка рисует.

Это идеальный инструмент для первых шагов в программировании: **видно результат** сразу, а команды простые, как в Scratch.

!!! tip "Кому подходит"
    - **5–7 класс** — самое то: игры с фигурами, рисунки, узоры
    - **8–11 класс** — тоже полезно: рекурсивные фракталы (снежинка Коха,
      треугольник Серпинского), деревья, генеративное искусство
