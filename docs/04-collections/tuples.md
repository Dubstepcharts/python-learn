## 🍎 Объясняем просто

!!! example "Кортеж — как фотография"
    Список — как альбом, куда можно вклеивать новые фото. Кортеж — как
    одна фотография: что попало в кадр, то и останется. Изменить нельзя.

    ```python
    point = (10, 20)             # координата
    date = (2024, 1, 15)         # дата
    rgb = (255, 128, 0)          # цвет
    ```

    В кортеже живут **связанные** значения, которые логично хранить вместе.

---

## 📖 Что такое кортеж

**Кортеж** (`tuple`) — упорядоченная, но **неизменяемая** коллекция.

| Свойство | Значение |
|---|---|
| Изменяемый? | ❌ Нет |
| Порядок важен? | ✅ Да |
| Дубликаты? | ✅ Да |
| Индексы и срезы? | ✅ Работают как у списка |

```python
empty = ()
single = (42,)            # ← запятая обязательна!
point = (10, 20)
person = ("Аня", 12, "Москва")
```

!!! warning "Кортеж из одного элемента — запятая!"
    ```python
    a = (42)     # это просто число 42, не кортеж!
    b = (42,)    # ✅ кортеж из одного элемента
    c = 42,      # тоже кортеж (запятая важнее скобок)
    ```

## 🎯 Зачем кортежи, если есть списки

1. **Защита от изменений** — если данные не должны меняться, кортеж не даст это сделать случайно
2. **Скорость** — кортежи немного быстрее
3. **Хешируемость** — кортеж можно использовать как ключ в словаре или элемент множества, список — нельзя
4. **Возврат нескольких значений** — функция может вернуть сразу несколько значений как кортеж
5. **Логика** — «это фиксированная структура», а не «набор, который растёт»

```python
# Ключ в словаре — только кортеж
data = {
    (10, 20): "точка A",
    (30, 40): "точка B",
}
```

## ✍️ Создание кортежа

```python
# Литералом
a = (1, 2, 3)

# Без скобок
b = 1, 2, 3

# Из списка
c = tuple([1, 2, 3])

# Из строки
d = tuple("abc")           # ('a', 'b', 'c')

# Из range
e = tuple(range(5))        # (0, 1, 2, 3, 4)

# Один элемент
f = (42,)                  # обязательно с запятой
```

## 🔢 Индексы и срезы

Работают точно так же, как у списка:

```python
t = (10, 20, 30, 40, 50)

print(t[0])          # 10
print(t[-1])         # 50
print(t[1:3])        # (20, 30)
print(t[::-1])       # (50, 40, 30, 20, 10)
print(20 in t)       # True
print(len(t))        # 5
```

Но **изменить нельзя**:

```python
t[0] = 99            # ❌ TypeError
```

## 🎯 Все методы кортежа

Их всего два — потому что менять кортеж нельзя.

| Метод | Что делает | Пример | ⭐ |
|---|---|---|---|
| `count(x)` | Сколько раз встречается | `(1, 2, 2, 3).count(2)` → `2` | ⭐⭐ |
| `index(x)` | Индекс первого вхождения | `(1, 2, 3).index(2)` → `1` | ⭐⭐ |

Всё остальное — через функции: `len`, `sum`, `max`, `min`, `sorted`, `in`.

```python
t = (5, 3, 8, 1)

print(len(t))         # 4
print(sum(t))         # 17
print(max(t))         # 8
print(min(t))         # 1
print(sorted(t))      # [1, 3, 5, 8] — список!
print(t.count(3))     # 1
print(t.index(8))     # 2
```

## 🔓 Распаковка кортежей

Мощная возможность Python:

```python
point = (10, 20)
x, y = point
print(x, y)          # 10 20

# Обмен без третьей переменной
a, b = 1, 2
a, b = b, a
print(a, b)          # 2 1

# Звёздочка для «остального»
first, *rest = (1, 2, 3, 4, 5)
print(first)         # 1
print(rest)          # [2, 3, 4, 5]

*init, last = (1, 2, 3, 4, 5)
print(init)          # [1, 2, 3, 4]
print(last)          # 5

a, *middle, b = (1, 2, 3, 4, 5)
print(a)             # 1
print(middle)        # [2, 3, 4]
print(b)             # 5
```

!!! tip "Игнорирование лишних значений"
    ```python
    x, _, z = (1, 2, 3)    # _ — «второе значение не нужно»
    ```
    По соглашению `_` означает «не важно».

## 🔄 Преобразования

```python
# Список → кортеж
t = tuple([1, 2, 3])

# Кортеж → список
lst = list((1, 2, 3))

# Кортеж → строка
s = "-".join(("a", "b", "c"))    # "a-b-c"

# Строка → кортеж
chars = tuple("abc")             # ('a', 'b', 'c')
```

## 💡 Примеры

### Пример 1. Возврат нескольких значений 🎯

```python
def min_max(numbers):
    return min(numbers), max(numbers)   # вернёт кортеж

nums = [3, 7, 1, 9, 5]
low, high = min_max(nums)
print(low, high)   # 1 9
```

Это самая частая причина использовать кортежи.

### Пример 2. Сюжетный — координаты 🗺️

```python
route = [(0, 0), (10, 5), (20, 0), (30, 10)]

for i, (x, y) in enumerate(route):
    print(f"Точка {i}: x={x}, y={y}")
```

Обратите внимание: `(x, y)` распаковывается прямо в цикле.

### Пример 3. Дни недели 📅

```python
DAYS = ("Пн", "Вт", "Ср", "Чт", "Пт", "Сб", "Вс")

for i, day in enumerate(DAYS, start=1):
    print(f"{i}. {day}")
```

Капсом `DAYS` — намёк, что это «константа», менять не надо.

### Пример 4. Кортеж как ключ словаря 🔑

```python
distances = {
    ("Москва", "Питер"): 705,
    ("Москва", "Казань"): 820,
    ("Питер", "Казань"): 1540,
}

print(distances[("Москва", "Питер")])   # 705
```

### Пример 5. `zip` — соединение кортежами 🔗

```python
names = ["Аня", "Борис", "Вика"]
ages = [12, 11, 13]

pairs = list(zip(names, ages))
print(pairs)   # [('Аня', 12), ('Борис', 11), ('Вика', 13)]

for name, age in zip(names, ages):
    print(f"{name} — {age}")
```

## 📌 Когда кортеж, когда список

| Ситуация | Что выбрать |
|---|---|
| Данные не должны меняться (дни недели, цвета RGB) | ✅ Кортеж |
| Функция возвращает несколько значений | ✅ Кортеж |
| Нужен ключ в словаре | ✅ Кортеж |
| Набор растёт/меняется | ✅ Список |
| Нужны методы `append`, `sort` | ✅ Список |
| Не уверен | ✅ Список (его проще менять) |

## ⚠️ Частые ошибки

!!! warning "Ошибка 1. Забыли запятую в кортеже из одного элемента"
    ```python
    a = (42)      # это int, не tuple!
    a = (42,)     # ✅
    ```

!!! warning "Ошибка 2. Попытка изменить кортеж"
    ```python
    t = (1, 2, 3)
    t[0] = 99     # ❌ TypeError
    ```
    Нужно менять — используйте список.

!!! warning "Ошибка 3. Путаница скобок"
    ```python
    a = (1, 2, 3)    # tuple
    b = [1, 2, 3]    # list
    c = {1, 2, 3}    # set (множество!) — не кортеж
    ```
    Фигурные скобки — это не кортеж, а множество или словарь.

!!! warning "Ошибка 4. Кортеж с изменяемыми элементами"
    ```python
    t = (1, [2, 3])
    t[1].append(4)   # это РАБОТАЕТ
    print(t)         # (1, [2, 3, 4])
    ```
    Кортеж неизменяем **сам**, но может содержать изменяемые объекты.
    Это не ошибка, но легко запутаться.
