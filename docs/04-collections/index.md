# Коллекции

Иногда нужно хранить не одно значение, а много: список покупок, набор оценок, имена учеников. Для этого в Python есть **коллекции** — контейнеры, в которых живёт много значений сразу.

В этом разделе — четыре основных типа коллекций и генераторы, которые делают код коротким и красивым.

!!! tip "Как учиться"
    Списки — самые используемые. Освойте их в первую очередь. Кортежи, словари
    и множества — по мере надобности. Генераторы (comprehensions) — когда
    почувствуете уверенность с обычными циклами.

## 📊 Сравнение четырёх типов

| Тип | Изменяемый? | Порядок важен? | Дубликаты? | Пример |
|---|---|---|---|---|
| **Список** `list` | ✅ Да | ✅ Да | ✅ Да | `[1, 2, 3, 2]` |
| **Кортеж** `tuple` | ❌ Нет | ✅ Да | ✅ Да | `(1, 2, 3)` |
| **Словарь** `dict` | ✅ Да | ✅ Да (с 3.7) | Только ключи | `{"a": 1, "b": 2}` |
| **Множество** `set` | ✅ Да | ❌ Нет | ❌ Нет | `{1, 2, 3}` |
