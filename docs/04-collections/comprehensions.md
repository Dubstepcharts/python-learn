# Генераторы коллекций (comprehensions)

!!! abstract "Уровень: ⭐⭐⭐ Продвинутый"
    Подойдёт для 9–11 класса. Нужно знать: [списки](lists.md), [словари](dicts.md), [множества](sets.md), [цикл for](../02-control-flow/for.md).

---

## 🍎 Объясняем просто

!!! example "Цикл — но в одну строчку"
    Обычный цикл:
    ```python
    squares = []
    for x in range(1, 6):
        squares.append(x ** 2)
    ```

    То же через генератор:
    ```python
    squares = [x ** 2 for x in range(1, 6)]
    ```

    Результат один и тот же — список `[1, 4, 9, 16, 25]`. Но запись короче и
    читается «с одного взгляда». Такие конструкции называются
    **comprehensions** — «понимания» или «генераторы коллекций».

---

## 📖 Общая форма

```python
[выражение for элемент in последовательность if условие]
```

Читается так: «построй список из `выражения` для каждого `элемента`
из `последовательности`, если выполняется `условие`».

**Три составные части:**
1. **Выражение** — что положить в результат (`x ** 2`)
2. **Цикл** — по чему пройти (`for x in range(...)`)
3. **Условие** — (необязательно) фильтр (`if x % 2 == 0`)

---

## 📋 Виды генераторов

| Вид | Синтаксис | Результат |
|---|---|---|
| Список | `[x for x in ...]` | `list` |
| Множество | `{x for x in ...}` | `set` |
| Словарь | `{k: v for x in ...}` | `dict` |
| Генератор | `(x for x in ...)` | итератор (ленивый) |

---

## 📝 Список: list comprehension

### Простая форма

```python
# Квадраты чисел
squares = [x ** 2 for x in range(1, 6)]
print(squares)   # [1, 4, 9, 16, 25]

# Длины слов
words = ["привет", "мир", "программирование"]
lengths = [len(w) for w in words]
print(lengths)   # [6, 3, 16]

# Верхний регистр
upper = [w.upper() for w in ["a", "b", "c"]]
print(upper)   # ['A', 'B', 'C']
```

### С условием `if`

```python
# Только чётные
evens = [x for x in range(10) if x % 2 == 0]
print(evens)   # [0, 2, 4, 6, 8]

# Слова длиннее 5
words = ["я", "привет", "ты", "программирование"]
long_words = [w for w in words if len(w) > 5]
print(long_words)   # ['привет', 'программирование']

# Только положительные
nums = [-3, 5, -1, 8, -2]
positives = [n for n in nums if n > 0]
print(positives)   # [5, 8]
```

### С `if` и `else` в выражении

Здесь `if/else` **внутри** выражения, а не как фильтр:

```python
# Знак числа: + или -
nums = [-3, 5, -1, 8]
signs = ["+" if n > 0 else "-" for n in nums]
print(signs)   # ['-', '+', '-', '+']
```

!!! warning "Разница между `if` как фильтром и `if` в выражении"
    **Фильтр** (в конце, отбрасывает элементы):
    ```python
    [x for x in nums if x > 0]
    ```
    **Условное значение** (внутри выражения, меняет значение):
    ```python
    ["+" if x > 0 else "-" for x in nums]
    ```

### Вложенные циклы

```python
# Все пары (i, j) для i, j в 1..3
pairs = [(i, j) for i in range(1, 4) for j in range(1, 4)]
print(pairs)
# [(1,1), (1,2), (1,3), (2,1), ..., (3,3)]
```

Порядок такой же, как у вложенных `for` — внешний идёт первым.

### Вложенные условия

```python
nums = range(30)
result = [x for x in nums if x % 2 == 0 if x % 3 == 0]
# То же, что if x % 2 == 0 and x % 3 == 0
print(result)   # [0, 6, 12, 18, 24]
```

## 📝 Множество: set comprehension

```python
# Уникальные длины слов
words = ["мама", "папа", "я", "дом"]
lengths = {len(w) for w in words}
print(lengths)   # {2, 3, 4}

# Уникальные буквы
letters = {c.lower() for c in "Hello World"}
print(letters)   # {'h', 'e', 'l', 'o', ' ', 'w', 'r', 'd'}
```

Всё то же, что и в списках, только `[]` заменяются на `{}`.

## 📝 Словарь: dict comprehension

```python
# Число → его квадрат
squares = {x: x ** 2 for x in range(1, 6)}
print(squares)   # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# Слова → их длины
words = ["привет", "мир", "код"]
lengths = {w: len(w) for w in words}
print(lengths)   # {'привет': 6, 'мир': 3, 'код': 3}

# Из двух списков
names = ["Аня", "Борис", "Вика"]
ages = [12, 11, 13]
people = {name: age for name, age in zip(names, ages)}
print(people)   # {'Аня': 12, 'Борис': 11, 'Вика': 13}

# Поменять ключи и значения местами
d = {"a": 1, "b": 2}
flipped = {v: k for k, v in d.items()}
print(flipped)   # {1: 'a', 2: 'b'}
```

## 📝 Генератор: generator expression

Если обернуть в **круглые скобки**, получится не список, а **генератор** —
ленивый объект, который «достаёт» элементы по одному:

```python
gen = (x ** 2 for x in range(1, 6))
print(gen)        # <generator object ...>

# Можно пройти один раз
for n in gen:
    print(n)

# Или превратить в список
lst = list(x ** 2 for x in range(5))
```

!!! info "Подробнее: зачем генератор, если есть список? 🔬"
    **Список** создаёт все элементы **сразу** — занимает всю память.
    **Генератор** выдаёт элементы по одному — экономит память.
    
    Пример: `sum(x ** 2 for x in range(1_000_000))` — не создаёт список
    из миллиона чисел, а суммирует «на лету». Это намного эффективнее.
    
    Правило: если нужно только «пройти и агрегировать» (`sum`, `max`,
    `any`, `all`) — используйте генератор. Если нужны индексы, повторный
    проход или `len` — список.

## 💡 Примеры

### Пример 1. Цены со скидкой 🛒

```python
prices = [100, 250, 80, 400]
discounted = [p * 0.9 for p in prices]
print(discounted)   # [90.0, 225.0, 72.0, 360.0]
```

### Пример 2. Только совершеннолетние 🎓

```python
people = [("Аня", 12), ("Борис", 18), ("Вика", 20), ("Глеб", 15)]

adults = [name for name, age in people if age >= 18]
print(adults)   # ['Борис', 'Вика']
```

Обратите внимание — распаковка прямо в генераторе.

### Пример 3. Квадраты чётных 🎲

```python
result = [x ** 2 for x in range(1, 11) if x % 2 == 0]
print(result)   # [4, 16, 36, 64, 100]
```

### Пример 4. Сюжетный — таблица умножения 📊

```python
table = {n: [n * i for i in range(1, 4)] for n in [2, 5, 7]}
print(table)
# {2: [2, 4, 6], 5: [5, 10, 15], 7: [7, 14, 21]}
```

### Пример 5. Частоты слов 📈

```python
text = "кот пёс кот кот пёс"
counts = {w: text.split().count(w) for w in set(text.split())}
print(counts)   # {'кот': 3, 'пёс': 2}
```

### Пример 6. Плоский список из вложенного 🪆

```python
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]
flat = [x for row in matrix for x in row]
print(flat)   # [1, 2, 3, 4, 5, 6, 7, 8, 9]
```

## 📌 Когда использовать, а когда — нет

**Используйте comprehension**, если:
- Логика умещается в одну строку
- Задача — «построить коллекцию из другой коллекции»
- Нет побочных эффектов (не печатаете, не меняете другие переменные)

**Не используйте**, если:
- Внутри есть `print`, запись в файл, изменения состояния
- Логика длинная — станет нечитаемо
- Два-три уровня вложенности — сложно понять

**Плохо:**
```python
result = [print(x) for x in range(5)]   # ❌ print — побочный эффект
```

**Правильно:**
```python
for x in range(5):
    print(x)
```

## ⚡ Плюсы comprehensions

1. **Короче** — в 2–3 раза меньше кода
2. **Быстрее** — Python оптимизирует такие конструкции лучше, чем ручные циклы с `append`
3. **Понятнее** — если логика простая, читается «с одного взгляда»

## ⚠️ Минусы

1. **Сложно читать**, если логика запутанная
2. **Не подходит для побочных эффектов**
3. **Может съесть память**, если элементов очень много (тут помогает генератор)

---

## ⚠️ Частые ошибки

!!! warning "Ошибка 1. Слишком сложная логика"
    ```python
    result = [x if x > 0 else -x for x in nums if x != 0 if not x % 2]
    ```
    Три условия в одной строке — уже тяжело. Разбейте на части.

!!! warning "Ошибка 2. `print` внутри comprehension"
    ```python
    [print(x) for x in range(5)]   # работает, но считается плохим стилем
    ```

!!! warning "Ошибка 3. Путаница порядка в вложенных циклах"
    ```python
    # Порядок как в обычных циклах:
    [x + y for x in "ab" for y in "12"]
    # эквивалентно:
    result = []
    for x in "ab":
        for y in "12":
            result.append(x + y)
    ```

!!! warning "Ошибка 4. Ожидание, что `if/else` стоит в конце"
    ```python
    [x if x > 0 else -x for x in nums]     # ✅
    [x for x in nums if x > 0 else -x]     # ❌ SyntaxError
    ```
    Если есть `else` — он идёт в **выражение**, а не в фильтр.
