## 🍎 Объясняем просто

!!! example "Множество — как список без повторов"
    У тебя есть коробка, куда можно класть шарики. Но — если такой шарик
    уже лежит, второй такой же **не положится**. И порядок не важен.
    
    ```python
    nums = {1, 2, 3, 2, 1}
    print(nums)    # {1, 2, 3} — дубликаты исчезли
    ```

    Множество удобно, когда надо: «убрать повторы», «есть ли пересечение»,
    «какие элементы общие».

## 📖 Что такое множество

**Множество** (`set`) — неупорядоченная коллекция **уникальных** элементов:

| Свойство | Значение |
|---|---|
| Изменяемый? | ✅ Да (но `frozenset` — нет) |
| Порядок важен? | ❌ Нет |
| Дубликаты? | ❌ Нет |
| Индексы? | ❌ Нет |
| Хешируемые элементы? | ✅ Обязательно |

```python
empty = set()             # ← не {}! (это пустой словарь)
numbers = {1, 2, 3}
mixed = {1, "два", 3.0}

# Из списка — убирает дубликаты
unique = set([1, 2, 2, 3, 3, 3])   # {1, 2, 3}

# Из строки — все уникальные буквы
letters = set("hello")              # {'h', 'e', 'l', 'o'}
```

!!! warning "Пустое множество — только `set()`"
    ```python
    a = {}          # это ПУСТОЙ СЛОВАРЬ
    b = set()       # а это пустое множество
    ```

## 🎯 Зачем множества

1. **Убрать дубликаты** — `list(set(my_list))`
2. **Проверить наличие** — `x in my_set` работает **быстро** (быстрее, чем в списке)
3. **Математические операции** — объединение, пересечение, разность
4. **Уникальные элементы** — «какие буквы есть в слове», «какие теги у поста»

---

## 🎯 Все методы множества

### Добавление

| Метод | Что делает | Пример | ⭐ |
|---|---|---|---|
| `add(x)` | Добавить элемент | `s.add(5)` | ⭐⭐⭐ |
| `update(iter)` | Добавить несколько | `s.update([6, 7])` | ⭐⭐ |

```python
s = {1, 2, 3}
s.add(4)                  # {1, 2, 3, 4}
s.add(2)                  # ничего не изменилось
s.update([5, 6])          # {1, 2, 3, 4, 5, 6}
```

### Удаление

| Метод | Что делает | Пример | ⭐ |
|---|---|---|---|
| `remove(x)` | Удалить, ошибка если нет | `s.remove(5)` | ⭐⭐ |
| `discard(x)` | Удалить, **без** ошибки | `s.discard(5)` | ⭐⭐⭐ |
| `pop()` | Удалить и вернуть **случайный** | `s.pop()` | ⭐ |
| `clear()` | Очистить | `s.clear()` | ⭐⭐ |

```python
s = {1, 2, 3}

s.discard(2)          # {1, 3}
s.discard(99)         # {1, 3} — не ошибка
s.remove(1)           # {3}
# s.remove(99)        # ❌ KeyError
x = s.pop()           # x=3, s=set()
```

!!! tip "`remove` vs `discard`"
    - `remove` — падает, если элемента нет
    - `discard` — молча ничего не делает

    В большинстве случаев нужен **`discard`** — он безопаснее.

### Математика множеств

| Метод | Что делает | Оператор | ⭐ |
|---|---|---|---|
| `union(other)` | Объединение (всё вместе) | `\|` | ⭐⭐⭐ |
| `intersection(other)` | Пересечение (общее) | `&` | ⭐⭐⭐ |
| `difference(other)` | Разность (мои − чужие) | `-` | ⭐⭐⭐ |
| `symmetric_difference(other)` | Не общее (XOR) | `^` | ⭐⭐ |
| `update(other)` | `\|=` на месте | `\|=` | ⭐⭐ |
| `intersection_update(other)` | `&=` на месте | `&=` | ⭐ |
| `difference_update(other)` | `-=` на месте | `-=` | ⭐ |
| `symmetric_difference_update(other)` | `^=` на месте | `^=` | ⭐ |

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}

print(a | b)    # {1, 2, 3, 4, 5, 6} — объединение
print(a & b)    # {3, 4}             — пересечение
print(a - b)    # {1, 2}             — что есть у a, нет у b
print(b - a)    # {5, 6}
print(a ^ b)    # {1, 2, 5, 6}       — что есть только у одного

# На месте
a |= b          # a стало объединением
a &= b          # a стало пересечением
```

### Сравнения

| Метод | Что проверяет | Оператор | ⭐ |
|---|---|---|---|
| `issubset(other)` | Я вхожу в other? | `<=` | ⭐⭐ |
| `issuperset(other)` | other входит в меня? | `>=` | ⭐⭐ |
| `isdisjoint(other)` | У нас ничего общего? | — | ⭐⭐ |

```python
a = {1, 2}
b = {1, 2, 3, 4}

print(a.issubset(b))      # True — a внутри b
print(b.issuperset(a))    # True — b содержит a
print(a.isdisjoint({5, 6}))   # True — общих нет

# Операторы
print(a <= b)             # True
print(a < b)              # True (строгое подмножество)
```

### Копирование

| Метод | Что делает |
|---|---|
| `copy()` | Поверхностная копия |

```python
a = {1, 2}
b = a.copy()
b.add(3)
print(a)   # {1, 2} — не изменился
```

### Полная таблица методов `set`

| Метод | Что делает |
|---|---|
| `add(x)` | Добавить элемент |
| `clear()` | Очистить |
| `copy()` | Копия |
| `difference(*others)` | Разность (новое множество) |
| `difference_update(*others)` | Разность на месте |
| `discard(x)` | Удалить, если есть |
| `intersection(*others)` | Пересечение |
| `intersection_update(*others)` | На месте |
| `isdisjoint(other)` | Нет общих? |
| `issubset(other)` | Я — подмножество? |
| `issuperset(other)` | other — подмножество меня? |
| `pop()` | Удалить случайный |
| `remove(x)` | Удалить, ошибка если нет |
| `symmetric_difference(other)` | Не общее |
| `symmetric_difference_update(other)` | На месте |
| `union(*others)` | Объединение |
| `update(*others)` | Обновить (объединение на месте) |

## 🧊 `frozenset` — неизменяемое множество

Есть и «замороженная» версия множества — `frozenset`. Его нельзя менять, но можно использовать как ключ словаря или элемент другого множества:

```python
fs = frozenset([1, 2, 3])
# fs.add(4)             # ❌ AttributeError

# Зато можно так:
d = {frozenset([1, 2]): "первое", frozenset([3, 4]): "второе"}
```

Все методы чтения (`union`, `intersection` и т.д.) есть, но нет `add`, `remove` и т.п.

## 💡 Примеры

### Пример 1. Убрать дубликаты 🧹

```python
nums = [1, 2, 2, 3, 3, 3, 4, 4]
unique = list(set(nums))
print(unique)   # [1, 2, 3, 4] — порядок может отличаться
```

!!! tip "Как сохранить порядок"
    ```python
    nums = [3, 1, 2, 1, 3]
    unique = list(dict.fromkeys(nums))
    print(unique)   # [3, 1, 2]
    ```
    `dict.fromkeys` сохраняет порядок первого вхождения.

### Пример 2. Общие друзья 👥

```python
anna = {"Борис", "Вика", "Глеб"}
boris = {"Аня", "Вика", "Даша"}

common = anna & boris
print(f"Общие друзья: {common}")   # {'Вика'}

only_anna = anna - boris
print(f"Только у Ани: {only_anna}")   # {'Борис', 'Глеб'}
```

### Пример 3. Проверка уникальности букв 🔤

```python
word = "программирование"
letters = set(word)
print(f"Всего букв: {len(word)}")
print(f"Уникальных: {len(letters)}")
print(letters)
```

### Пример 4. Сюжетный — теги постов 📌

```python
post1_tags = {"python", "учёба", "школа"}
post2_tags = {"школа", "спорт", "python"}

print("Общие теги:", post1_tags & post2_tags)
print("Все теги:", post1_tags | post2_tags)
print("Только у первого:", post1_tags - post2_tags)
```

### Пример 5. Быстрая проверка наличия ⚡

```python
import time

big_list = list(range(1_000_000))
big_set = set(big_list)

# Проверка "входит ли 999_999"
# В set — мгновенно, в list — секунды
```

Множества проверяют наличие за O(1), списки — за O(n). Для больших данных разница колоссальна.

## ⚠️ Частые ошибки

!!! warning "Ошибка 1. `{}` — это не множество!"
    ```python
    a = {}          # пустой СЛОВАРЬ, не множество
    a = set()       # ✅
    ```

!!! warning "Ошибка 2. Множество не индексируется"
    ```python
    s = {1, 2, 3}
    s[0]            # ❌ TypeError
    ```
    Порядка нет! Чтобы взять элемент — превратите в список или используйте `next(iter(s))`.

!!! warning "Ошибка 3. Изменяемые элементы"
    ```python
    {[1, 2], [3, 4]}    # ❌ TypeError
    ```
    Элемент множества должен быть хешируемым. Список — нет, кортеж — да.

!!! warning "Ошибка 4. `remove` падает"
    ```python
    {1, 2}.remove(99)   # ❌ KeyError
    ```
    Используйте `discard` — он безопаснее.

!!! warning "Ошибка 5. Ожидание порядка"
    ```python
    print({3, 1, 2})    # может вывести {1, 2, 3} или другой порядок
    ```
    Порядок **не гарантирован**. Если он важен — используйте список или `dict`.
