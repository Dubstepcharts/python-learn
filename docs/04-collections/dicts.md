## 🍎 Объясняем просто

!!! example "Словарь — как телефонная книга"
    Ты не ищешь «Аня» по номеру страницы — ты открываешь и находишь её
    по **имени**. Имя — это ключ, телефон — значение.
    
    ```python
    phones = {
        "Аня": "+7-999-111-22-33",
        "Борис": "+7-999-444-55-66",
    }
    print(phones["Аня"])   # +7-999-111-22-33
    ```

    В словаре ты ищешь по ключу и получаешь значение — мгновенно, независимо
    от размера словаря.

## 📖 Что такое словарь

**Словарь** (`dict`) — коллекция пар **«ключ → значение»**:

- **Ключ** — уникальный «адрес» (число, строка, кортеж)
- **Значение** — что угодно: число, строка, список, другой словарь
- Порядок **сохраняется** (с Python 3.7) — в порядке добавления
- Ключи **уникальны**, значения — могут повторяться

```python
person = {
    "name": "Аня",
    "age": 12,
    "city": "Москва",
}

empty = {}
empty2 = dict()
```

## ✍️ Создание словаря

```python
# Литералом
a = {"x": 1, "y": 2}

# Из пар
b = dict(x=1, y=2)                # ключи — строки

# Из списка пар
c = dict([("x", 1), ("y", 2)])

# Из двух списков
keys = ["x", "y"]
values = [1, 2]
d = dict(zip(keys, values))
```

## 🎯 Основные операции

### Доступ и изменение

```python
person = {"name": "Аня", "age": 12}

print(person["name"])           # Аня
person["age"] = 13              # изменить
person["city"] = "Москва"       # добавить
del person["city"]              # удалить
```

### Обращение к несуществующему ключу — ошибка

```python
person["phone"]     # ❌ KeyError
```

**Безопасно через `get`:**

```python
print(person.get("phone"))            # None
print(person.get("phone", "не указан"))   # "не указан"
```

!!! tip "`get` vs `[]`"
    - `d[key]` — если ключа нет, **ошибка**
    - `d.get(key)` — если ключа нет, **None** (или своё значение по умолчанию)
    
    В «недоверенных» данных используйте `get`.

### Проверка наличия ключа

```python
if "name" in person:
    print("Есть такой ключ")
```

`in` проверяет именно **ключи**, не значения.

## 🎯 Все методы словаря

### Чтение

| Метод | Что возвращает | Пример | ⭐ |
|---|---|---|---|
| `keys()` | Все ключи | `d.keys()` | ⭐⭐⭐ |
| `values()` | Все значения | `d.values()` | ⭐⭐⭐ |
| `items()` | Пары `(ключ, значение)` | `d.items()` | ⭐⭐⭐ |
| `get(k, default)` | Значение или default | `d.get("x", 0)` | ⭐⭐⭐ |

```python
d = {"a": 1, "b": 2, "c": 3}

print(list(d.keys()))     # ['a', 'b', 'c']
print(list(d.values()))   # [1, 2, 3]
print(list(d.items()))    # [('a', 1), ('b', 2), ('c', 3)]
print(d.get("z", "нет"))  # нет
```

!!! info "Подробнее: `keys()` и `values()` — это «представления» 🔬"
    Они не создают копию, а смотрят на словарь «вживую». Если словарь
    изменится — изменится и вид. Чтобы получить список — оберните в `list()`:
    ```python
    keys = list(d.keys())
    ```

### Добавление и изменение

| Метод | Что делает | Пример | ⭐ |
|---|---|---|---|
| `update(other)` | Обновить парами из другого | `d.update({"x": 1})` | ⭐⭐ |
| `setdefault(k, default)` | Получить или установить | `d.setdefault("x", 0)` | ⭐⭐ |

```python
d = {"a": 1}

d.update({"b": 2, "c": 3})   # {'a': 1, 'b': 2, 'c': 3}
d.update([("d", 4)])          # то же с парами

# setdefault — «если ключа нет, создай с этим значением»
counts = {}
counts.setdefault("a", 0)
counts["a"] += 1             # a: 1
```

!!! tip "Где полезен `setdefault`"
    Классический счётчик:
    ```python
    text = "abracadabra"
    counts = {}
    for ch in text:
        counts.setdefault(ch, 0)
        counts[ch] += 1
    print(counts)   # {'a': 5, 'b': 2, 'r': 2, 'c': 1, 'd': 1}
    ```
    С 3.8+ то же делает `collections.Counter(text)`.

### Удаление

| Метод | Что делает | Пример | ⭐ |
|---|---|---|---|
| `pop(k, default)` | Удалить ключ и вернуть значение | `d.pop("a")` | ⭐⭐⭐ |
| `popitem()` | Удалить и вернуть последнюю пару | `d.popitem()` | ⭐ |
| `clear()` | Очистить словарь | `d.clear()` | ⭐⭐ |
| `del d[k]` | Удалить ключ (оператор) | `del d["a"]` | ⭐⭐⭐ |

```python
d = {"a": 1, "b": 2, "c": 3}

val = d.pop("a")          # val=1, d={"b": 2, "c": 3}
key, val = d.popitem()    # key="c", val=3, d={"b": 2}

del d["b"]                # d={}
d.clear()                 # то же самое
```

### Копирование

| Метод | Что делает |
|---|---|
| `copy()` | Поверхностная копия |

```python
a = {"x": 1}
b = a.copy()          # независимая копия
b["y"] = 2
print(a)              # {'x': 1} — не изменился
```

!!! warning "`b = a` — это ссылка, а не копия!"
    То же правило, что и со списками.

### Полная таблица методов `dict`

| Метод | Возвращает | Что делает |
|---|---|---|
| `clear()` | `None` | Удалить все элементы |
| `copy()` | новый dict | Поверхностная копия |
| `fromkeys(iter, val)` | dict | Создать из ключей (класс-метод) |
| `get(k, default=None)` | значение | Безопасный доступ |
| `items()` | view | Пары `(ключ, значение)` |
| `keys()` | view | Ключи |
| `pop(k, default)` | значение | Удалить и вернуть |
| `popitem()` | (k, v) | Удалить последнюю пару |
| `setdefault(k, default=None)` | значение | Получить/установить |
| `update(other)` | `None` | Обновить из другого |
| `values()` | view | Значения |
| `d \| other` (3.9+) | dict | Объединить словари |
| `d \|= other` (3.9+) | — | Обновить in-place |

```python
# fromkeys — пример
keys = ["a", "b", "c"]
d = dict.fromkeys(keys, 0)
print(d)   # {'a': 0, 'b': 0, 'c': 0}

# | — объединение (3.9+)
a = {"x": 1}
b = {"y": 2}
c = a | b
print(c)   # {'x': 1, 'y': 2}
```

## 🔁 Перебор словаря

```python
person = {"name": "Аня", "age": 12, "city": "Москва"}

# Только ключи
for key in person:
    print(key)

# Только значения
for value in person.values():
    print(value)

# Пары
for key, value in person.items():
    print(f"{key}: {value}")
```

Самый полезный — третий вариант с `.items()`.

## 💡 Примеры

### Пример 1. Телефонная книга 📞

```python
phones = {
    "Аня": "+7-999-111-22-33",
    "Борис": "+7-999-444-55-66",
}

name = input("Кого ищем? ")
if name in phones:
    print(f"{name}: {phones[name]}")
else:
    print("Нет такого контакта")
```

### Пример 2. Подсчёт слов 📊

```python
text = "кот пёс кот кот пёс"
words = text.split()

counts = {}
for w in words:
    counts[w] = counts.get(w, 0) + 1

print(counts)   # {'кот': 3, 'пёс': 2}
```

### Пример 3. Сюжетный — ученики и оценки 🎓

```python
grades = {
    "Аня": [5, 4, 5],
    "Борис": [3, 4, 3],
    "Вика": [5, 5, 5],
}

for name, marks in grades.items():
    avg = sum(marks) / len(marks)
    print(f"{name}: средний балл {avg:.2f}")
```

### Пример 4. Вложенный словарь 🪆

```python
school = {
    "7А": {"учеников": 25, "классрук": "Иванова"},
    "7Б": {"учеников": 27, "классрук": "Петров"},
}

for cls, info in school.items():
    print(f"{cls} — {info['учеников']} учеников")
```

### Пример 5. Словарь из двух списков 🔗

```python
names = ["Аня", "Борис", "Вика"]
ages = [12, 11, 13]

people = dict(zip(names, ages))
print(people)   # {'Аня': 12, 'Борис': 11, 'Вика': 13}
```

## ⚠️ Частые ошибки

!!! warning "Ошибка 1. `KeyError` при обращении к несуществующему ключу"
    ```python
    d["нет такого"]        # ❌ KeyError
    ```
    Проверяйте `in` или используйте `.get()`.

!!! warning "Ошибка 2. Изменение словаря во время `for`"
    ```python
    for k in d:
        del d[k]           # ❌ RuntimeError
    ```
    **Правильно:**
    ```python
    for k in list(d.keys()):
        del d[k]
    ```

!!! warning "Ошибка 3. Список как ключ"
    ```python
    d = {[1, 2]: "x"}      # ❌ TypeError
    ```
    Ключ должен быть **хешируемым**: число, строка, кортеж, `frozenset`.
    Список — нет, кортеж — да.

!!! warning "Ошибка 4. `d.keys()` — не список"
    ```python
    d.keys()[0]            # ❌ TypeError
    ```
    Оберните: `list(d.keys())[0]` или просто `list(d)[0]`.
